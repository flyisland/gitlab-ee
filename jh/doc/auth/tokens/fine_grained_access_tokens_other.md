细粒度个人访问令牌只能访问您授予它的资源和权限。
要将其用于 Git 及其他操作，请创建令牌并定义其作用域。有关更多信息，请参阅
[细粒度个人访问令牌](fine_grained_access_tokens.md)。

在下表中：

- **资源**和**权限**是您创建令牌时要选择的资源和权限。
- **访问**是必须包含目标资源的边界。作用域为群组的令牌也会授权对该群组中项目的操作。

<a id="git-operations"></a>

## Git 操作

用作 Git over HTTPS 密码的细粒度个人访问令牌必须具有以下权限：

| 操作                          | 资源 | 权限 | 访问        |
| ---------------------------------- | -------- | ---------- | ------------- |
| 克隆或拉取项目代码仓库 | 代码     | 下载   | 项目       |
| 推送到项目代码仓库       | 代码     | 推送       | 项目       |
| 克隆或拉取 Wiki               | Wiki     | 读取       | 项目、群组 <sup>1</sup> |
| 推送到 Wiki                     | Wiki     | 创建     | 项目、群组 <sup>1</sup> |
| 克隆或拉取代码片段            | 代码片段  | 读取       | 项目、用户 <sup>2</sup> |
| 推送到代码片段                  | 代码片段  | 更新     | 项目、用户 <sup>2</sup> |
| 下载 Git LFS 对象           | 代码     | 下载   | 项目       |
| 上传 Git LFS 对象             | 代码     | 推送       | 项目       |

**脚注**：

1. 项目 Wiki 使用项目边界，群组 Wiki 使用群组边界。
1. 项目代码片段使用项目边界，个人代码片段使用用户边界。

<a id="container-registry"></a>

## 容器镜像仓库

用于登录
[容器镜像仓库](../../user/packages/container_registry/authenticate_with_container_registry.md)
的细粒度个人访问令牌必须具有以下权限：

| 操作                                     | 资源             | 权限 | 访问  |
| --------------------------------------------- | -------------------- | ---------- | ------- |
| 拉取容器镜像                         | 容器仓库 | 读取       | 项目 |
| 删除容器镜像和标签              | 容器仓库 | 删除     | 项目 |

> [!note]
> 您不能使用细粒度个人访问令牌推送容器镜像。

## 依赖代理

用于登录
[依赖代理](../../user/packages/dependency_proxy/_index.md) 的细粒度个人访问令牌必须具有以下
权限：

| 操作                                     | 资源         | 权限 | 访问 |
| --------------------------------------------- | ---------------- | ---------- | ------ |
| 通过依赖代理拉取容器镜像 | 依赖代理 | 读取  | 群组  |

## 归档和发布资产下载

| 操作                                     | 资源 | 权限 | 访问  |
| --------------------------------------------- | -------- | ---------- | ------- |
| 下载代码仓库归档                 | 代码     | 下载   | 项目 |
| 通过直接链接下载发布资产   | 发布       | 读取       | 项目 |

<a id="rss-and-calendar-feeds"></a>

## RSS 和日历订阅源

用于验证 RSS 或 iCalendar 订阅源请求的细粒度个人访问令牌必须具有
以下权限：

| 订阅源                                          | 资源              | 权限 | 访问               |
| --------------------------------------------- | --------------------- | ---------- | -------------------- |
| 用户活动                                 | 活动              | 读取       | 用户                 |
| 项目活动                              | 事件                 | 读取       | 项目              |
| 群组活动                                | 事件                 | 读取       | 群组                |
| 项目提交                               | 代码                  | 读取       | 项目              |
| 项目标签                                  | 代码                  | 读取       | 项目              |
| 议题和工作项，包括日历    | 工作项             | 读取       | 项目、群组、用户 |
| 合并请求                                | 合并请求         | 读取       | 项目、群组       |
| 您的项目                                 | 项目               | 读取       | 用户                 |
| 个人访问令牌过期日历     | 个人访问令牌 | 读取       | 用户                 |
