[极狐 GitLab for Visual Studio 扩展](https://marketplace.visualstudio.com/items?itemName=GitLab.GitLabExtensionForVisualStudio) 将 极狐 GitLab 与 Visual Studio for Windows 集成。

极狐 GitLab for Visual Studio 支持：

- [极狐 GitLab Duo Agent Platform](../../user/duo_agent_platform/_index.md)，包括 极狐 GitLab Duo Agentic Chat、软件开发流程和 极狐 GitLab Duo 代码建议。
- [极狐 GitLab Duo](../../user/gitlab_duo/feature_summary.md)，包括 极狐 GitLab Duo Non-Agentic Chat 和 代码建议。

要安装和配置扩展，请参阅 [安装和设置](setup.md)。

<a id="update-the-extension"></a>

## 更新扩展

要将扩展更新到最新版本：

1. 在 Visual Studio 中，前往 **扩展** > **管理扩展...**。
1. 选择 **更新** 选项卡。
1. 搜索由 **极狐 GitLab (`jihulab.com`)** 发布的 **极狐 GitLab for Visual Studio**。
1. 选择扩展上的 **更新** 以更新到最新版本。
