Git 是一个[免费且开源](https://git-scm.com/about/free-and-open-source)的分布式版本控制系统。它可以快速高效地处理各种规模的项目，并支持在需要时回滚变更。

极狐GitLab 构建于 Git 之上（并伴随 Git），为您提供一个基于 Git 的全集成平台进行软件开发。极狐GitLab 在 Git 之上添加了许多强大的[功能](https://gitlab.cn/features/)来增强您的工作流程。
