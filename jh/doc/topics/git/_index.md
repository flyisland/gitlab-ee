Git 是一个[免费开源](https://git-scm.com/about/free-and-open-source)的分布式版本控制系统。它能够快速、高效地处理各种规模的项目，并在需要时支持回滚更改。

极狐GitLab 构建于 Git 之上（并与 Git 结合），为您提供一个基于 Git、完全集成的软件开发平台。极狐GitLab 在 Git 之上添加了许多强大的[功能](https://about.gitlab.com/pricing/feature-comparison/)，以增强您的工作流。
