您可以更新偏好设置，以更改极狐GitLab 的外观和体验。

<a id="change-the-mode"></a>

## 更改模式

您可以将界面的颜色模式更改为浅色、深色，或根据设备偏好自动更新。

要更改外观：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 在 **模式** 部分，选择一个选项。
1. 选择 **保存更改**。

<a id="change-the-navigation-theme"></a>

## 更改导航主题

您可以更改极狐GitLab UI 的导航主题。这些颜色显示在左侧边栏中。
使用不同的导航主题可能有助于您区分不同的
极狐GitLab 实例。

要更改导航主题：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 在 **主题** 部分，选择一个主题。

<a id="change-the-syntax-highlighting-theme"></a>

## 更改语法高亮主题

语法高亮是代码编辑器和 IDE 中的一项功能。高亮器为每种类型的代码（如字符串和注释）分配一种颜色。

要更改语法高亮主题：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 在 **语法高亮** 部分，选择一个主题。
1. 选择 **保存更改**。

要查看更新后的语法高亮主题，请刷新您项目的页面。

要自定义语法高亮主题，您还可以[使用应用程序设置 API](../../api/settings.md#available-settings)。使用 `default_syntax_highlighting_theme` 和 `default_dark_syntax_highlighting_theme` 在更细粒度级别更改语法高亮颜色。

如果这些步骤不起作用，您的编程语言可能不受语法高亮器支持。
有关更多信息，请查看 [Rouge Ruby 库](https://github.com/rouge-ruby/rouge) 以获取代码文件和代码片段的指导。查看 [Monaco Editor](https://microsoft.github.io/monaco-editor/) 和 [Monarch](https://microsoft.github.io/monaco-editor/monarch.html) 以获取 Web IDE 的指导。

<a id="change-the-diff-colors"></a>

## 更改差异颜色

差异使用两种不同的背景颜色来显示代码版本之间的更改。默认情况下，原始文件为红色，更改部分为绿色。

要更改差异颜色：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 转到 **差异** 部分。
1. 选择一种颜色或输入颜色代码。
1. 选择 **保存更改**。

要更改回默认颜色，请清除 **已删除行的颜色** 和 **已添加行的颜色** 文本框，然后选择 **保存更改**。

<a id="behavior"></a>

## 行为

使用 **行为** 部分自定义系统布局和默认视图的行为。您可以更改布局宽度，并选择主页、群组和项目概览页面的默认内容。您可以选择自定义外观和功能，例如空白字符渲染、文件显示和文本自动化。

您还可以使用此部分为极狐GitLab Duo 设置默认命名空间。

### 更改 UI 上的布局宽度

1. 选择 **保存更改**。

<a id="set-a-default-gitlab-duo-namespace"></a>

### 设置默认的极狐GitLab Duo 命名空间

设置默认的极狐GitLab Duo 命名空间，以确保极狐GitLab Duo 可用于您的项目。
您的默认极狐GitLab Duo 命名空间决定了您可用的 [AI 模型](../gitlab_duo/model_selection.md)
和极狐GitLab Duo 功能，以及您对 [极狐GitLab Credits](../../subscriptions/gitlab_credits.md) 的消耗。

您的默认极狐GitLab Duo 命名空间决定了以下场景中的功能可用性和 Credits 消耗：

- 您不是您正在工作的项目的成员。
- 您属于多个极狐GitLab Duo 命名空间。
- 您在 IDE 中使用一个未配置极狐GitLab 远程代码仓库的项目。
- 您在 CLI 中使用极狐GitLab Duo。

当您在您作为直接或继承成员的项目或群组中工作时，
该项目或群组的顶级群组将用于功能可用性和 Credits 消耗：

- 如果您在您是其成员的项目中使用极狐GitLab Duo 功能，
  使用量将计入该项目的顶级群组。
- 如果您在项目之外使用极狐GitLab Duo 功能（例如，在未打开项目的 IDE 中或在 CLI 中），
  使用量将计入您的默认命名空间。
- 如果您在您不是其成员的项目中使用极狐GitLab Duo 功能，
  使用量将计入您的默认命名空间。

如果您未设置默认命名空间，极狐GitLab Duo Agentic Chat 和极狐GitLab Duo Agent Platform 将被禁用。

要设置默认的极狐GitLab Duo 命名空间：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 滚动到 **行为** 部分。
1. 从 **默认极狐GitLab Duo 群组** 下拉列表中，选择要设置为默认的群组。
1. 选择 **保存更改**。

<a id="namespace-resolution-in-your-local-environment"></a>

#### 本地环境中的命名空间解析

当您在 IDE 或 CLI 中使用极狐GitLab Duo 时，第一个可用的命名空间决定功能
可用性和 Credits 消耗。与其他 Agent Platform 要求一样，您工作的项目
必须位于[群组命名空间](../namespace/_index.md)中。

极狐GitLab Duo 按以下顺序检查命名空间：

1. 项目命名空间，如果您的项目链接到极狐GitLab 中的远程代码仓库。
1. 在您的用户偏好设置中设置的默认命名空间。
1. 对于 IDE，在编辑器扩展设置中设置的默认命名空间：
   - 对于 VS Code，在 **扩展** > **GitLab** > **极狐GitLab Duo** > **GitLab › Duo Agent Platform: 默认命名空间** 下。
   - 对于 JetBrains IDE，在 **设置** > **工具** > **极狐GitLab Duo** > **极狐GitLab Duo Agent Platform** 下。
   - 对于 Visual Studio，在 **工具** > **选项** > **GitLab** > **常规** 下。

如果识别出的第一个命名空间无权访问所请求的功能或没有可用的 Credits，
则该功能不可用。极狐GitLab Duo 不会回退到列表中的下一个命名空间。

<a id="show-whitespace-characters-in-the-web-ide"></a>

### 在 Web IDE 中显示空白字符

空白字符是文本中的任何空白字符，例如空格和缩进。您可以使用空白字符来组织代码内容。如果您的编程语言对空白字符敏感，Web IDE 可以检测到对它们的更改。

要在 Web IDE 中渲染空白字符：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 滚动到 **行为** 部分。
1. 选中 **在 Web IDE 中渲染空白字符** 复选框。
1. 选择 **保存更改**。

您可以在差异中查看对空白字符的更改。

要在 Web IDE 上查看差异，请按照以下步骤操作：

1. 在左侧边栏中，选择 **源代码管理** ({{< icon name="branch" >}})。
1. 在 **更改** 选项卡下，选择您的文件。

<a id="show-whitespace-changes-in-diffs"></a>

### 在差异中显示空白字符更改

在差异文件中查看对空白字符的更改。有关空白字符的更多信息，请查看上一个任务。

要在差异中查看对空白字符的更改：

1. 选择 **偏好设置**。
1. 滚动到 **行为** 部分。

有关差异的更多信息，请查看 [更改差异颜色](#change-the-diff-colors)。

<a id="auto-enclose-characters"></a>

### 自动闭合字符

当您键入左字符时，自动在文本中添加相应的右字符。例如，当您键入左括号时，可以自动插入右括号。此设置仅适用于描述和评论框，以及以下字符：`**"`, `'`, ```, `(`, `[`, `{`, `<`, `*`, `_**`。

要在描述和评论框中自动闭合字符：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 滚动到 **行为** 部分。
1. 选中 **键入引号或括号时包围文本选择** 复选框。
1. 选择 **保存更改**。

现在，在描述或评论框中，您可以键入一个单词，突出显示它，然后键入一个
左字符。右字符将添加到末尾，而不是替换文本。

1. 选择 **保存更改**。

<a id="turn-off-emoji-autocomplete"></a>

### 关闭表情符号自动补全

匹配的表情符号。如果您出于其他原因键入冒号，例如在冒号前加空格的
语言中，您可以关闭这些建议。关闭后，您仍然可以通过其他方式插入表情符号，
例如复制和粘贴。

要关闭表情符号自动补全：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 滚动到 **行为** 部分。
1. 清除 **启用表情符号自动补全** 复选框。
1. 选择 **保存更改**。

<a id="user-identities-in-ci-job-json-web-tokens"></a>

## CI 作业 JSON Web 令牌中的用户身份

CI/CD 作业会生成 JSON Web 令牌，其中可以包含您的外部身份列表。
您无需单独调用 API 来获取各个账户，而可以在单个身份验证令牌中找到您的用户身份。

默认情况下不包含外部身份。
要启用包含外部身份，请参阅 [令牌负载](../../ci/secrets/id_token_authentication.md#token-payload)。

<a id="control-follower-engagement"></a>

## 控制关注者互动

关闭被其他极狐GitLab 用户关注或关注其他用户的功能。默认情况下，您的用户个人资料（包括您的姓名和个人资料照片）在其他用户的 **关注** 选项卡中是公开的。当您停用此设置时：

- 极狐GitLab 会删除您的所有关注者和关注连接。
- 极狐GitLab 会自动从每个连接的页面中删除您的用户个人资料。

要移除被其他用户关注和关注其他用户的功能：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 清除 **启用关注用户** 复选框。
1. 选择 **保存更改**。

要访问您的 **关注者** 和 **关注** 选项卡：

- 在右上角，选择您的头像。
- 选择 **关注者** 或 **关注**。

<a id="integrate-your-gitlab-instance-with-third-party-services"></a>

## 将您的极狐GitLab 实例与第三方服务集成

授予第三方服务访问权限，以增强极狐GitLab 体验。

<a id="integrate-your-gitlab-instance-with-ona"></a>

### 将您的极狐GitLab 实例与 Ona 集成

当您想直接从极狐GitLab 浏览器启动和管理代码时，请使用 Ona 配置您的极狐GitLab 实例。Ona 会自动为您的项目准备和构建开发环境。

要与 Ona 集成：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 找到 **集成** 部分。
1. 选中 **启用 Ona 集成** 复选框。
1. 选择 **保存更改**。

<a id="integrate-your-gitlab-instance-with-sourcegraph"></a>

### 将您的极狐GitLab 实例与 Sourcegraph 集成

极狐GitLab 支持对极狐GitLab 上的所有公共项目进行 Sourcegraph 集成。

要与 Sourcegraph 集成：

1. 在右上角，选择您的头像。
1. 选择 **偏好设置**。
1. 找到 **集成** 部分。
1. 选中 **在代码视图上启用集成代码智能** 复选框。
1. 选择 **保存更改**。

您必须是极狐GitLab 实例的管理员才能使用 Sourcegraph 配置极狐GitLab。

### 与扩展市场集成
