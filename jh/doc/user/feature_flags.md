<a id="gitlab-provides-feature-flags"></a>

极狐 GitLab 提供功能标识来打开或关闭特定功能。此页面包含极狐 GitLab 提供的所有功能标识的列表。在极狐 GitLab 私有化部署中，极狐 GitLab 管理员可以[更改这些功能标识的状态](../administration/feature_flags.md)。

<a id="for-help-developing-custom-feature-flags"></a>

有关开发自定义功能标识的帮助，请参阅[创建功能标识](../operations/feature_flags.md#create-a-feature-flag)。
