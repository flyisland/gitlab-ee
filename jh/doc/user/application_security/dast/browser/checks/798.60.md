## 描述

响应体中包含与 HubSpot 私有应用 API 令牌模式匹配的内容，即检测到了此类令牌泄露。私有应用允许您使用 HubSpot 的 API 来访问 HubSpot 帐户中的特定数据，并可通过设定特定作用域进行限制。获得此令牌的恶意行为者可以凭借与应用程序作用域设置相同的权限调用 API 端点。这可能导致从仅读取营销活动到访问用户和账户信息以及发送邮件等多种后果。泄露此值可能使攻击者能够获取该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 补救措施

有关处理密钥泄露安全事故的一般性指导，请参见极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换私有应用 API 令牌：

- 登录您的 HubSpot 账户，访问 <https://app.hubspot.com/>
- 在左侧菜单中，将鼠标悬停在数据库图标上，然后选择“集成”
- 找到包含已识别令牌的私有应用并单击其名称
- 在页面顶部选择“身份验证”选项卡
- 在页面的“访问令牌”区域中，选择“轮换”
- 当出现提示时，选择“立即轮换并过期此令牌”
- 在“立即轮换访问令牌？”对话框中，选择“立即轮换”

更多信息，请参阅 [HubSpot 的私有应用文档](https://developers.hubspot.com/beta-docs/guides/apps/private-apps/overview)
