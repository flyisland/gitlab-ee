<a id="description"></a>

## 描述

可能在目标应用服务器的后端数据库中执行任意 SQL 命令。SQL 注入是一个严重漏洞，可能导致数据或系统受损。

<a id="remediation"></a>

## 修复

在向后端数据库系统发出请求时始终使用参数化查询。在必须创建动态查询的情况下，切勿直接使用用户输入，而应使用由有效值组成的映射或字典，并通过用户提供的键来解析这些值。

例如，部分数据库驱动不允许对 `>` 或 `<` 比较运算符使用参数化查询。在这些情况下，不要使用用户提供的 `>` 或 `<` 值，而是让用户提供 `gt` 或 `lt` 值。然后使用这些字母值来查找 `>` 和 `<` 值，以用于构建动态查询。对于其他需要列名或表名但无法参数化的查询，也采用同样的方法。
