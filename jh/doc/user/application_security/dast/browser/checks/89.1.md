<a id="description"></a>

## 描述

可以在目标应用服务器的后端数据库上执行任意 SQL 命令。SQL 注入是一种严重漏洞，可能导致数据或系统遭到入侵。

<a id="remediation"></a>

## 修复

在向后端数据库系统发出请求时，请始终使用参数化查询。在必须创建动态查询的情况下，切勿使用直接的用户输入，而应使用有效值的映射或字典，并通过用户提供的键来解析这些值。

例如，某些数据库驱动程序不允许对 `>` 或 `<` 比较运算符使用参数化查询。在这些情况下，不要使用用户提供的 `>` 或 `<` 值，而应让用户提供 `gt` 或 `lt` 值。然后使用这些字母值查找要在构建动态查询时使用的 `>` 和 `<` 值。对于需要列名或表名但无法参数化的其他查询，也是如此。
