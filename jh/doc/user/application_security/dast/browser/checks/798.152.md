<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab CI 构建（作业）令牌模式匹配的内容。作业令牌用于在流水线作业的上下文中执行功能。在大多数情况下，作业令牌的权限有限，只能用于从流水线执行所在的代码仓库读取内容。外部项目可以授予其他项目的作业令牌访问权限。恶意行为者利用此令牌尝试访问代码仓库的时间窗口有限。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。由于作业令牌的有效期很短，因此没有吊销流程，创建它的作业完成后该令牌即不再可用。有关作业令牌具体可以访问哪些内容的更多详情，请参阅 [极狐GitLab 关于作业令牌的文档](../../../../../ci/jobs/ci_job_token.md)。
