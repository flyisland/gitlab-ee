## 描述

我们在响应正文内容中检测到了与 极狐GitLab CI 构建（作业）令牌模式相匹配的内容。作业令牌用于在流水线作业的上下文中执行功能。在大多数情况下，作业令牌的权限有限，只能用于从流水线执行的仓库中进行读取。外部项目可以授予来自其他项目的作业令牌访问权限。恶意行为者只有有限的时间窗口使用此令牌来尝试访问代码仓库。
暴露此值可能允许攻击者获得此令牌所授予的所有资源的访问权限。

## 修复建议

有关处理因密钥泄露导致的安全事件的一般指导，请参阅 极狐GitLab 文档中关于[凭证暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。由于作业令牌的生命周期很短，因此没有撤销流程，它在创建它的作业完成后就不再可用。
有关作业令牌具体允许访问哪些内容的更多详细信息，请参阅[极狐GitLab 关于作业令牌的文档](../../../../../ci/jobs/ci_job_token.md)。
