<a id="description"></a>

## 描述

响应正文中包含与 GCP 服务账号模式匹配的内容。服务账号可被授予多种权限或访问范围。能够访问该服务账号的恶意行为者可能会危及整个 GCP 账号，也可能仅对资源拥有有限访问权限，具体取决于所授予的访问权限。暴露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 GCP 服务账号：

- 登录您的 GCP 账号并前往 <https://console.cloud.google.com/iam-admin/serviceaccounts>
- 从列表中选择正确的项目（如果提供选择）
- 在“服务账号”表中找到密钥 ID 及关联的服务账号
- 为所识别的密钥选择三点菜单（垂直省略号），然后选择“管理密钥”
- 选择所识别密钥旁边的垃圾桶图标

有关更多信息，请参阅 [Google 关于创建服务账号密钥的文档](https://docs.cloud.google.com/iam/docs/keys-create-delete)。
