<a id="description"></a>

## 描述

响应主体包含与 GCP 服务账号模式相匹配的内容。服务账号可被授予广泛的权限或访问权限。获得该服务账号访问权限的恶意攻击者可能会危害整个 GCP 账号，或根据所授予的访问权限，限制对资源的访问。泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复建议

有关泄露密钥的安全事件处理的通用指南，请参阅极狐GitLab 文档中的[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 GCP 服务账号：

- 登录你的 GCP 账号并前往 <https://console.cloud.google.com/iam-admin/serviceaccounts>
- 从列表中选择正确的项目（如果可选的话）
- 在“服务账号”表中找到密钥 ID 与关联的服务账号
- 选择识别出的密钥旁边的烤肉串菜单（垂直省略号），然后选择“管理密钥”
- 选择识别出的密钥旁边的垃圾桶图标

更多信息，请参阅[Google 关于创建服务账号密钥的文档](https://cloud.google.com/iam/docs/keys-create-delete)。
