<a id="description"></a>

## 描述

检测到响应正文中包含与 Slack webhook URL 模式匹配的内容。Slack webhook URL 用于从外部来源向 Slack 发送消息。它们使用带有 JSON 负载的 HTTP 请求，该负载包含消息和一些其他可选细节。您可以包含消息附件以显示格式丰富的消息。能够访问此 URL 的恶意行为者可以向其绑定的 Slack 频道发布消息。
泄露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换 Slack webhook URL：

- 登录 Slack 并访问 <https://api.slack.com/apps>
- 找到具有已识别 webhook URL 的应用程序并选择其名称
- 在左侧菜单中，选择“Incoming Webhooks”
- 在“Webhook URL”表中，选择已识别 webhook URL 旁边的垃圾桶图标。
- 出现提示时，在确认对话框中选择“移除”

更多信息，请参阅 [Slack 关于 webhook 的文档](https://api.slack.com/messaging/webhooks)。
