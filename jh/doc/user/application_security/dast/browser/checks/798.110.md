<a id="description"></a>

## 描述

检测到响应正文中包含与 Slack webhook URL 模式匹配的内容。Slack webhook URL 用于将来自外部来源的消息发布到 Slack 中。它们使用带有 JSON 载荷的 HTTP 请求，其中包含消息以及一些其他可选详情。您可以包含消息附件以显示格式丰富的消息。能够访问此 URL 的恶意行为者可以向其绑定的 Slack 频道发布消息。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换 Slack webhook URL：

- 登录 Slack 并访问 <https://api.slack.com/apps>
- 找到具有所识别 webhook URL 的应用，并选择其名称
- 在左侧菜单中，选择“Incoming Webhooks”
- 在“Webhook URL”表格中，选择所识别 webhook URL 旁边的垃圾桶图标。
- 出现提示时，在确认对话框中选择“Remove”

有关更多信息，请参阅 [Slack 关于 webhook 的文档](https://api.slack.com/messaging/webhooks)。
