<a id="description"></a>

## 描述

应用程序存在服务端模板注入（SSTI）漏洞，使攻击者能够在服务端操纵模板。当未经验证的用户输入在未进行充分清理的情况下直接被用于服务端模板时，就会产生此漏洞。攻击者可以利用这一弱点在模板中注入并执行任意代码，从而可能危及系统的完整性和机密性。

<a id="remediation"></a>

## 修复方案

在构建表达式语言语句时，应始终对用户控制的数据中的特殊元素进行中性化处理。请查阅您所使用的模板系统的文档，了解如何正确中性化处理用户控制的数据。
