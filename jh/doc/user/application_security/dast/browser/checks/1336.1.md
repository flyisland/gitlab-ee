<a id="description"></a>

## 描述

该应用程序易受服务端模板注入（SSTI）攻击，攻击者可借此在服务端操纵模板。当不受信任的用户输入未经充分清理就直接用于服务端模板时，就会出现此漏洞。攻击者可利用该弱点在模板中注入并执行任意代码，从而可能破坏系统的完整性和机密性。

<a id="remediation"></a>

## 修复

在将用户可控数据用于构建表达式语言（Expression Language）语句时，应始终对其中的特殊元素进行中和处理。请查阅所用模板系统的文档，了解如何正确中和用户可控数据。
