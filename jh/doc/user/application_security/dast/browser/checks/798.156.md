<a id="description"></a>

## 描述

响应正文中包含与 Intercom 客户端密钥或客户端 ID 模式匹配的内容。客户端密钥用于允许用户登录您的应用程序。根据所请求的范围，恶意行为者可能冒充该服务来访问用户的信息。暴露此值可能使攻击者能够访问此令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。客户端密钥或 ID 无法轮换。您必须删除应用程序并重新创建。有关更多信息，请参阅 [Intercom 关于设置应用程序的文档](https://developers.intercom.com/docs/build-an-integration/getting-started/build-an-app-for-your-messenger/sheets-app#set-up)。
