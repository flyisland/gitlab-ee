<a id="description"></a>

## 描述

在响应主体中检测到匹配 AWS 访问令牌模式的内容。AWS 访问令牌通常与其密钥值配对。能访问此令牌的恶意行为者可以使用生成该密钥的用户相同的权限访问 AWS 服务，前提是他们同时拥有这两个值。
暴露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方案

有关处理涉及密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据在互联网上的暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。要删除访问密钥：- 在“访问密钥”部分中，找到被标识的密钥 - 选择“操作” - 选择“删除” - 按照对话框中的说明先停用，然后确认删除。有关如何管理和撤销 AWS 访问密钥的信息，请参阅其[文档](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html#Using_CreateAccessKey)。
