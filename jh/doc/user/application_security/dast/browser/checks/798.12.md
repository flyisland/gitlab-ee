<a id="description"></a>

## 描述

检测到响应正文中包含与 AWS 访问令牌模式匹配的内容。AWS 访问令牌通常与其密钥值成对出现。能够访问此令牌的恶意行为者，只要同时获取了这两个值，就可以使用与生成该密钥的用户相同的权限访问 AWS 服务。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要删除访问密钥：- 在“访问密钥”部分，找到被识别出的密钥 - 选择“操作” - 选择“删除” - 按照对话框中的说明，先停用该密钥，然后确认删除。有关如何管理和撤销 AWS 访问密钥的信息，请参阅其[文档](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html#Using_CreateAccessKey)。
