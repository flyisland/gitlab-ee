<a id="description"></a>

## 描述

响应正文中包含与已识别的 LinkedIn 客户端密钥模式匹配的内容。客户端密钥用于允许用户登录您的应用程序。根据请求的范围，恶意行为者可以冒充该服务以访问用户信息。暴露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理涉及密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露至公网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的说明。

要重新生成您的客户端密钥：

- 登录您的 LinkedIn 账户并访问 <https://www.linkedin.com/developers/apps/>
- 找到包含已识别密钥的应用程序并选择其名称
- 选择 "Auth" 选项卡
- 在 "Application credentials" 部分中选择 "Generate a new Client Secret"
- 如果 "Generate a new Client Secret" 不存在，您很可能有两个活动密钥，删除其中一个，它应该会出现
- 选择已识别密钥旁边的 "X" 以将其删除
- 当出现提示时，在 "Remove the Primary Client Secret" 对话框中选择 "Confirm"

更多信息，请参阅 [LinkedIn 的 API 访问文档](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access)。
