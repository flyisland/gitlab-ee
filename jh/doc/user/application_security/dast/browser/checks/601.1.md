<a id="description"></a>

## 描述

发现此站点允许来自用户输入的开放重定向。开放重定向通常被滥用于网络钓鱼攻击中，原始域名或 URL 看似合法链接，但随后将用户重定向到恶意站点。例如 `https://example.com/redirect?url=https://%62%61%64%2e%63%6f%6d%2f%66%61%6b%65%6c%6f%67%69%6e`，解码后变为 `bad.com/fakelogin`。

<a id="remediation"></a>

## 修复建议

永远不要根据 `GET` 请求中的用户输入重定向客户端。建议将重定向目标链接列表保存在服务器端，并使用数字值作为索引来检索要重定向到的链接。例如，`/redirect?id=1` 会使应用程序查找索引 `1` 并返回诸如 `https://example.com` 的 URL。然后使用此 URL，通过 301 响应代码和 `Location` 头部重定向用户。
