<a id="description"></a>

## 描述

发现此站点允许基于用户提供的输入进行开放重定向。开放重定向通常被滥用于钓鱼攻击中，此时原始域名或 URL 看起来像是合法链接，但随后会将用户重定向到恶意站点。例如
`https://example.com/redirect?url=https://%62%61%64%2e%63%6f%6d%2f%66%61%6b%65%6c%6f%67%69%6e`，
解码后会变成 `bad.com/fakelogin`。

<a id="remediation"></a>

## 修复

切勿根据 `GET` 请求中的用户输入来重定向客户端。建议将用于重定向用户的目标链接列表保存在服务器端，并使用数值作为索引来检索要重定向到的链接。例如，`/redirect?id=1` 会使应用程序查找 `1` 索引并返回诸如 `https://example.com`的 URL。然后使用该 URL 重定向用户，使用 301 响应代码和 `Location` 响应头。
