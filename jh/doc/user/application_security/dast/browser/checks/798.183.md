## 描述

响应正文包含匹配 Yandex Cloud IAM API 密钥 v1 模式的内容。
暴露该令牌可能使攻击者获得此令牌授予的所有资源的访问权限。

## 修复

有关处理涉及泄露密钥的安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。
