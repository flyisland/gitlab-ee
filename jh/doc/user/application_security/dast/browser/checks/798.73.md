## 描述

响应正文中包含与 Mailgun 公共验证密钥模式匹配的内容。这些密钥已被弃用，您应改用 v4 验证服务。获得此密钥的恶意人员可利用其验证电子邮件地址。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中关于 [凭证暴露于互联网的内容](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换您的公共验证密钥：

- 登录您的 Mailgun 账户并访问仪表盘，地址为 <https://app.mailgun.com/>
- 在右上角，选择您的账户头像，然后选择 **API Security**
- 在 **Verification public key** 部分，选择右侧的旋转箭头图标
- 出现提示时，在 **Reset public verification key** 对话框中，选择 **Reset Key**

更多信息，请参阅 [Mailgun 关于 API 密钥的文档](https://mailchimp.com/help/about-api-keys)。
