<a id="description"></a>

## 描述

响应正文包含与识别出的 X 机密访问令牌模式匹配的内容。访问密钥是用于验证 OAuth 1.0a API 请求的用户特定凭据，用于指定代表哪个 X 账户发起请求。获得此令牌的恶意行为者可以冒充用户发起请求。
暴露此值可能使攻击者获取该令牌授予的所有资源的访问权限。

## 修复

有关处理密钥泄露安全事件的一般指导，请参见极狐GitLab 文档：[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
