<a id="description"></a>

## 描述

响应正文中包含与 X 密钥访问令牌模式匹配的内容。访问密钥是用于对 OAuth 1.0a API 请求进行身份验证的用户专属凭据。它们指定了请求所代表的 X 账号。能够访问此令牌的恶意行为者可代表用户伪造请求。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
