<a id="description"></a>

## 描述

响应正文中包含与 Slack 应用级令牌模式匹配的内容。应用级令牌用于 Slack 应用，但仅适用于特定 API，这些 API 在所有安装了该应用的组织中都与该应用相关。

可以分配三个权限范围级别：

- `connections:write:` 通过 WebSocket 路由应用的交互和事件负载
- `authorizations:read:` 查看应用在已安装团队中的授权信息
- `app_configurations:write:` 配置您的应用

获得此令牌的恶意行为者会被授予上述一项或多项权限，从而可以针对特定应用访问 API。

暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 Slack 应用级令牌：

- 登录 Slack 并访问 <https://api.slack.com/apps>
- 找到具有所识别令牌的应用，然后选择其名称
- 在左侧菜单中，选择“基本信息”
- 向下滚动到“应用级令牌”部分，然后选择所识别令牌的令牌名称
- 在令牌对话框中，选择“撤销”
- 出现提示时，在“Are you sure?”对话框中选择“是的，我确定”
