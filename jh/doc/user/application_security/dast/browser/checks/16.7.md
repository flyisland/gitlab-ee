<a id="description"></a>

## 描述

`Strict-Transport-Security` 头部缺失或无效。`Strict-Transport-Security` 头部允许网站运营商强制通过 TLS 连接进行通信。通过启用此头部，网站可以保护其用户免受各种形式的网络窃听或拦截攻击。虽然大多数浏览器会阻止混合内容（从 HTTPS 站点导航时从 HTTP 加载资源），但此头部还确保所有资源请求仅通过安全传输发起。

<a id="remediation"></a>

## 修复

`Strict-Transport-Security` 头部仅适用三个指令。

1. `max-age`：此必需指令指定收到响应后，应在多长时间内（以秒为单位）仅通过安全传输进行通信。
1. `includeSubDomains`：此可选、无值的指令表示该策略适用于此主机以及此主机域下的任何子域名。
1. `preload`：虽然不属于规范的一部分，但设置此可选值允许主流浏览器组织将此站点添加到浏览器的预加载 HTTPS 站点集中。这需要网站运营商进一步操作，将其域名提交到浏览器的 HSTS 预加载列表。有关更多信息，请参阅 [hstspreload.org](https://hstspreload.org/)。

无效的指令，或者 `Strict-Transport-Security` 头部出现多次（如果值不同），均被视为无效。

在将此安全配置添加到您的网站之前，建议您查看 hstspreload.org 的[部署建议](https://hstspreload.org/#deployment-recommendations)。
