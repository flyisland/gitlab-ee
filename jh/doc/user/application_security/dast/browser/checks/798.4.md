## 描述

响应正文中包含与 age 加密密钥模式匹配的内容。Age 是一款现代且安全的文件加密工具、格式和 Go 库。它具有简短明确的密钥、无需配置选项，并具备 UNIX 风格的可组合性。这些密钥通常用于加密敏感文件。能够访问此密钥的恶意行为者可解密任何使用该密钥加密的文件或消息。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要生成新的 age 密钥，请运行以下命令：```console age-keygen -o new_key.age``` 请考虑使用口令保护身份文件。如果此密钥打算用于自动化系统，则可能无法这样做：```console age-keygen | age -p > new_key.age```
