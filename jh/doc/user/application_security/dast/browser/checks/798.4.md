<a id="description"></a>

## 描述

检测到响应正文中的内容与 Age 加密密钥的模式匹配。Age 是一个现代、安全的文件加密工具、格式和 Go 库。它采用简短明确的密钥，无需配置选项，并具备 UNIX 风格的可组合性。这些密钥通常用于加密敏感文件。获得此密钥的恶意行为者可以解密使用它加密的任何文件或消息。
泄露此值可能会让攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理密钥泄露安全事件的一般指导，请参阅 极狐GitLab 文档中的[凭证泄露至互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。要生成新的 Age 密钥，请运行以下命令：```console age-keygen -o new_key.age``` 考虑使用密码短语保护身份文件。如果此密钥用于自动化系统，这可能无法实现：```console age-keygen | age -p > new_key.age```
