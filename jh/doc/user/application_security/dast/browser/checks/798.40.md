## 描述

响应正文包含与 Fastly API 用户或自动化令牌模式匹配的内容。Fastly API 令牌根据配置可授予读写或只读访问权限。
泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

## 修复措施

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 API 令牌：

- 登录 Fastly Web 界面：<https://manage.fastly.com/account>
- 进入左侧菜单中的“Account”，然后选择“API Tokens”
- 找到要删除的令牌，并记录其作用域的任何详细信息。
- 准备好后，选择垃圾桶图标
- 出现提示时选择“Delete”

更多信息，请参阅[Fastly 关于使用 API 令牌的文档](https://docs.fastly.com/en/guides/using-api-tokens)。
