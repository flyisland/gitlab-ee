<a id="description"></a>

## 描述

响应正文中包含与 Fastly API 用户令牌或自动化令牌模式匹配的内容。Fastly API 令牌根据其配置方式，可授予读写或只读访问权限。泄露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 API 令牌：

- 登录 Fastly Web 界面：<https://manage.fastly.com/account>
- 在左侧菜单中依次转到“Account”和“API Tokens”
- 找到要删除的令牌，并记下其作用域的相关信息。
- 准备就绪后，选择垃圾桶图标
- 出现提示时，选择“Delete”

有关更多信息，请参阅 [Fastly 关于使用 API 令牌的文档](https://docs.fastly.com/en/guides/using-api-tokens)。
