<a id="description"></a>

## 描述

跨站脚本攻击 (XSS) 是一种利用 Web 应用或系统将用户输入当作标记或脚本代码处理的攻击。根据使用数据的具体上下文对其进行编码非常重要。至少有以下六种上下文类型：

- HTML 标签内部：`<div>上下文 1</div>`
- 属性内部：```<div class="上下文 2"></div>```
- 事件属性内部：```<button onclick="上下文 3">按钮</button>```
- 脚本块内部：```<script>var x = "上下文 4"</script>```
- 不安全的 HTML 元素赋值：```element.innerHTML = "上下文 5"```
- URL 内部：```<iframe src="上下文 6"></iframe><a href="上下文 6">链接</a>```

脚本块本身可以通过多种方式进行编码。如果用户输入必须写在脚本标签之外，请谨慎操作。

<a id="remediation"></a>

## 修复措施

应用中展示的用户输入必须经过编码、清理或验证，以避免其被视作 HTML 或作为 JavaScript 代码执行。注意不要混用服务端模板和客户端模板，因为服务端不会对 `{{ 7*7 }}` 这样的文本进行编码，而客户端可能会执行相关功能。

在将用户输入存入数据存储之前不要对其进行编码。数据必须依据其输出上下文进行编码。强制展示系统来处理编码会更加安全。

请考虑使用框架内置的功能来自动对用户输入进行编码。如果无法自动编码，请务必使用正确的输出编码。以下建议仅为尽力而为，可能并非适用于所有场景：

- 在 HTML 标签内部（不包括 `script` 标签）对以下内容进行编码：
  - `<` 替换为 `&lt;`
  - `>` 替换为 `&gt;`
  - `'` 替换为 `&apos;`
  - `"` 替换为 `&quot;`
  - `=` 替换为 `&#61;`
- 在属性内部（不包括事件属性）对以下内容进行编码：
  - `<` 替换为 `&lt;`
  - `>` 替换为 `&gt;`
  - `'` 替换为 `&apos;`
  - `"` 替换为 `&quot;`
  - `=` 替换为 `&#61;`
- 在事件属性、脚本块和不安全的 HTML 赋值中对以下内容进行编码：
  - 字面制表符 (`\t`) 替换为 `\\t`
  - 字面换行符 (`\n`) 替换为 `\\n`
  - 字面垂直制表符 (`\v`) 替换为 `\u000b`
  - 字面换页符 (`\f`) 替换为 `\\f`
  - 字面回车符 (`\r`) 替换为 `\\r`
  - 字面等号 (`=`) 替换为 `\u0061`
  - 字面反引号 (`` \ ``) 替换为 `\u0060`
  - 字面双引号 (`"`) 替换为 `\u0022`
  - 字面与符号 (`&`) 替换为 `\u0026`
  - 字面单引号 (`'`) 替换为 `\u0027`
  - 字面加号 (`+`) 替换为 `\u002b`
  - 字面正斜杠 (`/`) 替换为 `\/`
  - 字面小于号 (`<`) 替换为 `\u003c`
  - 字面大于号 (`>`) 替换为 `\u003e`
  - 字面左括号 (`(`) 替换为 `\u0028`
  - 字面右括号 (`)`) 替换为 `\u0029`
  - 字面左方括号 (`[`) 替换为 `\u005b`
  - 字面右方括号 (`]`) 替换为 `\u005d`
  - 字面左花括号 (`{`) 替换为 `\u007b`
  - 字面右花括号 (`}`) 替换为 `\u007d`
  - 字面反斜杠 (`\`) 替换为 `\\`

  此列表并不详尽。根据上下文，您可能需要对其他字符进行编码。
- 在 URL 内部：
  - 绝不允许用户输入直接出现在 URL 中。攻击者可能会注入 `javascript:...` 代码或恶意链接。
