<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab Runner 认证令牌模式匹配的内容。这些令牌允许用户以 runner 身份向所选项目注册或进行认证。能够访问此令牌的恶意行为者可以将自定义 runner 添加到流水线中，如果该 runner 被使用，还可能危及代码仓库。泄露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 runner 认证令牌，需要移除并重新创建该 runner：

- 登录您的极狐GitLab 账号，并访问创建该 runner 注册令牌的项目
- 在左侧菜单中，选择“设置”
- 在“设置”选项中，选择“CI/CD”
- 在“Runners”部分中，找到使用所识别令牌的 runner（如果不确定，可以检查 runner 的 `config.toml`）
- 选择“移除 runner”
- 出现提示时，选择“移除”

有关更多信息，请参阅 [极狐GitLab 关于注册 runner 的文档](https://gitlab.cn/docs/runner/register/)。
