<a id="description"></a>

## 描述

检测到响应正文包含匹配 极狐GitLab Runner 认证令牌 格式的内容。这些令牌允许用户作为 runner 注册或认证所选项目。能够访问此令牌的恶意行为者可以将自定义 runner 添加到流水线，并可能在使用此 runner 时危及仓库。暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

处理有关密钥泄露的安全事件的通用指导，请参阅极狐GitLab 文档中关于[互联网凭据暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)部分。

要撤销 runner 认证令牌，需要移除并重新创建 runner：

- 登录到您的极狐GitLab 帐户，并访问创建 runner 注册令牌的项目
- 在左侧菜单中，选择“设置”
- 在“设置”选项中，选择“CI/CD”
- 在“Runners”部分，找到具有识别令牌的 runner（如果无法确定，可以检查 runner 的 `config.toml` 文件）
- 选择“删除 runner”
- 出现提示时，选择“删除”

有关更多信息，请参阅 [极狐GitLab 文档中关于注册 runners 的部分](https://gitlab.cn/docs/runner/register/)。
