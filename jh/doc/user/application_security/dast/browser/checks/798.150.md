## 描述

响应正文中包含了与极狐GitLab 部署令牌模式匹配的内容。部署令牌可以独立于用户账户，为部署任务启用身份验证。通过部署令牌，自动化任务可以：
- 克隆 Git 仓库
- 从极狐GitLab 容器镜像仓库拉取和推送
- 从极狐GitLab 软件包仓库拉取和推送
获得此令牌的恶意行为者可以访问 Git 仓库或破坏已发布的软件包或容器。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

有关更多信息，请参阅[极狐GitLab 关于撤销部署令牌的文档](../../../../project/deploy_tokens/_index.md)。
