<a id="description"></a>

## 描述

响应体中的内容与已弃用的极狐GitLab Runner 注册令牌的模式匹配。这些令牌允许用户向所选项目注册一个 runner。能够访问此令牌的恶意行为者可以添加自定义 runner 到流水线，并可能在使用 runner 时危及代码仓。
暴露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换 runner 注册令牌：

- 登录你的极狐GitLab 账户，并访问创建 runner 注册令牌的项目
- 在左侧菜单中，选择 **设置**
- 在 **设置** 选项下，选择 **CI/CD**
- 在 **Runner** 部分下，选择 **新建项目 runner** 旁边的烤肉串菜单（垂直省略号）
- 从下拉列表中选择 **重置注册令牌**
- 在弹出的 **重置注册令牌** 对话框中选择 **重置令牌**

更多信息，请参阅[极狐GitLab 文档中关于改用 runner 认证令牌的内容](https://gitlab.cn/docs/runner/register/#register-with-a-runner-authentication-token)。
