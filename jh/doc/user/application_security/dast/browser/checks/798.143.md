<a id="description"></a>

## 描述

响应正文中包含与已弃用的极狐GitLab Runner 注册令牌模式匹配的内容。这些令牌允许用户将 Runner 注册到所选项目。能够访问此令牌的恶意行为者可以将自定义 Runner 添加到流水线，如果该 Runner 被使用，还可能危及代码仓库。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换 Runner 注册令牌：

- 登录您的极狐GitLab 账号，并访问创建该 Runner 注册令牌的项目
- 在左侧菜单中，选择“设置”
- 在“设置”选项下，选择“CI/CD”
- 在“Runners”部分，选择“新建项目 Runner”旁边的 kebab 菜单（垂直省略号）
- 从下拉列表中选择“重置注册令牌”
- 出现提示时，在“重置注册令牌”对话框中选择“重置令牌”

有关更多信息，请参阅 [极狐GitLab 文档中关于改用 Runner 认证令牌的说明](https://gitlab.cn/docs/runner/register/#register-with-a-runner-authentication-token)。
