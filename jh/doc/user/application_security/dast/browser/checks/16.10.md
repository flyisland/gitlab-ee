## 内容安全策略违规

<a id="description"></a>

## 描述

在目标站点上识别到一个 `Content-Security-Policy`（CSP），当尝试在浏览器中加载页面时，该策略报告了违规行为。这可能会导致您的用户在尝试访问页面时遇到中断。

<a id="remediation"></a>

## 修复措施

检查违规行为，以确定是否需要采取任何措施。
