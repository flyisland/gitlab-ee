## 描述

在目标站点上检测到 `Content-Security-Policy`（CSP），当尝试在浏览器中加载该页面时会报告违规。这可能会在您的用户尝试访问该页面时造成干扰。

<a id="remediation"></a>

## 修复

查看这些违规，以确定是否需要采取任何措施。
