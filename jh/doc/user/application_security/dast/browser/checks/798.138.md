<a id="description"></a>

## 描述

检测到响应正文中包含与 GCP OAuth 客户端密钥模式匹配的内容。客户端密钥用于允许用户登录您的应用程序。根据请求的范围，拥有该密钥的恶意行为者可以冒充服务来访问用户信息。暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 OAuth 客户端密钥：

- 登录您的 GCP 账户并转到 <https://console.cloud.google.com/apis/credentials>
- 在“OAuth 2.0 客户端 ID”表格的“名称”列下，选择已识别密钥的客户端名称
- 在“客户端密钥”部分，您必须首先添加一个新密钥，选择“添加密钥”
- 对于已识别的密钥，选择“禁用”
- 出现提示时，在“禁用此密钥？”对话框中选择“禁用”
- 您现在可以选择垃圾桶图标来删除已禁用的密钥

更多信息，请参阅 [Google 关于设置 OAuth 2.0 的身份验证文档](https://support.google.com/cloud/answer/6158849?hl=en)
