<a id="description"></a>

## 描述

在响应正文中识别到与 Contentful 预览 API 令牌模式相匹配的内容。预览 API 令牌的行为和参数与内容交付 API (CDA) 相同，但会交付条目和资产的最新草稿。内容预览 API 用于显示条目的最新版本。能够访问此令牌的恶意行为者可查看已发布和未发布的条目。更多信息，请参阅[预览 API 文档](https://www.contentful.com/developers/docs/references/content-preview-api/)。
泄露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方法

有关处理泄露密钥安全事件的一般性指导，请参阅 GitLab 关于[凭据泄露至互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。

要撤销预览 API 令牌：

- 登录并访问 <https://app.contentful.com/>
- 选择右上角的齿轮图标，然后选择“API 密钥”
- 找到被检测到的 API 密钥，在 API 密钥表中选择其名称
- 选择右上角的“删除”
- 当出现提示时，选择“删除”。请注意，此操作也会删除交付 API 令牌。

生成一套新的 API 密钥是必需的。

更多信息，请参阅开发者[关于身份验证的文档](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api)。
