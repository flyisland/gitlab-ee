## 描述

响应正文中包含与 Contentful 预览 API 令牌模式匹配的内容。预览 API 令牌的行为和参数与内容交付 API（CDA）相同，但会提供条目和资源的最新草稿。内容预览 API 用于显示条目的最新版本。获得此令牌访问权限的恶意行为者可以查看已发布和未发布的条目。有关更多信息，请参阅[预览 API 文档](https://www.contentful.com/developers/docs/references/content-preview-api/)。暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销预览 API 令牌：

- 登录并访问 <https://app.contentful.com/>
- 选择右上角的齿轮图标，然后选择“API 密钥”
- 找到被检测到的 API 密钥，并在 API 密钥表中选择其名称
- 选择右上角的“删除”
- 出现提示时，选择“删除”。请注意，这也会删除交付 API 令牌。

需要生成一组新的 API 密钥。

有关更多信息，请参阅开发者[身份验证文档](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api)。
