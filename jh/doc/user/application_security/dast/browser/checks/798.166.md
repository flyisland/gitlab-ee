## 描述

响应正文包含与 PGP 私钥模式匹配的内容。PGP 私钥用于加密和解密消息。能够访问此密钥的恶意攻击者可以加密和解密所有过去和未来的消息。请注意，使用此密钥加密的过去消息应被视为已泄露，新消息不能被视为可信。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复措施

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档：[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。PGP 密钥无法轮换，必须创建新密钥。更多信息，请参阅 [GnuPG 的密钥生成文档](https://gnupg.org/gph/en/manual.html#AEN26)
