## 描述

在请求 URL 和 cookie 值中都发现了一个会话 ID。会话 ID 不应在 GET 请求中发送，因为它们可能被代理系统捕获，存储在浏览器历史记录中，或者存储在日志文件中。如果攻击者获取了会话 ID，他们可能能够访问目标账户。

## 修复方法

由于请求头很少被第三方系统记录或捕获，请确保会话 ID 值仅通过 cookie 发送（通过 `Set-Cookie` 响应头分配），永远不要通过请求 URL 发送。
