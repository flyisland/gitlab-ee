<a id="description"></a>

## 描述

在请求 URL 以及 cookie 值中发现了会话 ID。会话 ID 不应通过 GET 请求发送，因为它们可能会被代理系统捕获、存储在浏览器历史记录中，或存储在日志文件中。如果攻击者获取了会话 ID，他们就有可能获得对目标账户的访问权限。

<a id="remediation"></a>

## 修复

由于请求头很少被第三方系统记录或捕获，请确保会话 ID 值仅通过 cookie（由 `Set-Cookie` 响应头设置）发送，绝不通过请求 URL 发送。
