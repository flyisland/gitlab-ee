<a id="description"></a>

## 描述

`X-Content-Type-Options` 标头设置为 `nosniff` 可确保用户代理不会尝试猜测接收到的数据格式。用户代理（如浏览器）通常会通过名为 MIME 类型嗅探的过程来尝试猜测所请求的资源类型。

如果不发送此标头，浏览器可能会错误解析数据，导致 MIME 混淆攻击。如果攻击者能够上传可通过浏览器访问的文件，他们可能会上传可被解释为 HTML 的文件并执行跨站脚本 (XSS) 攻击。

<a id="remediation"></a>

## 修复建议

我们建议在服务器范围内设置 `X-Content-Type-Options: nosniff` 标头和值。这可以确保任何错误地缺少 `Content-Type` 值的资源不会被错误解析。
