<a id="description"></a>

## 描述

值为 `nosniff`的 `X-Content-Type-Options` 响应头可确保用户代理不会尝试猜测所接收数据的格式。浏览器等用户代理通常会通过称为 MIME 类型嗅探的过程来猜测所请求的资源类型。

如果不发送此响应头，浏览器可能会误解数据，从而导致 MIME 混淆攻击。如果攻击者能够上传可通过浏览器访问的文件，他们就可以上传可被解释为 HTML 的文件并执行跨站脚本（XSS）攻击。

<a id="remediation"></a>

## 修复

建议在服务器范围内设置 `X-Content-Type-Options: nosniff` 响应头及其值。这可确保任何因疏忽而缺少 `Content-Type` 值的资源不会被误解。
