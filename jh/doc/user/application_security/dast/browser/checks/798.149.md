## 描述

在响应正文中发现了匹配极狐GitLab 入站邮件令牌模式的内容。您的入站邮件令牌在您通过邮件创建新议题时用于身份验证，并包含在您个人项目特定的电子邮件地址中。它无法用于访问任何其他数据。能够获取此令牌的恶意行为者可以以您的身份创建议题。
暴露此值可能允许攻击者获取此令牌所授予的所有资源的访问权限。

## 修复措施

有关处理泄露密钥相关安全事件的一般指导，请参阅有关[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的极狐GitLab 文档。

要重新生成 feed 令牌：

- 登录您的极狐GitLab 账户，访问[用户设置](../../../../profile/_index.md#access-your-user-settings) 左侧菜单，选择 **访问令牌**
- 在 **入站邮件令牌** 部分，选择 **重置此令牌** 链接
- 当出现提示时，选择 **确认**

更多信息请参阅[有关 feed 令牌的极狐GitLab 文档](../../../../../security/tokens/_index.md#feed-token)。
