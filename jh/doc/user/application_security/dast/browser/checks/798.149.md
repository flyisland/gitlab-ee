<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab 接收邮件令牌模式匹配的内容。您的接收邮件令牌在您通过电子邮件创建议题和合并请求时用于身份验证，并包含在您的个人项目专属电子邮件地址中。获得此令牌的恶意攻击者可以冒充您创建议题和合并请求。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成 feed 令牌：

- 登录您的极狐GitLab 账号，访问[用户设置](../../../../profile/_index.md#access-your-user-settings)左侧菜单，选择“访问令牌”
- 在“接收电子邮件令牌”部分，选择“重置此令牌”链接
- 出现提示时选择“确定”

更多信息，请参阅[极狐GitLab 关于 feed 令牌的文档](../../../../../security/tokens/_index.md#feed-token)。
