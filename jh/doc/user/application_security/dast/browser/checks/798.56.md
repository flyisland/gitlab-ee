<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab 个人访问令牌模式匹配的内容。个人访问令牌可用于以创建该令牌的用户身份访问极狐GitLab 服务。在大多数情况下，这些令牌会被授予对所有代码仓库的读写访问权限。能够获取此令牌的恶意行为者可代表该用户，以该令牌被授予的权限执行相关功能。暴露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要重新生成个人访问令牌：

- 登录您的极狐GitLab 账号，访问左侧菜单中的[用户设置](../../../../profile/_index.md#access-your-user-settings)，选择“访问令牌”
- 在“活跃的个人访问令牌”表格中找到被识别出的访问令牌
- 记下分配给该令牌的权限
- 在该令牌的“操作”列中选择垃圾桶图标
- 出现提示时，选择“撤销”
