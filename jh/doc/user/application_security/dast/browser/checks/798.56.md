<a id="description"></a>

## 描述

响应体包含与极狐GitLab 个人访问令牌模式匹配的内容。个人访问令牌可用于以创建它们的用户身份访问极狐GitLab 服务。在大多数情况下，这些令牌被授予对所有仓库的读写访问权限。获得此令牌的恶意行为者可以以拥有该令牌权限的用户身份执行功能。
暴露此值可能允许攻击者获取此令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方案

有关处理泄露密钥的安全事件的通用指南，请参阅极狐GitLab 文档中的 [凭据暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

重新生成个人访问令牌：

- 登录您的极狐GitLab 帐户，并访问左侧菜单中的 [用户设置](../../../../profile/_index.md#access-your-user-settings)，选择“访问令牌”
- 在“活跃的个人访问令牌”表格中找到被识别的访问令牌
- 记下分配给此令牌的权限
- 选择令牌“操作”列中的垃圾桶图标
- 出现提示时，选择“撤销”
