## 描述

响应正文中包含与 Discord 客户端 ID 模式匹配的内容已识别。客户端 ID 用于 OAuth 应用程序，并与客户端密钥结合使用。该值本身不授予任何访问权限，必须与客户端密钥值一同使用。
公开此值可能允许攻击者获取该令牌授予的所有资源。

## 修复

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。您无法撤销 Discord 客户端 ID。相反，您必须生成一个全新的 Discord 应用程序。

更多信息，请参阅 [Discord 的 OAuth 文档](https://discord.com/developers/docs/topics/oauth2)。
