## 描述

检测到响应正文包含与 Asana 客户端 ID 模式匹配的内容。此 ID 与客户端密钥结合使用。能够访问此 ID 的恶意操作者如果同时拥有客户端密钥，可以冒充客户端应用程序。暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复

Asana 客户端 ID 无法轮换，只能创建一个新的 OAuth 客户端应用程序以获得新的客户端 ID。有关更多信息，请[参阅其配置 OAuth 的文档](https://developers.asana.com/docs/oauth)
