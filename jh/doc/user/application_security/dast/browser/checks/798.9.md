## 描述

响应正文中包含与 Asana 客户端 ID 模式匹配的内容。此 ID 与客户端密钥配合使用。如果恶意行为者能够访问此 ID，并且同时能够访问客户端密钥，就可以冒充客户端应用程序。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

Asana 客户端 ID 无法轮换，只能创建新的 OAuth 客户端应用程序来获取新的客户端 ID。有关更多信息，请[参阅其关于配置 OAuth 的文档](https://developers.asana.com/docs/oauth)
