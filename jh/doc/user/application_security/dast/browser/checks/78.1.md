<a id="description"></a>

## 描述

可以在目标应用程序服务器上执行任意操作系统命令。操作系统命令注入是一个严重漏洞，可能导致整个系统受损。

<a id="remediation"></a>

## 修复

绝不应使用用户输入来构建执行操作系统命令的函数的命令或命令参数。这包括用户上传或下载所提供的文件名。

确保您的应用程序不会：

- 使用用户提供的信息作为要执行的进程名称。
- 在不转义 shell 元字符的操作系统命令执行函数中使用用户提供的信息。
- 在操作系统命令的参数中使用用户提供的信息。

应用程序应使用硬编码的参数集传递给操作系统命令。如果需要将文件名传递给这些函数，建议改用文件名的哈希或其他唯一标识符。强烈建议使用实现相同功能的本机库代替使用操作系统命令，因为使用第三方命令可能存在未知攻击风险。
