<a id="description"></a>

## 描述

攻击者可以在目标应用服务器上执行任意操作系统命令。操作系统命令注入是一种严重漏洞，可能导致系统被完全攻陷。

<a id="remediation"></a>

## 修复

在构造命令或传递给执行操作系统命令的函数的命令参数时，绝不应使用用户输入。这包括用户上传或下载所提供的文件名。

请确保您的应用不会：

- 在执行所用的进程名称中使用用户提供的信息。
- 在不转义 shell 元字符的操作系统命令执行函数中使用用户提供的信息。
- 在操作系统命令的参数中使用用户提供的信息。

应用应使用一组硬编码的参数传递给操作系统命令。如果要将文件名传递给这些函数，建议改用文件名的哈希值或其他唯一标识符。由于针对第三方命令的未知攻击风险，强烈建议改用实现相同功能的本机库，而不是使用操作系统命令。
