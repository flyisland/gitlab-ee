<a id="description"></a>

## 描述

该服务器易受 PHP 远程文件包含（RFI）攻击，攻击者可借此加载远程文件，并使其在服务器端作为 PHP 脚本执行。当不受信任的用户输入未经适当验证就被直接用于脚本包含时，就会出现此漏洞。攻击者可利用此漏洞包含并执行任意远程文件，从而可能破坏系统的完整性和机密性。

<a id="remediation"></a>

## 修复

避免在 `include` 和 `require` 语句中直接使用用户可控的数据，而应考虑采用允许名单的方式来动态包含脚本。

如有可能，还应考虑在服务器的 PHP 配置中设置 `allow_url_include=Off`，以确保 URL 无法用于 `include` 和 `require` 语句。
