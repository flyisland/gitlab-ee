<a id="description"></a>

## 描述

服务器存在 PHP 远程文件包含（RFI）漏洞，攻击者可利用此漏洞加载远程文件并在服务器端将其作为 PHP 脚本执行。当不受信任的用户输入未经适当验证便直接用于脚本包含时，就会产生此漏洞。攻击者可以利用此漏洞包含并执行任意远程文件，从而可能危及系统的完整性和机密性。

<a id="remediation"></a>

## 修复方案

避免在 `include` 和 `require` 语句中直接使用用户控制的数据，而是考虑采用允许清单的方式来动态包含脚本。

如果可能，还可以考虑在服务器的 PHP 配置中设置 `allow_url_include=Off`，以确保 URL 不能用于 `include` 和 `require` 语句。
