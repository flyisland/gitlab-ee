<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab Kubernetes Agent 令牌模式匹配的内容。Kubernetes 访问令牌用于向 Kubernetes 集群认证极狐GitLab Kubernetes Agent。能够访问此令牌的恶意行为者可以访问 Agent 配置项目中的源代码、访问极狐GitLab 实例上任何公共项目中的源代码，甚至在非常特定的条件下获取 Kubernetes 清单。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。更多信息请参阅 [极狐GitLab 文档中关于轮换 Kubernetes Agent 令牌](../../../../clusters/agent/work_with_agent.md#reset-the-agent-token)的内容。
