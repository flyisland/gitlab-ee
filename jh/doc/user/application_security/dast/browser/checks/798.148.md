<a id="description"></a>

## 描述

响应正文包含与极狐GitLab Kubernetes 代理令牌模式匹配的内容。Kubernetes 访问令牌用于对极狐GitLab Kubernetes 代理与 Kubernetes 集群进行身份验证。获得此令牌的恶意行为者可以访问代理配置项目中的源代码、访问极狐GitLab 实例上任何公共项目中的源代码，甚至在某些特定条件下获取 Kubernetes 清单。
泄漏此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的[互联网凭据暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。更多信息请参阅[极狐GitLab 关于轮换 Kubernetes 代理令牌的文档](../../../../clusters/agent/work_with_agent.md#reset-the-agent-token)。
