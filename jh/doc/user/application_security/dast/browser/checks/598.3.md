<a id="description"></a>

## 描述

在请求 URL 中发现了授权标头值。这些标头通常包含用户名和密码或 JWT 令牌。这些值绝不应在 GET 请求中发送，因为它们可能被代理系统捕获、存储在浏览器历史记录中，或保存在日志文件里。如果攻击者获得了这些日志或日志系统的访问权限，他们就能获取目标账户的访问权限。

<a id="remediation"></a>

## 修复

授权标头详细信息绝不应在 GET 请求中发送。在传输敏感信息（如 JWT 令牌）时，应始终使用 `POST` 请求或标头来传输敏感数据。
