## Description

在响应正文中发现与 Pulumi API 令牌模式匹配的内容。个人访问令牌映射到用户的权限。获得此令牌的恶意行为者可以以令牌所有者的身份删除堆栈、标签、更新和 webhook。泄露此值可能使攻击者能够访问此令牌授予的所有资源。

## Remediation

关于处理泄露密钥安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。要撤销 API 令牌：

- 登录你的 Pulumi 账户并访问 <https://app.pulumi.com/>
- 在右上角，选择个人头像并选择 **Personal access tokens**
- 找到已识别的令牌，然后在密钥的 **Actions** 列中选择省略号，接着选择 **Delete token**
- 出现提示时，在 **Delete token** 对话框中再次选择 **Delete token**

更多信息，请参阅 [Pulumi 关于个人访问令牌的文档](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/#personal-access-tokens)。
