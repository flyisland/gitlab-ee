<a id="description"></a>

## 描述

响应正文中包含与 Pulumi API 令牌模式匹配的内容。个人访问令牌映射到用户的权限。能够访问此令牌的恶意行为者可以以访问令牌所有者的身份删除堆栈、标签、更新和 webhook。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要撤销 API 令牌：

- 登录您的 Pulumi 账号并访问 <https://app.pulumi.com/>
- 在右上角，选择个人资料图片并选择“Personal access tokens”
- 找到识别出的令牌，在密钥的“Actions”列中选择省略号，然后选择“Delete token”
- 出现提示时，在“Delete token”对话框中选择“Delete token”

有关更多信息，请参阅 [Pulumi 关于个人访问令牌的文档](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/#personal-access-tokens)。
