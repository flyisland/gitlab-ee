<a id="description"></a>

## 描述

响应正文中包含与 Stripe 正式环境受限密钥模式匹配的内容。受限密钥通过仅允许对特定 API 资源进行读取或写入访问，提供了更高的安全性。获得该密钥的恶意行为者会受到为该密钥定义的范围限制。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换您的 Stripe 正式环境受限密钥：

- 登录您的 Stripe 账号并访问 <https://dashboard.stripe.com/apikeys>
- 确保已禁用“测试模式”
- 在“受限密钥”部分，找到被识别出的密钥，然后选择右侧的省略号
- 选择“轮换密钥...”
- 在“轮换 API 密钥”对话框中，选择一个到期日期，例如“现在”
- 选择“轮换 API 密钥”

有关更多信息，请参阅 [Stripe 关于轮换 API 密钥的文档](https://docs.stripe.com/keys#rolling-keys)。
