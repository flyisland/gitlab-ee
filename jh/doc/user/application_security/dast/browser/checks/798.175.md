<a id="description"></a>

## 描述

在响应正文中发现了匹配 Stripe 实时受限密钥模式的内容。受限密钥通过仅允许对特定 API 资源进行读取或写入访问来提供更高的安全性。拥有此密钥的恶意行为者受限于为该密钥定义的范围。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换您的 Stripe 实时受限密钥：

- 登录您的 Stripe 账户并访问 <https://dashboard.stripe.com/apikeys>
- 确保“测试模式”已禁用
- 在“受限密钥”部分，找到被识别的密钥，然后选择右侧的省略号
- 选择“轮换密钥...”
- 在“轮换 API 密钥”对话框中，选择过期日期，例如“现在”
- 选择“轮换 API 密钥”

有关更多信息，请参阅 [Stripe 关于轮换 API 密钥的文档](https://docs.stripe.com/keys#rolling-keys)。
