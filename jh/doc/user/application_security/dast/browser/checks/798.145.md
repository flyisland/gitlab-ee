<a id="description"></a>

## 描述

响应正文包含与极狐GitLab Feed 令牌模式匹配的内容。
暴露该值可能允许攻击者获取该令牌授予的所有资源。

<a id="remediation"></a>

## 修复措施

有关处理密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成 Feed 令牌：

- 登录你的极狐GitLab 账号，进入左侧菜单的[用户设置](../../../../profile/_index.md#access-your-user-settings)，选择“访问令牌”
- 在“Feed 令牌”部分，选择“重置此令牌”链接
- 当提示时选择“确定”

有关更多信息，请参阅[极狐GitLab 关于 Feed 令牌的文档](../../../../../security/tokens/_index.md#feed-token)。
