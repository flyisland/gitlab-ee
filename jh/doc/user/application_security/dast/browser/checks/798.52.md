## 描述

响应体包含与 GitHub 个人访问令牌（经典版）模式匹配的内容。个人访问令牌可用于以创建者身份访问 GitHub 服务。在大多数情况下，这些令牌被授予对所有仓库的读写权限。拥有此令牌的恶意行为者可以代表用户执行令牌所赋予权限的功能。暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成个人访问令牌：

- 登录您的 GitHub 帐户并访问 <https://github.com/settings/tokens>
- 找到已识别的令牌并选择名称
- 在页面顶部选择“重新生成令牌”，或者，您可以在页面底部选择“删除此令牌”并创建一个新令牌。在执行此操作之前，请务必记下设置的范围和权限。

有关更多信息，请参阅 [GitHub 关于个人访问令牌的文档](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)。
