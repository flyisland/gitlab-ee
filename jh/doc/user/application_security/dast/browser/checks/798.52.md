## 描述

响应正文中包含与 GitHub 个人访问令牌（经典版）模式匹配的内容。个人访问令牌可用于以创建该令牌的用户身份访问 GitHub 服务。在大多数情况下，这些令牌会被授予对所有代码仓库的读写访问权限。能够访问此令牌的恶意行为者可以以该用户身份、按照该令牌被授予的权限执行操作。暴露此值可能使攻击者能够访问该令牌所授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要重新生成个人访问令牌：

- 登录您的 GitHub 账号并访问 <https://github.com/settings/tokens>
- 找到被识别出的令牌并选择其名称
- 在页面顶部选择“重新生成令牌”。或者，您也可以在页面底部选择“删除此令牌”并创建一个新令牌。执行此操作前，请务必记下所设置的作用域和权限。

有关更多信息，请参阅 [GitHub 关于个人访问令牌的文档](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)。
