<a id="description"></a>

## 描述

响应正文中包含与 Anthropic API 密钥模式匹配的内容。Anthropic 密钥用于访问生成式 AI 服务。恶意行为者可能利用这些密钥向您的账户累积高额费用。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要修复泄露的 Anthropic 密钥，您应将其从组织的 API 密钥列表中删除。

- 登录您的 Anthropic 账户
- 选择您的个人资料图标，然后选择“API Keys”，或通过 Settings 标签页进入“API settings”
- 找到泄露的 API 密钥，选择要删除的密钥旁边的三点菜单（三个水平圆点）
- 选择“Delete API Key”
- 注意：删除 API 密钥是永久性操作，无法撤销
- 选择“Create Key”生成新密钥，并为其指定一个描述性名称

有关更多信息，请参阅 Anthropic 网站：<https://support.anthropic.com/en/articles/8384961-what-should-i-do-if-i-suspect-my-api-key-has-been-compromised>。
