## 描述

检测到响应正文中包含与 API 密钥模式匹配的内容。API 密钥用于访问生成式 AI 服务。恶意攻击者可能利用这些密钥产生超额费用。
泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

## 修复

有关处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
