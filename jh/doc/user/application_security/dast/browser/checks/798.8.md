## 描述

响应体包含与阿里巴巴密钥模式匹配的内容。泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
