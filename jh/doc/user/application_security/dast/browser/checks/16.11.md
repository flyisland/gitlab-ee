<a id="description"></a>

## 描述

在目标 Web 服务器上发现调试用的 TRACE 方法已启用。此 HTTP 方法会在响应中将 HTTP 请求数据回显给用户。在某些情况下，这些信息可能包含由中间代理添加的敏感数据。

<a id="remediation"></a>

## 修复

TRACE HTTP 方法仅用于调试，不应在生产站点上启用。

对于基于 Apache 的 Web 服务器，请确保移除 `TraceEnable` 指令，或将其设置为 `off`。

对于 Microsoft 服务器，请删除以下注册表项中名为 "EnableTraceMethod" 的注册表参数：

- `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\W3SVC\Parameters`

对于所有其他服务器类型，请查阅您的产品文档，了解如何禁用 TRACE 方法。
