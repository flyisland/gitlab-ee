<a id="description"></a>

## 描述

响应正文中包含与 Twitch OAuth 客户端密钥模式匹配的内容。OAuth 客户端密钥用于允许服务代表 Twitch 用户执行功能。能够访问此客户端密钥的恶意行为者可以冒充该服务，并代表其用户执行功能。暴露此值可能使攻击者能够访问此令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换 OAuth 客户端密钥：

- 登录您的 Twitch 账号并访问 <https://dev.twitch.tv/console>
- 找到使用所识别密钥的扩展
- 在“Extensions”部分中，选择扩展名称旁边的“Manage”
- 在右上角，选择“Extension Settings”
- 在“Twitch API Client Configuration”部分中，在“Twitch API Client Secret”下选择“Generate Secret”
- 出现提示时，在对话框中选择“OK”

有关更多信息，请参阅 [Twitch 关于 OAuth 的开发者文档](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#authorization-code-grant-flow)。
