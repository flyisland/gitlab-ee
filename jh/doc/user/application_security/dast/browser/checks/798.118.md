<a id="description"></a>

## 描述

响应正文中包含与 Twitch OAuth 客户端密钥模式匹配的内容。OAuth 客户端密钥用于允许服务代表 Twitch 用户执行功能。访问此客户端密钥的恶意行为者可以冒充服务，代表其用户执行功能。
暴露该值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理泄露密钥的安全事件的一般指南，请参阅极狐GitLab 文档中的[凭证在互联网上暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换 OAuth 客户端密钥：

- 登录您的 Twitch 账户并访问 <https://dev.twitch.tv/console>
- 找到使用已识别密钥的扩展程序
- 在“Extensions”部分，选择扩展程序名称旁边的“Manage”
- 在右上角，选择“Extension Settings”
- 在“Twitch API Client Configuration”部分，选择“Twitch API Client Secret”下的“Generate Secret”
- 出现提示时，在对话框中选择“OK”

更多信息，请参阅 [Twitch 开发者文档关于 OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#authorization-code-grant-flow)。
