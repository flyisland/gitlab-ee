<a id="description"></a>

## 描述

在响应正文中检测到匹配 Lob API 密钥模式的内容。API 密钥可用于验证地址、创建活动、打印或直接邮寄给客户。能够获取此密钥的恶意行为者可以不受限制地向 Lob 发起任何 API 请求。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 有关 [凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet) 的文档。

要轮换 API 密钥：

- 登录您的账户并访问 <https://dashboard.lob.com/>
- 在左下角选择齿轮图标 / **设置** 菜单选项
- 在 **设置** 下选择 **API 密钥** 选项卡
- 在 **实时环境** 下的 **Secret API 密钥** 部分，选择旋转箭头图标
- 出现提示时，在 **Rotate Secret Live API Key** 对话框中选择 **是**

有关更多信息，请参阅 [Lob 关于 API 密钥的文档](https://docs.lob.com/#tag/Authentication/API-Keys)。
