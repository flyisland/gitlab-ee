## 描述

该漏洞可通过在 URL 端点的参数中插入有效负载进行利用，从而允许读取任意文件。这可用于读取敏感文件、访问其他用户数据，或辅助进一步获取系统访问权限。

## 修复

绝不应使用用户输入来构建用于与文件系统交互的路径或文件。这包括用户上传或下载提供的文件名。

如果可能，请考虑对文件名进行哈希处理，并在数据库或数据存储中引用哈希后的文件名，而不是直接尝试访问用户或其他系统组件提供的文件名。

在极少数需要应用程序必须处理文件名的情况下，请使用语言提供的功能仅提取所提供值中的文件名部分。切勿尝试使用来自用户输入的路径或目录信息。
