<a id="description"></a>

## 描述

响应正文包含与 HashiCorp Vault 批处理令牌模式匹配的内容。批处理令牌用于成百上千个系统需要访问 Vault 但生成唯一令牌无法扩展的场景。这些令牌通常生命周期较短，并绑定到特定的 Vault 策略。获取此令牌的恶意行为者可以冒充服务，并拥有与该批处理令牌所创建策略相同的权限级别。
暴露该值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。批处理令牌无法撤销，因此在创建批处理令牌时应使用非常短的“生存时间”值。更多信息，请参阅 [Vault 关于批处理令牌的文档](https://developer.hashicorp.com/vault/tutorials/tokens/batch-tokens)。
