## Description

响应正文中包含匹配 Postman API 令牌模式的内容。API 密钥可访问该账户有权访问的所有 Postman 数据。拥有此令牌的恶意行为者可以访问该用户通过 API 密钥有权访问的存储于 Postman 服务中的所有数据。暴露该值可能会允许攻击者获得此令牌所授予的全部资源访问权限。

## Remediation

有关处理泄露密钥相关安全事件的通用指导，请参阅极狐GitLab 文档中的[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成 API 令牌：

- 前往 <https://www.postman.com/> 登录您的 Postman 账户
- 选择右上角的头像，然后选择“设置”
- 在左侧菜单中选择“API 密钥”
- 找到被识别的密钥，然后在“API 密钥”部分中状态列旁边的省略号处点击
- 选择“重新生成”
- 出现提示时，在“重新生成 API 密钥”对话框中选择“重新生成 API 密钥”

更多信息，请参阅 [Postman 的 API 密钥文档](https://learning.postman.com/docs/developer/postman-api/authentication/)。
