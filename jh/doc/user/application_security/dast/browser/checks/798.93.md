<a id="description"></a>

## 描述

响应正文中包含与 Postman API 令牌模式匹配的内容。API 密钥可访问该账号有权限访问的所有 Postman 数据。恶意行为者一旦获取此令牌，即可访问创建该 API 密钥的用户在 Postman 服务中有权访问的所有数据。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要重新生成 API 令牌：

- 在 <https://www.postman.com/> 登录您的 Postman 账号
- 选择右上角的个人资料图片，然后选择“设置”
- 在左侧菜单中选择“API 密钥”
- 找到被识别出的密钥，然后在“API 密钥”部分的状态列旁选择省略号
- 选择“重新生成”
- 出现提示时，在“重新生成 API 密钥”对话框中选择“重新生成 API 密钥”

有关更多信息，请参阅 [Postman 关于 API 密钥的文档](https://learning.postman.com/docs/developer/postman-api/authentication/)。
