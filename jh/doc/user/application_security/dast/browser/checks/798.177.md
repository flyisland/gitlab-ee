## 描述

响应体中包含匹配 Stripe 密钥模式的内容。密钥用于访问和执行测试数据和功能。获取此测试密钥的恶意行为者只能模拟访问，账户对象不会返回敏感字段。
泄露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。

轮换您的 Stripe 密钥：

- 登录您的 Stripe 账户并访问 <https://dashboard.stripe.com/apikeys>
- 通过选择顶部菜单中的切换开关，确保启用"测试模式"
- 在"标准密钥"部分，找到被识别的密钥并选择右侧的省略号
- 选择"轮换密钥..."
- 在"轮换 API 密钥"对话框中，选择过期日期，例如"现在"
- 选择"轮换 API 密钥"

更多信息，请参阅 [Stripe 关于轮换 API 密钥的文档](https://docs.stripe.com/keys#rolling-keys)。
