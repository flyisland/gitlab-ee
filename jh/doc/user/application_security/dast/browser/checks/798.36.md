<a id="description"></a>

## 描述

响应正文中包含与 EasyPost 生产 API 密钥模式匹配的内容。生产 API 密钥用于实时应用程序操作，并允许完全访问账户。获得此令牌的恶意行为者可以执行目标环境的所有 API 调用。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销已识别的 API 令牌：

- 登录您的账户并前往设置页面 <https://www.easypost.com/account/settings>
- 在“生产 API 密钥”下，选中“状态”复选框以禁用该密钥
- 在“确定要禁用此密钥？”对话框中，选择“禁用”
- 在“状态”复选框区域，选择垃圾桶图标以删除该密钥

有关撤销和处理 API 密钥管理的信息，请[参阅其文档](https://docs.easypost.com/docs/authentication#api-key-management)。
