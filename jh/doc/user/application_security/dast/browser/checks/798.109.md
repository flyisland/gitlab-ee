<a id="description"></a>

## 描述

响应正文中包含与 Slack 机器人用户 OAuth 令牌模式匹配的内容。Slack 应用的能力和权限由其请求的 scope 决定。完整的权限列表可在 [Slack 的 scope 文档](https://api.slack.com/scopes)中找到。能够访问此令牌的恶意行为者可执行已分配给它的功能。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 Slack 机器人用户 OAuth 令牌（注意：这需要所有用户重新授权您的应用）：

- 登录 Slack 并访问 <https://api.slack.com/apps>
- 找到具有所识别令牌的应用，并选择其名称
- 在左侧菜单中，选择“OAuth & Permissions”
- 向下滚动到“Revoke All OAuth Tokens”，然后选择“Revoke tokens”
- 出现提示时，在“Are you sure?”对话框中选择“Yes, I'm sure”
- 稍等片刻后，向上滚动回“OAuth Tokens”部分，选择“Reinstall to XXX”，其中 XXX 是您的工作区名称

有关更多信息，请参阅 [Slack 的 OAuth 文档](https://api.slack.com/authentication/oauth-v2)
