<a id="description"></a>

## 描述

响应正文包含与 Slack 机器人用户 OAuth 令牌模式匹配的内容。Slack 应用的功能和权限由其请求的 scopes 控制。完整的权限列表可以在 [Slack 的 scopes 文档](https://api.slack.com/scopes) 中找到。拥有此令牌的恶意行为者可以执行分配给它的功能。
暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的 [凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 Slack 机器人用户 OAuth 令牌（注意：这需要所有用户重新授权您的应用程序）：

- 登录 Slack 并访问 <https://api.slack.com/apps>
- 找到具有已识别令牌的应用程序并选择其名称
- 在左侧菜单中，选择 “OAuth 与权限”
- 向下滚动到 “撤销所有 OAuth 令牌” 并选择 “撤销令牌”
- 出现提示时，在 “您确定吗？” 对话框中选择 “是的，我确定”
- 一段时间后，向上滚动回 “OAuth 令牌” 部分并选择 “重新安装到 XXX”，其中 XXX 是您的工作区名称

更多信息，请参阅 [Slack 的 OAuth 文档](https://api.slack.com/authentication/oauth-v2)
