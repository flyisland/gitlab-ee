<a id="description"></a>

## 描述

发现目标应用程序通过 HTTP 使用摘要式身份验证方案对用户进行身份验证。摘要式身份验证使用不安全的哈希算法（MD5）对用户名和密码进行哈希处理，并将其放在 `Authentication` 请求头中发送。位于客户端与服务器通信路径中间（或同一本地网络）的攻击者可以使用数据包嗅探器修改服务器的响应参数，以降低摘要式访问身份验证模式的安全性。此外，服务器会存储经过哈希处理的凭据，通常保存在名为 `.htpasswd`的文件中。破解这些密码的工具唾手可得。

<a id="remediation"></a>

## 修复

如有可能，请改用更稳健的用户身份验证方法，例如 OAuth 2.0，或将用户名和密码存储在受 Argon2id 算法保护的数据存储中。如果必须使用摘要式身份验证，请确保凭据仅通过 HTTPS/TLS 等安全通道传输。
