## 描述

发现目标应用程序使用基于 HTTP 的摘要认证方案对用户进行认证。摘要认证使用不安全的哈希算法（MD5）对用户名和密码进行哈希处理，并将其放在 `Authentication` 请求头中发送。处于客户端和服务器通信路径之间（或在同一本地网络）的攻击者可以使用数据包嗅探器修改服务器的响应参数，以降低摘要访问认证模式的安全性。此外，服务器通常将哈希后的凭据存储在名为 `.htpasswd` 的文件中。有现成的工具可破解这些密码。

## 修复方法

如果可能，请切换到更健壮的用户认证方法，例如 OAuth 2.0，或者将用户名和密码存储在由 Argon2id 算法保护的数据存储中。如果必须使用摘要认证，请确保凭据仅通过 HTTPS/TLS 等安全通道传输。
