<a id="description"></a>

## 描述

目标网站返回了 `Server` 头以及该网站的版本信息。攻击者可能通过这些暴露的值，尝试识别目标软件是否存在已知漏洞，或对运行特定版本的已知站点进行编目，以便在将来发现该特定版本中的漏洞时加以利用。

<a id="remediation"></a>

## 补救措施

我们建议将版本信息从 `Server` 头中移除。

Apache：
对于基于 Apache 的网站，在 `httpd.conf` 配置文件中将 `ServerTokens` 设置为 `Prod`。

NGINX：
对于基于 NGINX 的网站，在 `nginx.conf` 文件中将 `server_tokens` 配置值设置为 `off`。

IIS：
对于基于 IIS 的网站（版本 10 及更高版本），可以在 `Web.config` 文件的 `requestFiltering` 部分中使用 `removeServerHeader` 元素。

对于所有其他服务器类型，请参考产品文档了解如何从 `Server` 头中删除版本信息。
