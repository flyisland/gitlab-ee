<a id="description"></a>

## 描述

目标网站返回了 `Server` 响应头以及该网站的版本信息。通过暴露这些值，攻击者可能会尝试判断目标软件是否存在已知漏洞，或者记录运行特定版本的已知站点，以便将来在特定版本中发现漏洞时加以利用。

<a id="remediation"></a>

## 修复

建议从 `Server` 响应头中移除版本信息。

Apache：
对于基于 Apache 的网站，请在 `httpd.conf` 配置文件中将 `ServerTokens` 设置为 `Prod`。

NGINX：
对于基于 NGINX 的网站，请在 `nginx.conf` 文件中将 `server_tokens` 配置值设置为 `off`。

IIS：
对于 IIS 10 及更高版本的网站，您可以在 `Web.config` 文件的 `requestFiltering` 节中使用 `removeServerHeader` 元素。

对于所有其他服务器类型，请查阅您的产品文档，了解如何从 `Server` 响应头中隐去版本信息。
