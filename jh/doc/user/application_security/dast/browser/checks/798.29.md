## 描述

检测到响应正文包含与 Doppler 个人访问令牌模式匹配的内容。
泄露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 Doppler 个人访问令牌：

- 打开并登录 <https://dashboard.doppler.com/>
- 在右侧菜单中选择 "Tokens"
- 选择 "Personal" 选项卡
- 找到个人令牌并在操作列中选择 "Roll"
- 显示 "Roll Personal Token" 对话框后，选择 "Roll"
- 复制新令牌的值

更多信息请参阅他们的文档：<https://docs.doppler.com/docs/start>
