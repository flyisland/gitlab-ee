<a id="description"></a>

## 描述

有可能向服务器端 XSLT 处理器提供 XSL 模板。XSLT 处理器可能被滥用，以读取或写入文件、发起出站连接，并在某些情况下执行任意代码。

<a id="remediation"></a>

## 修复

应用程序绝不应接受用户提供的样式表。XSLT 处理器并非为处理潜在恶意样式表文件而构建。不过，某些处理器确实实现或提供了可能可用的安全功能。请查阅目标应用程序所使用的 XSLT 处理器的文档，了解安全指南和加固步骤。建议所有 XML 解析器和处理器至少禁用外部实体解析。
