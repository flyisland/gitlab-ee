<a id="description"></a>

## 描述

响应正文中包含与有效的 Shippo API 令牌模式匹配的内容。API 令牌可用于访问用于运输服务的 Shippo API。拥有此令牌的恶意行为者可以访问账单和订单信息并修改运输数据。暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 API 令牌：

- 登录你的 Shippo 账户并访问 <https://apps.goshippo.com/>
- 在右上角，选择“齿轮”图标进入“设置”页面
- 在左侧菜单中向下滚动到“高级”并选择“API”
- 在“令牌”部分下，选择“管理你的令牌”
- 找到已识别的令牌并选择垃圾桶图标
- 出现提示时，在“管理你的令牌”对话框中选择“是，移除令牌”

更多信息，请参阅 [Shippo 的 API 密钥文档](https://portal.goshippo.com/api-config/api)。
