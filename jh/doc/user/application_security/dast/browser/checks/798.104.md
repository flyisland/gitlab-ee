<a id="description"></a>

## 描述

响应正文中包含与有效 Shippo API 令牌模式匹配的内容。API 令牌可用于访问 Shippo API，该 API 用于提供运输服务。获得此令牌访问权限的恶意行为者可以访问账单和订单信息，并修改运输数据。暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 API 令牌：

- 登录您的 Shippo 账号并访问 <https://apps.goshippo.com/>
- 在右上角，选择“齿轮”图标进入“设置（Settings）”页面
- 在左侧菜单中向下滚动到“高级（Advanced）”，然后选择“API”
- 在“令牌（Token）”部分，选择“管理您的令牌（Manage your token）”
- 找到已识别的令牌并选择垃圾桶图标
- 出现提示时，在“管理您的令牌（Manage Your Tokens）”对话框中选择“是，移除令牌（Yes, remove token）”

有关更多信息，请参阅 [Shippo 关于 API 密钥的文档](https://portal.goshippo.com/api-config/api)。
