<a id="description"></a>

## 描述

响应正文中包含与 PlanetScale 密码匹配的模式。PlanetScale 密码用于连接数据库实例。能够获取此密码的恶意行为者可以访问 PlanetScale 托管的数据库。
暴露此值可能导致攻击者获取该令牌授予的所有资源访问权限。

<a id="remediation"></a>

## 修复措施

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)部分。更多信息，请参阅 [PlanetScale 关于数据库连接字符串的文档](https://planetscale.com/docs/concepts/connection-strings)。
