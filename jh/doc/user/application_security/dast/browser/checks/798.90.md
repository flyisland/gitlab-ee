<a id="description"></a>

## 描述

响应正文中包含与 PlanetScale 密码模式匹配的内容。PlanetScale 密码用于连接数据库实例。能够访问此密码的恶意行为者可以访问 PlanetScale 托管数据库。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。更多信息，请参阅 [PlanetScale 关于数据库连接字符串的文档](https://planetscale.com/docs/concepts/connection-strings)。
