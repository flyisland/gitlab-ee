<a id="description"></a>

## 描述

响应正文中包含与 Mailgun webhook 签名密钥模式匹配的内容。Mailgun 使用此密钥对所有传入的 webhook 消息负载进行签名。能够访问此密钥的恶意行为者可能伪造 webhook 事件并将其发送到您的服务，从而通过验证并被处理。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换您的 HTTP webhook 签名密钥：

- 登录您的 Mailgun 账号，并访问仪表板 <https://app.mailgun.com/>
- 在右上角，选择您的账号资料，然后选择“API Security”
- 在“HTTP webhook signing key”部分，选择右侧的轮换箭头图标
- 出现提示时，在“Reset HTTP webhook signing key”对话框中选择“Reset Key”

有关更多信息，请参阅 [Mailgun 关于 webhook 的文档](https://documentation.mailgun.com/docs/mailgun/user-manual/tracking-messages/#securing-webhooks)。
