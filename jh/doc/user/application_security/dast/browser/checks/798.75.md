<a id="description"></a>

## 描述

响应正文包含与 Mailgun Webhook 签名密钥的模式匹配的内容。此密钥由 Mailgun 用于对所有传入的 Webhook 消息有效负载进行签名。拥有此密钥的恶意攻击者可能会伪造虚假 Webhook 事件，并将其发送到您的服务以通过验证并被处理。暴露此值可能会让攻击者获得此令牌授权访问的所有资源。

<a id="remediation"></a>

## 修复

有关处理涉及泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的 [凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换您的 HTTP Webhook 签名密钥：

- 登录您的 Mailgun 账户并访问仪表板，网址为 <https://app.mailgun.com/>
- 在右上角，选择您的账户资料，然后选择“API 安全”
- 在“HTTP Webhook 签名密钥”部分，选择右侧的旋转箭头图标
- 出现提示时，在“重置 HTTP Webhook 签名密钥”对话框中，选择“重置密钥”

更多信息，请参阅 [Mailgun 的 Webhook 文档](https://documentation.mailgun.com/docs/mailgun/user-manual/tracking-messages/#securing-webhooks)。
