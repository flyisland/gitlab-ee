<a id="description"></a>

## 描述

响应正文中包含与 极狐GitLab OAuth 应用程序密钥模式匹配的内容。OAuth 密钥用于允许用户登录您的应用程序。根据分配的权限范围，恶意行为者可以冒充服务来访问他们的仓库或数据。
暴露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理泄露密钥安全事件的一般指导，请参阅 极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

重新生成 OAuth 密钥：

- 登录您的 极狐GitLab 账号，访问[用户设置](../../../../profile/_index.md#access-your-user-settings)左侧菜单，选择 **应用程序**
- 找到使用已识别令牌的应用程序，在 **名称** 列中选择名称链接 - 在应用程序详情页面中选择 **更新密钥**
- 出现提示时，选择 **更新密钥**

更多信息，请参阅[极狐GitLab 关于配置 OAuth 2.0 提供程序的文档](../../../../../integration/oauth_provider.md)
