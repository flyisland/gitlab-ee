<a id="description"></a>

## 描述

响应正文中包含与 Artifactory 身份令牌模式匹配的内容。Artifactory 身份令牌允许根据令牌分配到的权限进行认证，以访问仓库、下载工件、上传工件以及在 JFrog Artifactory 中执行特权操作。如果泄露，恶意行为者可能利用此令牌窃取专有代码、向软件供应链注入受损依赖项，或者可能未经授权访问依赖 Artifactory 进行构建的关联 CI/CD 系统。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

关于处理涉及泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的 [凭证暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
