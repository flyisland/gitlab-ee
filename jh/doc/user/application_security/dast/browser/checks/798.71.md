<a id="description"></a>

## 描述

响应正文中包含与 Lob 可发布 API 密钥模式匹配的内容。可发布 API 密钥仅用于美国验证、国际验证和美国自动补全请求。恶意行为者一旦获取此密钥，即可在您的账户下执行有限的功能。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换可发布 API 密钥：

- 登录您的账户并前往 <https://dashboard.lob.com/>
- 在左下角选择齿轮图标 /“Settings”菜单选项
- 在“Settings”下选择“API Keys”标签页
- 在“Publishable API Keys”部分确认该密钥是生产环境密钥还是测试环境密钥
- 选择所识别密钥的轮换箭头图标
- 出现提示时，在“Rotate Publishable API Key”对话框中选择“Yes”

有关更多信息，请参阅 [Lob 关于 API 密钥的文档](https://docs.lob.com/#tag/Authentication/API-Keys)。
