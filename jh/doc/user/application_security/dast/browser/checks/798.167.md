<a id="description"></a>

## 描述

响应正文中包含与 PKCS8 私钥模式匹配的内容。PKCS #8 是用于存储私钥信息的标准语法。能够访问此密钥的恶意行为者可以加密和解密所有过去和未来的消息。请注意，使用此密钥加密的过去消息应视为已泄露，新消息也不能视为可信。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。PKCS8 密钥无法轮换，必须生成新密钥。有关更多信息，请参阅 [openssl.org 上关于生成密钥示例的文档](https://docs.openssl.org/3.4/man1/openssl-genpkey/#examples)。
