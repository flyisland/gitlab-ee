## 描述

响应体中包含与 PKCS8 私钥模式匹配的内容。PKCS #8 是存储私钥信息的一种标准语法。拥有该密钥的恶意攻击者可以加密和解密所有历史及未来的消息。需要注意的是，使用此密钥加密的过往消息应视为已被泄露，新的消息也无法信任。
泄露该值可能让攻击者获得该令牌所授权的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。PKCS8 密钥无法轮换，必须生成新的密钥。更多信息请参考 [openssl.org 上关于生成密钥的示例](https://docs.openssl.org/3.4/man1/openssl-genpkey/#examples)。
