<a id="description"></a>

## 描述

目标应用程序被发现易受代码注入攻击。恶意行为者可以注入任意 Ruby 代码在服务器上执行。这可能导致系统完全被攻陷，例如访问存储的密钥、注入代码以接管账号，或执行操作系统命令。

<a id="remediation"></a>

## 修复

切勿将用户输入直接传入会将字符串数据作为代码求值的函数，例如 `eval`、`send`、`public_send`、`instance_eval` 或 `class_eval`。将字符串值传入这些方法几乎没有好处，因此最佳建议是将当前逻辑替换为更安全的实现，以根据用户输入动态求值逻辑。如果使用 `send` 或 `public_send`，请确保第一个参数指向已知的、硬编码的方法/符号，而不是来自用户输入。

对于 `eval`、`instance_eval` 和 `class_eval`，绝不应将用户输入直接发送到这些方法。一种替代方案是将函数或方法存储在 Hash 中，通过键进行查找。如果该键存在，则可以执行相应的函数。

```ruby
def func_to_run
  puts 'hello world'
end

input = 'fn'

function_map = { fn: method(:func_to_run) }

if function_map.key?(input.to_sym)
  function_map[input.to_sym].call
else
  puts 'invalid input'
end
```
