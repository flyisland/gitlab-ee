<a id="description"></a>

## 描述

目标应用被发现存在代码注入漏洞。恶意行为者可以注入任意 Ruby 代码并在服务器上执行。这可能导致系统完全被攻破，例如访问存储的密钥、注入代码接管账户或执行操作系统命令。

<a id="remediation"></a>

## 修复方案

切勿将用户输入直接传递给那些将字符串数据作为代码执行的方法，例如 `eval`、`send`、`public_send`、`instance_eval` 或 `class_eval`。向这些方法传递字符串值几乎没有任何好处，因此最佳建议是使用更安全的实现方式来替换当前逻辑，以实现基于用户输入动态执行逻辑。如果必须使用 `send` 或 `public_send`，请确保第一个参数指向一个已知的、硬编码的方法或符号，并且不是来自用户输入。

对于 `eval`、`instance_eval` 和 `class_eval`，绝不应将用户输入直接发送给这些方法。一种替代方案是将函数或方法存储在 Hash 中，以便通过键来查找。如果键存在，则执行相应的函数。

```ruby
def func_to_run
  输出 '你好世界'
end

input = 'fn'

function_map = { fn: method(:func_to_run) }

if function_map.key?(input.to_sym)
  function_map[input.to_sym].call
else
  输出 '输入无效'
end
```
