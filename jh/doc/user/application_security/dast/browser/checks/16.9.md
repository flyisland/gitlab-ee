## 描述

在目标站点上检测到 `Content-Security-Policy-Report-Only` (CSPRO)。CSP-Report-Only 响应头有助于确定如何实施不会干扰目标站点正常使用的 `Content-Security-Policy`。

<a id="remediation"></a>

## 修复

请遵循相关建议，确定是否需要采取任何措施来加固此 `Content-Security-Policy-Report-Only`。在解决所有告警后，将此响应头更改为 `Content-Security-Policy`。
