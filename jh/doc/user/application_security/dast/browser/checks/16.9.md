## 描述

在目标站点上发现了一个 `Content-Security-Policy-Report-Only` (CSPRO)。CSP-Report-Only 标头有助于确定如何实施 `Content-Security-Policy` 而不会影响目标站点的正常使用。

<a id="remediation"></a>

## 修复建议

请遵循建议，确定是否需要采取任何措施来加固此 `Content-Security-Policy-Report-Only`。在所有警报解决后，将此标头更改为 `Content-Security-Policy`。
