<a id="description"></a>

## 描述

用户的密码在请求 URL 中被识别出来。密码绝不应通过 GET 请求发送，因为它们可能被代理系统捕获、存储在浏览器历史或日志文件中。如果攻击者获取了这些日志或日志系统，他们就能访问目标账户。

<a id="remediation"></a>

## 修复

密码绝不应通过 GET 请求发送。进行用户认证或要求用户重置密码时，请始终使用 POST 请求传输敏感数据。
