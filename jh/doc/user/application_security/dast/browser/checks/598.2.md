<a id="description"></a>

## 描述

在请求 URL 中识别出了用户的密码。密码绝不应通过 GET 请求发送，因为它们可能会被代理系统捕获、存储在浏览器历史记录中，或存储在日志文件中。如果攻击者能够访问这些日志或日志系统，他们就能获取目标账号的访问权限。

<a id="remediation"></a>

## 修复

密码绝不应通过 GET 请求发送。在对用户进行身份验证或请求用户重置密码时，请始终使用 `POST` 请求来传输敏感数据。
