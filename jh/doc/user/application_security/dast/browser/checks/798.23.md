<a id="description"></a>

## 描述

响应正文包含与 Contentful 交付 API 令牌模式匹配的内容。Contentful 交付 API（CDA）是一种只读 API，用于将 Contentful 中的内容交付到应用程序、网站和其他媒体。内容以 JSON 数据形式交付，图像、视频和其他媒体以文件形式交付。拥有此令牌的恶意行为者可以读取条目。暴露此值可能使攻击者获取此令牌授予的所有资源。

<a id="remediation"></a>

## 补救措施

有关处理密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)部分。

要撤销交付 API 令牌：

- 登录并访问 <https://app.contentful.com/>
- 选择右上角的齿轮图标，然后选择 “API 密钥”
- 找到被检测到的 API 密钥，在 API 密钥表中选择其名称
- 在右上角选择 “删除”
- 当提示时，选择 “删除”。注意这也会删除预览 API 令牌。需要生成一套新的 API 密钥。

更多信息，请参阅开发者[认证文档](https://www.contentful.com/developers/docs/references/authentication/#the-content-delivery-and-preview-api)。
