<a id="description"></a>

## 描述

目标网站返回 `X-Backend-Server` 标头，其中可能包含内部/隐藏的 IP 地址或主机名。通过暴露这些值，攻击者可能会试图绕过安全代理并直接访问这些主机。

<a id="remediation"></a>

## 修复措施

请咨询你的代理/负载均衡器文档或供应商，了解如何禁止显露 `X-Backend-Server` 标头值。
