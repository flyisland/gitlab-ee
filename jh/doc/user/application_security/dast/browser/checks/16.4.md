<a id="description"></a>

## 描述

目标网站返回 `X-Backend-Server` 响应头，其中包含可能是内部或隐藏的 IP 地址或主机名。通过泄露这些值，攻击者可能会尝试绕过安全代理并直接访问这些主机。

<a id="remediation"></a>

## 修复

请查阅您的代理/负载均衡器文档或联系提供商，了解如何禁止泄露 `X-Backend-Server` 响应头的值。
