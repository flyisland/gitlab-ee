## 描述

响应正文中包含与 Contentful 个人访问令牌模式匹配的内容。个人访问令牌与请求它们的用户绑定，并具有相同的权限，包括访问组织、空间和内容。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复

有关处理涉及密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭证在互联网上暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要撤销个人访问令牌：

- 登录并访问您的账户资料：<https://app.contentful.com/account/profile/user>
- 在顶部菜单中选择 "CMA tokens" 选项卡
- 识别出被检测到的令牌
- 在右侧列中选择 "Revoke"
- 在提示时选择 "Revoke"

欲了解更多信息，请参阅[关于个人访问令牌的开发者文档](https://www.contentful.com/help/token-management/personal-access-tokens)。
