## 描述

在响应正文中发现了匹配 RSA 私钥模式的内容。RSA 私钥可用于多种类型的应用程序，但通常用于身份验证和对称密钥交换。能够访问此密钥的恶意行为者可以利用它来冒充应用程序或服务。
暴露此值可能使攻击者获得此令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要生成新的 RSA 密钥，请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -m PEM -t rsa -b 4096 -C "email@company.com"
```

更多信息，请参阅 [`ssh-keygen` 文档](https://linux.die.net/man/1/ssh-keygen)。
