<a id="description"></a>

## 描述

响应体包含的内容匹配了 GitHub OAuth 访问令牌的模式，已被识别。与传统 OAuth 令牌不同，用户访问令牌不使用作用域，而是使用细粒度权限。用户访问令牌仅拥有用户和应用程序共同拥有的权限。如果恶意行为者获取了令牌，且应用程序被授予了写入仓库内容的权限，但用户只能读取内容，那么用户访问令牌也只能读取内容。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的 [互联网凭据暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。更多信息，请参阅 [撤销 OAuth 访问令牌的 GitHub 文档](https://docs.github.com/en/rest/apps/oauth-applications?apiVersion=2022-11-28#delete-an-app-token)。另请注意，GitHub 应用程序优于 OAuth 应用程序，请参阅 [更多细节的 GitHub 文档](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/differences-between-github-apps-and-oauth-apps)。
