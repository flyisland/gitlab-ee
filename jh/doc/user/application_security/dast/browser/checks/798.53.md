<a id="description"></a>

## 描述

响应正文中包含与 GitHub OAuth 访问令牌模式匹配的内容。与传统 OAuth 令牌不同，用户访问令牌不使用作用域，而是使用细粒度权限。用户访问令牌仅具有用户和应用同时拥有的权限。如果恶意行为者获取了该令牌，且应用被授予写入代码仓库内容的权限，但用户只能读取内容，那么该用户访问令牌也只能读取内容。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。有关更多信息，请参阅 [GitHub 关于撤销 OAuth 访问令牌的文档](https://docs.github.com/en/rest/apps/oauth-applications?apiVersion=2022-11-28#delete-an-app-token)。另请注意，GitHub Apps 优于 OAuth 应用，请参阅 [GitHub 文档了解更多详情](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/differences-between-github-apps-and-oauth-apps)。
