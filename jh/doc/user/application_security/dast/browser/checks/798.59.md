## 描述

在响应正文中发现与 Heroku API 密钥或应用授权令牌模式匹配的内容。API 密钥和授权令牌可用于代表用户或账户执行 API 调用。能够访问这些令牌的恶意行为者可以访问 Heroku API 平台以及所有已部署的应用。
泄露此值可能允许攻击者获得由此令牌授予的所有资源的访问权限。

## 修复方法

有关处理与密钥泄露相关的安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。

要为已识别的用户重新生成 API 密钥：

- 登录您的账户并访问 <https://dashboard.heroku.com/account>
- 在“API Key”部分下，选择“Regenerate API Key”
- 出现提示时，在“Regenerate API Key”对话框中选择“Regenerate API Key”

要重新生成应用授权令牌：

- 登录您的账户并访问 <https://dashboard.heroku.com/account/applications>
- 在“Authorizations”部分下，找到包含已识别令牌的注册授权
- 选择铅笔图标
- 选择“Regenerate token”

有关 API 密钥的更多信息，请参阅[他们关于生成 API 密钥的常见问题解答](https://help.heroku.com/PBGP6IDE/how-should-i-generate-an-api-key-that-allows-me-to-use-the-heroku-platform-api)。
Heroku 没有任何关于应用授权令牌的文档。
