<a id="description"></a>

## 描述

响应正文中包含与 PlanetScale API 服务令牌模式匹配的内容。服务令牌根据允许的范围创建并分配权限。获得该服务令牌的恶意行为者将获得分配给此服务令牌的相同权限。泄露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露的安全事件的通用指南，请参阅极狐GitLab 文档中的 [凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销服务令牌：

- 登录您的 PlanetScale 帐户并访问 <https://app.planetscale.com/>。
- 从左侧菜单中，选择 **设置**
- 在 **设置** 下，选择 **服务令牌**
- 找到已识别的安全令牌并选择其名称
- 记下其组织访问权限、权限和范围
- 选择右上角的 **删除服务令牌**
- 出现提示时，在 **删除服务令牌** 对话框中选择 **删除**

有关更多信息，请参阅 [PlanetScale 的服务令牌文档](https://planetscale.com/docs/concepts/service-tokens)。
