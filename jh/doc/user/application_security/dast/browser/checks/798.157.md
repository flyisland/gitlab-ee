<a id="description"></a>

## 描述

响应正文中包含与 Ionic 个人访问令牌模式匹配的内容。个人访问令牌可用于对 Ionic CLI、Appflow CLI 或任何第三方应用程序进行身份验证。获得此令牌的恶意行为者可以完全访问关联的代码仓库和流水线。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销您的 API 令牌：

- 登录您的 Ionic 账户并访问 <https://dashboard.ionicframework.com/settings/personal-access-tokens>
- 找到被识别出的 API 令牌
- 选择“删除”（Delete）
- 出现提示时，在“确定吗？”（Are you sure?）对话框中选择“我确定，删除此个人访问令牌”（I'm sure, delete this personal access token）

有关更多信息，请参阅 [Ionic 关于访问令牌的文档](https://ionic.io/docs/appflow/personal-access-tokens)。
