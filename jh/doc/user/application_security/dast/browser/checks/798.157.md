<a id="description"></a>

## 描述

响应体中包含的内容与 Ionic 个人访问令牌的模式匹配。个人访问令牌可用于对 Ionic CLI、Appflow CLI 或任何第三方应用程序进行身份验证。能够访问此令牌的恶意行为者可以完全访问关联的代码仓和流水线。
暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的通用指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销您的 API 令牌：

- 登录您的 Ionic 账户并访问 <https://dashboard.ionicframework.com/settings/personal-access-tokens>
- 找到被识别的 API 令牌
- 选择 "删除"
- 出现提示时，在 "确定吗？" 对话框中，选择 "我确定，删除此个人访问令牌"

更多信息，请参阅 [Ionic 关于访问令牌的文档](https://ionic.io/docs/appflow/personal-access-tokens)。
