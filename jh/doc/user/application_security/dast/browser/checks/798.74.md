<a id="description"></a>

## 描述

在响应正文中发现了与 Mailgun 私有 API 令牌模式匹配的内容。此密钥允许你通过各种 API 端点，对你拥有的任何发送域名执行读取、写入和删除操作。获得此密钥的攻击者可以不受限制地对 Mailgun 发起任何 API 请求。
泄露此值可能使攻击者能够获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方案

有关处理因密钥泄露而导致的安全事件的一般性指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

轮换私有 API 令牌：

- 登录你的 Mailgun 账户并访问仪表盘：<https://app.mailgun.com/>
- 在右上角，选择你的账户资料，然后选择“API 安全”
- 找到已识别的密钥并选择垃圾桶图标
- 如果你无法选择垃圾桶图标，则必须首先通过选择“添加新密钥”来生成一个新密钥
- 出现提示时，在“删除 API 密钥”对话框中选择“删除”

更多信息，请参阅 [Mailgun 关于 API 密钥的文档](https://documentation.mailgun.com/docs/mailgun/user-manual/get-started/#primary-account-api-key)。
