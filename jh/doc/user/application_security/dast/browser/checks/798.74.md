<a id="description"></a>

## 描述

响应正文中包含与 Mailgun 私有 API 令牌模式匹配的内容。此密钥允许您通过各类 API 端点对您的任意发信域名执行读取、写入和删除操作。恶意行为者一旦获取该密钥，即可不受限制地向 Mailgun 发起任意 API 请求。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换私有 API 令牌：

- 登录您的 Mailgun 账号，并访问仪表板 <https://app.mailgun.com/>
- 在右上角，选择您的账号资料，然后选择“API Security”
- 找到被识别的密钥，然后选择垃圾桶图标
- 如果无法选择垃圾桶图标，您必须先通过选择“Add new key”生成一个新密钥
- 出现提示时，在“Delete API Key”对话框中选择“Delete”

有关更多信息，请参阅 [Mailgun 关于 API 密钥的文档](https://documentation.mailgun.com/docs/mailgun/user-manual/get-started/#primary-account-api-key)。
