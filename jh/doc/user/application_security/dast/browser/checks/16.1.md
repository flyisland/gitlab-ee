title: 缺少 Content-Type 响应头
---

<a id="description"></a>

## 描述

`Content-Type` 响应头可确保用户代理正确解释所接收的数据。如果不发送此响应头，浏览器可能会错误解释数据，从而导致 MIME 混淆攻击。如果攻击者能够上传可通过浏览器访问的文件，他们就可以上传可能被解释为 HTML 的文件，从而执行跨站脚本（XSS）攻击。

<a id="remediation"></a>

## 修复

确保所有资源都返回与其格式匹配的正确 `Content-Type` 响应头。例如，返回 JavaScript 文件时，响应头应为：`Content-Type: application/javascript`

为增强防护，所有资源都应返回 `X-Content-Type-Options: nosniff` 响应头，以禁止用户代理错误解释资源。
