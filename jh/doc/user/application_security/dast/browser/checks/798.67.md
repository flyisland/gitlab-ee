<a id="description"></a>

## 描述

响应正文中包含与 OAuth 2.0 Linear 客户端密钥或 ID 模式匹配的内容。客户端密钥用于允许用户登录您的应用程序。根据所请求的范围，恶意行为者可能冒充该服务来访问用户的信息。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 Linear OAuth 2.0 客户端密钥：

- 登录您在 <https://linear.app/> 上的账号
- 在左上角选择您的组织，然后选择“Preferences”
- 在左侧菜单中，选择“My Account”下的“API”
- 在页面的“OAuth Applications”部分中，找到包含所识别密钥的应用程序
- 选择应用程序名称右侧的省略号，然后选择“Manage application” - 在“Admin Actions”旁边选择“Rotate secret”
- 出现提示时，在“Rotate your client secret?”对话框中选择“Rotate”

有关更多信息，请参阅 [Linear 关于 OAuth 2.0 身份验证的文档](https://developers.linear.app/docs/oauth/authentication)。
