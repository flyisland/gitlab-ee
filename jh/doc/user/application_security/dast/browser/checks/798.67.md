<a id="description"></a>

## 描述

在响应正文中检测到匹配 OAuth 2.0 Linear 客户端密钥或 ID 模式的内容。客户端密钥用于允许用户登录您的应用。根据所请求的权限范围，恶意行为者可能冒充该服务来访问用户信息。
泄露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要撤销 Linear OAuth 2.0 客户端密钥：

- 登录您的帐户：<https://linear.app/>
- 选择左上角的组织，然后选择 **Preferences**
- 在左侧菜单中，选择 **My Account** 下的 **API**
- 在页面的 **OAuth Applications** 部分，找到包含已识别密钥的应用
- 选择应用名称右侧的省略号，然后选择 **Manage application**
- 在 **Admin Actions** 旁边，选择 **Rotate secret**
- 出现提示时，在 **Rotate your client secret?** 对话框中选择 **Rotate**

更多信息，请参阅 [Linear 关于 OAuth 2.0 认证的文档](https://developers.linear.app/docs/oauth/authentication)。
