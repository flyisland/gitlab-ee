<a id="description"></a>

## 描述

在响应正文中发现了与 Stripe 受限测试密钥模式匹配的内容。测试受限密钥通过仅允许对特定 API 资源进行读取或写入访问，提供了更高的安全性。能够访问此密钥的恶意操作者会受到定义范围的限制，并且只能访问测试数据。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 补救措施

有关处理与泄露密钥相关的安全事件的一般指南，请参阅极狐GitLab 文档中关于[凭据暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要轮换你的 Stripe 受限测试密钥：

- 登录你的 Stripe 账户并访问 <https://dashboard.stripe.com/apikeys>
- 通过选择顶部菜单中的切换开关，确保启用了“测试模式”
- 在“受限密钥”部分，找到被识别的密钥，然后选择右侧的省略号
- 选择 **Roll key...**
- 在 **Roll API key** 对话框中，选择一个过期日期，例如“now”
- 选择 **Roll API Key**

更多信息，请参阅 [Stripe 关于轮换 API 密钥的文档](https://docs.stripe.com/keys#rolling-keys)。
