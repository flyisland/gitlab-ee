## 描述

响应正文包含与 SSH 私钥模式匹配的内容。SSH 私钥用于身份验证和对称密钥交换。能够访问此密钥的恶意攻击者可以使用它来冒充应用程序或服务。
泄露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

## 补救措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要生成新的 DSA 密钥，请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -t dsa
```

较新版本的 SSH 可能输出 `-----BEGIN OPENSSH PRIVATE KEY-----` 而不是 `-----BEGIN DSA PRIVATE KEY-----`

更多信息，请参阅 `ssh-keygen` [文档](https://linux.die.net/man/1/ssh-keygen)。
