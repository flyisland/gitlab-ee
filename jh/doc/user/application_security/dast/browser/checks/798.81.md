<a id="description"></a>

## 描述

响应 body 包含匹配 New Relic 用户 API 密钥模式的内容。用户密钥用于查询数据和管理配置（警报、Synthetics、仪表盘等）。能够访问此密钥的恶意行为者可以以创建它的用户身份执行 API 请求。暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

对于处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。更多信息，请参阅[New Relic 关于轮换 API 密钥的文档](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#rotate-keys)。
