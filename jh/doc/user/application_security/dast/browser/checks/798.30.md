<a id="description"></a>

## 描述

响应正文包含与 Dropbox API secret/key 模式匹配的内容。
暴露此值可能允许攻击者获取此令牌授权的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露至互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。
