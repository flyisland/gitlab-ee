<a id="description"></a>

## 描述

发现目标应用程序通过 HTTP 使用基本身份验证方案对用户进行身份验证。基本身份验证会对用户名和密码进行 base64 编码，并将其放在 `Authentication` 请求头中发送。位于客户端与服务器通信路径中间（或同一本地网络上）的攻击者可以使用数据包嗅探器读取并解码用户名和密码。

<a id="remediation"></a>

## 修复

如果可能，请改用更稳健的用户身份验证方法，例如 OAuth 2.0，或将用户名和密码存储在受 Argon2id 算法保护的数据存储中。如果必须使用基本身份验证，请确保凭据仅通过 HTTPS/TLS 等安全通道传输。
