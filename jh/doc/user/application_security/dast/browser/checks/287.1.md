## 描述

发现目标应用程序通过 HTTP 使用基本认证方案对用户进行认证。
基本认证会将用户名和密码进行 Base64 编码，并将其放在 `Authentication` 请求头中发送。
处于客户端与服务器通信路径中间（或位于同一本地网络）的攻击者，可以使用数据包嗅探器来读取并解码用户名和密码。

## 修复建议

如果可能，请切换到更可靠的方法对用户进行认证，例如 OAuth 2.0，或者将用户名和密码存储在受 Argon2id 算法保护的数据存储中。如果必须使用基本认证，请确保凭证仅通过 HTTPS/TLS 等安全通道传输。
