## 描述

目标网站返回 `X-Powered-By` 头部及其版本信息。通过暴露这些值，攻击者可能试图判断目标软件是否存在已知漏洞，或者对运行特定版本的已知站点进行编目，以便未来在该特定版本中发现漏洞时加以利用。

## 修复建议

我们建议从 `X-Powered-By` 头部移除版本信息。

PHP：
对于基于 PHP 的网站，在 `php.ini` 配置文件中将 `expose_php` 选项设置为 `off`。

对于所有其他服务器类型，请查阅产品文档，了解如何从 `X-Powered-By` 头部中删除版本信息。
