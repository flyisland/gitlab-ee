<a id="description"></a>

## 描述

通过插入回车/换行（CRLF）字符，恶意用户可能向 HTTP 响应中注入任意数据。通过修改 HTTP 响应，攻击者可以针对系统其他用户实施跨站脚本或缓存投毒攻击。

<a id="remediation"></a>

## 修复

在构造 HTTP 响应头时，绝不应在未对换行符进行某种形式验证的情况下使用用户输入。这包括用户为 HTTP 重定向提供的 URL。
