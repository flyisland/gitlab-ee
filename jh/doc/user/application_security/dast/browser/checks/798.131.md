## 描述

响应正文包含与 CircleCI 项目令牌模式匹配的内容。CircleCI 项目令牌可以赋予以下三种范围之一：- 状态 - 只读 - 管理员。根据检测到的令牌的访问级别，能够访问此令牌的恶意行为者可能能够获得对项目和 CI/CD 流水线的完全访问权限。
暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

## 补救措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换项目令牌：

- 在 CircleCI 应用程序中，选择侧边栏中的 Projects，然后选择项目旁边的省略号 (...)，并选择“Project Settings”。
- 选择 API Permissions。
- 在要替换的令牌的 Remove 列中选择“X”。当确认窗口出现时，在表单中输入文本 DELETE，然后选择“Delete API Token”。
- 选择“Create API Token”。
- 从下拉列表中选择与旧令牌相同的范围。
- 在 Label 字段中，为令牌键入一个标签。可以使用与旧令牌相同的名称。
- 选择“Add API Token”。

有关更多信息，请参阅他们的[关于轮换项目令牌的文档](https://circleci.com/docs/managing-api-tokens/#rotating-a-project-api-token)。
