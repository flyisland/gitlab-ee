## 描述

响应正文包含与极狐GitLab 个人访问令牌（可路由）模式匹配的内容。暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理涉及密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
