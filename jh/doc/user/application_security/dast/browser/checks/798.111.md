<a id="description"></a>

## 描述

响应正文中包含匹配 Stripe 实时密钥模式的内容。实时密钥在实时模式下用于在服务器上认证请求。默认情况下，您可以使用此密钥无限制地执行任何 API 请求。获得此密钥的恶意行为者可获取此账户在 Stripe 中所有数据的读/写访问权限。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复建议

有关处理密钥泄露安全事件的一般指南，请参阅 极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换您的 Stripe 实时密钥：

- 登录您的 Stripe 账户并访问 <https://dashboard.stripe.com/apikeys>
- 确保"测试模式"已禁用
- 在"标准密钥"部分，找到被识别的密钥，并选择右侧的省略号
- 选择"轮换密钥..." - 在"轮换 API 密钥"对话框中，选择一个过期日期，例如"立即"
- 选择"轮换 API 密钥"

更多信息，请参阅 [Stripe 关于轮换 API 密钥的文档](https://docs.stripe.com/keys#rolling-keys)。
