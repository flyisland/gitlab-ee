## 描述

目标应用被发现通过不安全的传输协议（HTTP）请求资源。这通常是由于 HTML 元素使用 `http://` 方案而非 `https://` 来加载资源。需要注意的是，大多数现代浏览器会自动阻止这些请求，因此风险有限。

应用的某些部分可能因这些文件未能正确加载而无法正常工作。

## 修复

<a id="remediation"></a>

确保所有从 URL 加载资源的 HTML 元素（JavaScript、样式表、图片、视频及其他媒体）都设置为使用 `https://` 方案而非 `http://`。或者，开发者可以使用 `//` 方案，该方案将仅通过与原始页面加载时相同的协议加载资源。

当浏览器访问 `https://example.com` 网站时，如果 HTML 中通过 `<script src="//example.com/cdn/bundle.js"></script>` 加载文件，这将确保 `example.com/cdn/bundle.js` 文件通过 HTTPS 加载。
