## 描述

发现目标应用程序通过不安全的传输协议（HTTP）请求资源。这通常是由于 HTML 元素使用 `http://` 方案而非 `https://` 加载资源所致。需要注意的是，大多数现代浏览器会自动阻止这些请求，因此风险有限。

应用程序的某些部分可能无法正常工作，因为这些文件未能正确加载。

<a id="remediation"></a>

## 修复

确保所有从 URL 加载资源的 HTML 元素（JavaScript、样式表、图像、视频和其他媒体）都设置为使用 `https://` 方案而非 `http://`。或者，开发者可以使用 `//` 方案，该方案只会使用加载原始页面时所用的协议来加载资源。

浏览器访问网站 `https://example.com`，而 HTML 使用 `<script src="//example.com/cdn/bundle.js"></script>` 加载文件时，将确保 `example.com/cdn/bundle.js` 文件通过 HTTPS 加载。
