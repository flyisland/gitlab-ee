## 描述

应用程序生成的查询旨在与 MongoDB 交互，但未中和或错误中和了可能修改查询预期逻辑的特殊元素。

<a id="remediation"></a>

## 修复

重构查找或搜索查询，使用标准过滤操作符（如 `$gt` 或 `$in`），而非宽泛操作符（如 `$where`）。如有可能，完全禁用 MongoDB JavaScript 接口。
