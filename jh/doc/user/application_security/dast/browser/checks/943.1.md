## 描述

应用程序生成用于与 MongoDB 交互的查询，但未中和或未正确中和可能修改查询预期逻辑的特殊元素。

<a id="remediation"></a>

## 修复

重构查找或搜索查询，改用标准过滤操作符（如 `$gt` 或 `$in`），而不要使用宽泛的操作符（如 `$where`）。如有可能，请完全禁用 MongoDB JavaScript 接口。
