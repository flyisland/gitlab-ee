<a id="description"></a>

## 描述

响应正文中包含与 Linear API 令牌模式匹配的内容。个人 API 令牌可用于访问 Linear 的 GraphQL API。拥有此令牌访问权限的恶意行为者可以读取或写入 Linear 以及该账号已集成的任何系统中的议题、项目和团队。暴露此值可能使攻击者能够访问此令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 Linear API 令牌：

- 登录您的账号：<https://linear.app/>
- 在左上角选择您的组织，然后选择“偏好设置”
- 在左侧菜单中，选择“我的账户”下的“API”
- 在页面的“个人 API 密钥”部分找到已识别的 API 密钥
- 在已识别的密钥旁选择“撤销”
- 出现提示时，在“撤销访问权限？”对话框中选择“撤销”

有关更多信息，请参阅 [Linear 关于使用个人 API 密钥的文档](https://developers.linear.app/docs/graphql/working-with-the-graphql-api#personal-api-keys)。
