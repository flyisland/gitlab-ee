## 描述

<a id="description"></a>

响应主体包含与 Linear API 令牌模式匹配的内容被发现。个人 API 令牌可用于访问 Linear 的 GraphQL API。恶意行为者获得此令牌后，可以读取或写入 Linear 中的议题、项目和团队，以及该账户已集成的任何系统。
暴露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

## 修复

<a id="remediation"></a>

有关处理因密钥泄露导致的安全事件的通用指南，请参阅极狐GitLab 文档中关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要撤销 Linear API 令牌，请执行以下操作：

- 登录您在 <https://linear.app/> 的账户
- 在左上角选择您的组织，然后选择“偏好设置”
- 在左侧菜单中，在“我的账户”下选择“API”
- 在页面上的“个人 API 密钥”部分找到已识别的 API 密钥
- 在该密钥旁边选择“撤销”
- 出现提示时，在“撤销访问权限？”对话框中选择“撤销”

有关更多信息，请参阅 [Linear 关于使用个人 API 密钥的文档](https://developers.linear.app/docs/graphql/working-with-the-graphql-api#personal-api-keys)。
