<a id="description"></a>

## 描述

该应用程序易受服务端请求伪造（SSRF）影响，这是一种高风险漏洞，允许攻击者向内部和外部资源发起未经授权的请求。当用户可控的输入在用于向资源发起请求之前未经过正确验证或清理时，就会出现此漏洞，使攻击者能够为恶意目的操纵这些请求。

<a id="remediation"></a>

## 修复

避免使用用户提供的数据来构造请求。如果业务上确有此需求，可考虑采用允许名单方式，和/或使用防火墙规则或具备防 SSRF 支持的健壮请求库来阻止对内部资源的请求。
