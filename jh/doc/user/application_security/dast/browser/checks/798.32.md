<a id="description"></a>

## 描述

检测到响应体包含与 Dropbox 短期 API 令牌模式匹配的内容。
这些令牌已于 2021 年弃用，请参阅 <https://dropbox.tech/developers/migrating-app-permissions-and-access-tokens#introducing-scoped-apps> 了解详情。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 补救措施

有关处理与密钥泄露相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
