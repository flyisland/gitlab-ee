<a id="description"></a>

## 描述

发现目标应用存在代码注入漏洞。恶意行为者可以注入任意 Python 代码并在服务器上执行。这可能导致完全的系统入侵，包括访问存储的密钥、注入代码接管帐户或执行操作系统命令。

<a id="remediation"></a>

## 修复

永远不要将用户输入直接传递给会将字符串数据作为代码执行的函数，例如 `eval` 或 `exec`。将字符串值传递给这些方法几乎没有任何好处，因此最好的建议是使用更安全的实现来替换当前逻辑，以动态评估包含用户输入的逻辑。一种替代方案是将函数或方法存储在可以用键查找的哈希映射中。如果键存在，就可以执行该函数。

```python
def func_to_run():
    print('你好世界')

function_map = {'fn': func_to_run}

input = 'fn'

if input in function_map:
    function_map[input]()
else:
    print('非法输入')
```
