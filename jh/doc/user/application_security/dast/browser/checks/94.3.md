<a id="description"></a>

## 描述

发现目标应用程序易受代码注入攻击。恶意行为者可以注入任意 Python 代码在服务器上执行。这可能导致系统完全被攻陷，例如访问存储的密钥、注入代码以接管账号，或执行操作系统命令。

<a id="remediation"></a>

## 修复

切勿将用户输入直接传入将字符串数据作为代码进行求值的函数，例如 `eval` 或 `exec`。将字符串值传入这些方法几乎没有任何好处，因此最好的建议是将当前逻辑替换为更安全的实现，以用户输入动态求值逻辑。一种替代方案是将函数或方法存储在哈希映射中，通过键进行查找。如果键存在，则可以执行该函数。

```python
def func_to_run():
    print('hello world')

function_map = {'fn': func_to_run}

input = 'fn'

if input in function_map:
    function_map[input]()
else:
    print('invalid input')
```
