## 描述

响应正文包含与 Discord API 密钥模式匹配的内容。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复

有关处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab 文档 [凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
