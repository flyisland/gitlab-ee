<a id="description"></a>

## 描述

响应正文中包含与 Mailchimp API 密钥模式匹配的内容。API 密钥可用于发送电子邮件、创建和发送营销活动、访问客户列表和电子邮件地址。能够访问此密钥的恶意行为者可不受限制地向 Mailchimp 发起任何 API 请求。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 API 密钥：

- 在 <https://login.mailchimp.com/> 登录您的 Mailchimp 账号
- 选择您的个人资料图标，然后选择 Profile
- 选择 Extras 下拉列表，然后选择 "API keys"
- 找到已识别的密钥，然后选择 "Revoke"
- 出现提示时，输入 "REVOKE" 以确认，然后在 "Revoke API Key" 对话框中选择 "Revoke"

有关更多信息，请参阅 [Mailchimp 关于 API 密钥安全的文档](https://mailchimp.com/help/about-api-keys/#api+key+security)。
