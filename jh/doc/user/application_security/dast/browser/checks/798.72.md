## 描述

响应正文中包含与 Mailchimp API 密钥模式匹配的内容。该 API 密钥可用于发送电子邮件、创建和发送营销活动、访问客户列表及邮件地址。获得此密钥的恶意攻击者可以不受限制地对 Mailchimp 执行任何 API 请求。
泄露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

## 修复

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要吊销 API 密钥：

- 通过 <https://login.mailchimp.com/> 登录你的 Mailchimp 账户
- 选择你的个人资料图标，然后选择 **Profile**
- 选择 **Extras** 下拉列表，然后选择 "API keys"
- 找到已识别的密钥并选择 **Revoke**
- 出现提示时，输入 "REVOKE" 进行确认，并在 **Revoke API Key** 对话框中选择 **Revoke**

更多信息，请参阅 [Mailchimp 关于 API 密钥安全的文档](https://mailchimp.com/help/about-api-keys/#api+key+security)。
