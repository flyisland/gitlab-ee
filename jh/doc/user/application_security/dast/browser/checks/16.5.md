<a id="description"></a>

## 描述

目标网站返回 AspNet 标头和版本信息。通过暴露这些值，攻击者可能试图识别目标软件是否存在已知漏洞，或者对运行特定版本的已知站点进行编目，以便在未来发现该特定版本中的漏洞时加以利用。

<a id="remediation"></a>

## 修复措施

要移除 `X-AspNet-Version` 标头，请在 `Web.config` 文件的 `<system.Web>` 部分中设置 `<httpRuntime enableVersionHeader="false" />`。
