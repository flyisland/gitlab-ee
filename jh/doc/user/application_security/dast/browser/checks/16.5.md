<a id="description"></a>

## 描述

目标网站返回 AspNet 响应头以及该网站的版本信息。通过泄露这些值，攻击者可能会尝试判断目标软件是否存在已知漏洞，或者编目运行特定版本的已知站点，以便将来在特定版本中发现漏洞时加以利用。

<a id="remediation"></a>

## 修复

要移除 `X-AspNet-Version` 响应头，请在 `Web.config` 文件的 `<system.Web>` 节中设置 `<httpRuntime enableVersionHeader="false" />`。
