<a id="description"></a>

## 描述

发现 JavaScript 或 CSS 源文件含有无效的
[子资源完整性 (SRI)](https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity)
`integrity` 值，或缺少 `crossorigin` 值。应调查这些脚本或链接，确保它们未被恶意篡改。如有疑问，请联系脚本所有者或将其替换为已知的良好版本。

<a id="remediation"></a>

## 补救措施

所有识别出的资源都应从与目标应用程序相同的域获取。如果无法实现，强烈建议所有带有 `src` 值的 `script` 标签，或带有 `href` 值的 `link` 标签，都包含子资源完整性。要生成 SRI 完整性值，可以使用 [SRI hash](https://www.srihash.org/) 工具，或运行以下任一命令：

- `cat FILENAME.js | openssl dgst -sha384 -binary | openssl base64 -A`
- `shasum -b -a 384 FILENAME.js | awk '{ print $1 }' | xxd -r -p | base64`

这些工具的输出必须作为额外属性添加，特别是：`integrity`，以及 `crossorigin=anonymous` 或 `crossorigin=use-credentials`。
一个有效的 SRI 受保护脚本标签示例如下：

```html
<script src="https://example.com/example-framework.js"
    integrity="sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8wC"
    crossorigin="anonymous"></script>
```
