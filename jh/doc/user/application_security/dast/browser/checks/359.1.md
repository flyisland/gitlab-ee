<a id="description"></a>

## 描述

目标应用程序被发现在响应中返回了信用卡信息。被发现返回此类信息的组织可能违反了行业法规，并可能面临罚款。

<a id="remediation"></a>

## 修复方法

像信用卡这样的 PII 绝不应直接返回给用户。大部分信息应该被屏蔽，只保留标识符的最后几位数字或字符。例如，信用卡号码应仅返回最后四位数字：`****-****-****-1234`。请确保此屏蔽操作在服务器端完成，然后再将屏蔽后的数据发送回客户端。不要依赖客户端 JavaScript 或其他方法来屏蔽这些值，因为数据仍可能被拦截或去屏蔽。

此外，信用卡信息绝不应以未加密的形式存储在文件或数据库中。
