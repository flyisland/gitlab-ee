<a id="description"></a>

## 描述

发现目标应用程序在响应中返回了信用卡信息。返回此类信息的组织可能违反行业法规，并可能面临罚款。

<a id="remediation"></a>

## 修复

信用卡等 PII 绝不应直接返回给用户。除标识符的最后几位数字或字符外，大部分信息都应进行掩码处理。例如，信用卡号应仅返回最后四位：`****-****-****-1234`。确保在服务器端完成此掩码处理，然后才将掩码后的数据发送回客户端。不要依赖客户端 JavaScript 或其他方法来掩码这些值，因为数据仍可能被拦截或还原为明文。

此外，信用卡信息绝不应以未加密的形式存储在文件或数据库中。
