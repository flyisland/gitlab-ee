<a id="description"></a>

## 描述

目标网站会返回 AspNet 响应头以及该网站的版本信息。通过泄露这些值，攻击者可能尝试判断目标软件是否易受已知漏洞影响，或者编目运行特定版本的已知站点，以便将来在特定版本中发现漏洞时加以利用。

<a id="remediation"></a>

## 修复

要移除 `X-AspNetMvc-Version` 信息，请在 `Global.asax.cs` 文件的 `Application_Start()` 方法中设置 `MvcHandler.DisableMvcResponseHeader = true;`。

```csharp
protected void Application_Start()
{
    MvcHandler.DisableMvcResponseHeader = true;
}
```
