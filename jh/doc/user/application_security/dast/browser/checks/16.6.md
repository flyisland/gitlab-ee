<a id="description"></a>

## 描述

目标网站返回 AspNet 标头以及该网站的版本信息。通过暴露这些值，攻击者可能试图识别目标软件是否易受已知漏洞的攻击，或者记录运行特定版本的已知站点，以便将来在该特定版本中发现漏洞时加以利用。

<a id="remediation"></a>

## 修复建议

要删除 `X-AspNetMvc-Version` 信息，请在 `Global.asax.cs` 文件的 `Application_Start()` 方法中设置 `MvcHandler.DisableMvcResponseHeader = true;`。

```csharp
protected void Application_Start()
{
    MvcHandler.DisableMvcResponseHeader = true;
}
```
