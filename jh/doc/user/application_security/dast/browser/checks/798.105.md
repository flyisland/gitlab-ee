<a id="description"></a>

## 描述

响应正文中包含与 Shopify 个人访问令牌模式匹配的内容。访问令牌可以被授予受限范围或获得对所有商店数据的完全访问权限。获得此令牌的恶意行为者可以读取或修改商店数据。暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方案

有关处理密钥泄露的安全事件的一般指导，请参阅极狐GitLab 文档中的 [互联网上的凭证暴露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。访问令牌无法撤销，您必须卸载并重新安装应用程序。请参阅 [Shopify 文档了解更多细节](https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/generate-app-access-tokens-admin#rotating-api-credentials-for-admin-created-apps)。
