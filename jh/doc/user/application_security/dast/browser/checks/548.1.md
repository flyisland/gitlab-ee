<a id="description"></a>

## 描述

目标 Web 服务器被配置为列出不含索引文件（如 `index.html`）的目录内容。这可能导致敏感信息被意外泄露，或让攻击者了解文件名和目录的结构与存储方式。

<a id="remediation"></a>

## 修复

应禁用目录索引。

Apache：
对于基于 Apache 的网站，请确保所有 `<Directory>` 定义都在 `apache2.conf` 或 `httpd.conf` 配置文件中配置了 `Options -Indexes`。

NGINX：
对于基于 NGINX 的网站，请确保所有 `location` 定义都在 `nginx.conf` 文件中设置了 `autoindex off` 指令。

IIS：
对于 7.0 及更高版本的基于 IIS 的网站，您可以在 `applicationHost.config` 或 `Web.config` 文件中使用 `<directoryBrowse enabled="false" />` 元素。

对于所有其他服务器类型，请查阅您产品的文档，了解如何禁用目录索引。
