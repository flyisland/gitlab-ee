<a id="description"></a>

## 描述

该 Cookie 在 `Set-Cookie` 响应中传输，但未设置 `Secure` 属性。为防止敏感 Cookie 值通过明文 HTTP 意外传输，请使用 `Secure` 属性声明 Cookie。

<a id="remediation"></a>

## 修复

大多数 Web 应用框架都允许配置 Cookie 发送到用户代理的方式。有关在向客户端分配 Cookie 时如何启用各种安全属性的更多信息，请查阅您所用框架的文档。

如果应用通过直接写入响应头来分配 Cookie，请确保所有响应都包含 `Secure` 属性。启用此保护后，应用将不再通过
HTTP 发送敏感 Cookie。

示例：

```http
Set-Cookie: {cookie_name}=<random secure value>; Secure
```
