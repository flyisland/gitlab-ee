<a id="description"></a>

## 描述

该 Cookie 在 `Set-Cookie` 响应中传输时未设置 `Secure` 属性。
为防止敏感 Cookie 值意外通过明文 HTTP 传输，请使用 `Secure` 属性声明 Cookie。

<a id="remediation"></a>

## 修复措施

大多数 Web 应用框架允许配置如何向用户代理发送 Cookie。请查阅框架文档，了解在为客户端分配 Cookie 时如何启用各种安全属性。

如果应用通过直接写入响应头来分配 Cookie，请确保所有响应都包含 `Secure` 属性。启用此保护后，应用将不再通过 HTTP 发送敏感 Cookie。

示例：

```http
Set-Cookie: {cookie_name}=<随机安全值>; Secure
```
