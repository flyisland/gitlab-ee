## 描述

在响应正文中检测到匹配极狐GitLab 流水线触发令牌模式的内容。流水线触发令牌可用于为项目的分支或标签执行流水线。该令牌模拟用户的项目访问和权限。能够获取此令牌的攻击者可以使用自定义变量执行流水线，从而可能危及仓库的安全。
泄露此值可能允许攻击者获取该令牌授予的所有资源的访问权限。

## 修复

有关处理泄露密钥安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)部分。

要吊销流水线触发令牌：

- 登录你的极狐GitLab 账号，并访问创建该流水线触发令牌的项目
- 在左侧菜单中，选择"设置"
- 在"设置"选项下，选择"CI/CD"
- 在"流水线触发令牌"部分找到已识别的令牌
- 在"活跃流水线触发令牌"表格的"操作"列中选择垃圾桶图标
- 出现提示时，选择"吊销触发"

更多信息，请参阅[极狐GitLab 流水线触发令牌文档](../../../../../ci/triggers/_index.md#create-a-pipeline-trigger-token)。
