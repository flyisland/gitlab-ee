<a id="description"></a>

## 描述

响应正文中包含与极狐GitLab 流水线触发器令牌模式匹配的内容。流水线触发器令牌可用于执行项目分支或标签的流水线。该令牌会模拟用户的项目访问和权限。能够访问此令牌的恶意行为者可以使用自定义变量执行流水线，从而可能危及代码仓库。暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销流水线触发器令牌：

- 登录您的极狐GitLab 账号，并访问创建该流水线触发器令牌的项目
- 在左侧菜单中，选择“设置”
- 在“设置”选项中，选择“CI/CD”
- 在“流水线触发器令牌”部分找到已识别的令牌
- 在“活跃的流水线触发器令牌”表格的“操作”列中，选择垃圾桶图标
- 出现提示时，选择“撤销触发器”

有关更多信息，请参阅 [极狐GitLab 关于流水线触发器令牌的文档](../../../../../ci/triggers/_index.md#create-a-pipeline-trigger-token)。
