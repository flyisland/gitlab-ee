<a id="description"></a>

## 描述

检测到响应正文中包含与 Adobe 客户端密钥模式匹配的内容。Adobe 客户端密钥用于连接各种基于 API 或 Webhook 事件的服务。根据为项目定义的服务类型不同，能够访问该密钥的恶意行为者可以利用它来访问可能包含敏感信息的各种 API 或事件。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。修复步骤取决于泄露的客户端密钥类型，请参阅以下各类修复步骤，并使用适用于所检测到密钥的那一种。

OAuth（服务器到服务器）：

- 登录您的账户：<https://developer.adobe.com/console>
- 选择项目或“所有项目”以找到受影响的项目 - 在左侧“凭据”下，选择“OAuth 服务器到服务器”
- 在“客户端密钥”下，选择“检索客户端密钥”
- 显示密钥表格后，在表格下方选择“添加新的客户端密钥”
- 创建新密钥后，找到泄露的令牌值并选择垃圾桶图标将其移除
- 复制密钥值并使用新的客户端密钥更新所有服务

OAuth Web 应用（基于事件的项目）：

- 选择项目或选择“所有项目”以找到受影响的项目
- 在左侧“凭据”下，选择“OAuth Web 应用”。
- 选择“检索客户端密钥”
- 确认这就是泄露的密钥
- 如果此项目配置了事件，请在移除之前复制所有事件详情。您可以通过在右侧找到列出的事件并选择它来完成此操作。您应该会进入一个仪表板，其中显示其详细信息，例如事件交付方式、提供商、订阅的事件和已连接的凭据。
- 要移除事件，请在事件中选择“...”，该事件位于项目页面右侧、“连接另一个服务”上方。
- 选择“移除”
- 出现提示时，输入项目名称并选择“删除事件注册”
- 在右上角，选择“删除凭据”
- 出现提示时，输入项目名称并选择“删除凭据”
- 使用与之前相同的详情重新添加事件
- 当提示重新添加凭据时，请务必使用“用户身份验证”OAuth
- 为 OAuth 2.0 身份验证和授权选择“Web 应用”
- 重新添加事件后，在左侧“凭据”下，选择“OAuth Web 应用”
- 选择“检索客户端密钥”
- 复制密钥值并使用新的客户端密钥更新所有服务

OAuth Web 应用（基于 API 服务的项目）：

- 登录您的账户：<https://developer.adobe.com/console>
- 选择项目或选择“所有项目”以找到受影响的项目
- 在左侧“凭据”下，选择“OAuth Web 应用”
- 选择“检索客户端密钥”
- 如果此项目配置了 API，请选择垃圾桶图标“移除”以移除已连接的产品和服务。
- 出现提示时，输入项目名称并选择“移除 API”
- 在右上角，选择“删除凭据”
- 出现提示时，输入项目名称并选择“删除凭据”
- 使用与之前相同的详情重新添加 API
- 为 OAuth 2.0 身份验证和授权选择“Web 应用”
- 重新添加服务后，在左侧“凭据”下，选择“OAuth Web 应用”
- 选择“检索客户端密钥”
- 复制密钥值并使用新的客户端密钥更新所有服务
