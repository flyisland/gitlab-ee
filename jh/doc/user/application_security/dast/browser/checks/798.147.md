## 描述

<a id="description"></a>

在响应正文中发现了与极狐GitLab 订阅源令牌模式匹配的内容。您的订阅源令牌会在 RSS 阅读器加载个性化 RSS 订阅源或日历应用程序加载个性化日历时对您进行身份验证。此令牌在这些订阅源 URL 中可见，不能用于访问任何其他数据。能够访问此令牌的恶意攻击者可以像您本人一样读取您的个性化 RSS 订阅源，并向您的日历订阅源发布 RSS 订阅源。
暴露此值可能会让攻击者获得此令牌授予的所有资源的访问权限。

## 修复措施

<a id="remediation"></a>

有关处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成订阅源令牌：

- 登录您的极狐GitLab 账户，访问[用户设置](../../../../profile/_index.md#access-your-user-settings)左侧菜单，选择 **访问令牌**
- 在 **订阅源令牌** 部分，选择 **重置此令牌** 链接
- 出现提示时选择 **确定**

更多信息请参阅[极狐GitLab 令牌文档中的订阅源令牌部分](../../../../../security/tokens/_index.md#feed-token)。
