## 描述

响应正文中包含与极狐GitLab feed 令牌模式匹配的内容。当您的 RSS 阅读器加载个性化 RSS 订阅源，或您的日历应用加载个性化日历时，feed 令牌会对您进行身份验证。它会在这些订阅源 URL 中可见。它不能用于访问任何其他数据。能够访问此令牌的恶意行为者可以读取您的个性化 RSS 订阅源，并以您的身份向您的日历订阅源发布 RSS 订阅源。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要重新生成 feed 令牌：

- 登录您的极狐GitLab 账号，访问[用户设置](../../../../profile/_index.md#access-your-user-settings)左侧菜单，选择“访问令牌”
- 在“Feed 令牌”部分，选择“重置此令牌”链接
- 出现提示时，选择“确定”

有关更多信息，请参阅 [极狐GitLab 关于 feed 令牌的文档](../../../../../security/tokens/_index.md#feed-token)。
