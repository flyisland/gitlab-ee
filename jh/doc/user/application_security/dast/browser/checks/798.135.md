## 描述

响应体包含匹配 DigitalOcean OAuth 访问令牌模式的内容。泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复

有关处理泄露密钥的安全事件的一般指导，请参见极狐GitLab 文档中的[凭据暴露给互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
