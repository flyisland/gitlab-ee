<a id="description"></a>

## 描述

响应正文中包含与 Shippo 测试 API 令牌模式匹配的内容。API 令牌可用于访问 Shippo API，该 API 用于提供物流运输服务。恶意行为者一旦获取此令牌，便可访问账单和订单信息，并修改物流数据。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 API 令牌：

- 登录您的 Shippo 账号并访问 <https://apps.goshippo.com/>
- 在右上方，选择“齿轮”图标进入“设置”页面
- 在左侧菜单中向下滚动到“高级”，然后选择“API”
- 在“令牌”部分下，选择“管理您的令牌”
- 找到已识别的令牌，然后选择垃圾桶图标
- 出现提示时，在“管理您的令牌”对话框中选择“是，移除令牌”

有关更多信息，请参阅 [Shippo 关于 API 密钥的文档](https://portal.goshippo.com/api-config/api)。
