<a id="description"></a>

## 描述

发现目标应用程序在响应中返回了社会安全号码 (SSN) 信息。

<a id="remediation"></a>

## 修复

社会安全号码等 PII 绝不应直接返回给用户。除标识符的最后几位数字或字符外，大部分信息都应被掩码。例如，社会安全号码只应显示最后四位数字：`***-**-1234`。请确保在服务器端完成此掩码处理，然后再将掩码后的数据发送回客户端。不要依赖客户端 JavaScript 或其他方法来掩码这些值，因为数据仍可能被拦截或还原为明文。

此外，社会安全号码绝不应以未加密的形式存储在文件或数据库中。
