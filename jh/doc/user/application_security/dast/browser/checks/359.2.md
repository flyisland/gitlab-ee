## 描述

目标应用程序在响应中返回了社会安全号码 (SSN) 信息。发现返回此类信息的组织可能违反（美国）州或联邦法律，并可能面临严厉处罚。

## 修正

社会安全号码等 PII 永远不应直接返回给用户。除了标识符的最后几位数字或字符外，大部分信息都应该被遮蔽。例如，社会安全号码只应显示最后四位数字：`***-**-1234`。确保此遮蔽在服务器端完成，然后仅将遮蔽后的数据发送回客户端。不要依赖客户端 JavaScript 或其他方法来遮蔽这些值，因为数据仍然可能被拦截或暴露。

此外，社会安全号码永远不应在文件或数据库中未加密存储。
