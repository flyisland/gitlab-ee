<a id="description"></a>

## 描述

已识别出响应正文中包含与 CircleCI 个人访问令牌模式匹配的内容。个人访问令牌授予与其创建者用户相同级别的权限。能够访问此令牌的恶意行为者可以冒充该用户，并获得对 CircleCI 中所有功能和服务的访问权限。公开此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 补救措施

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭证泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换个人访问令牌：

- 在 CircleCI 应用程序中，转到您的用户设置。
- 选择“个人 API 令牌”。
- 在要替换的令牌的“移除”列中选择“X”并确认删除。
- 选择“创建新令牌”。
- 在“令牌名称”字段中，为要轮换的旧令牌键入新名称。可以使用与旧令牌相同的名称。
- 选择“添加 API 令牌”。
- 令牌出现后，将其复制并粘贴到其他位置。无法再次查看该令牌。

有关更多信息，请参阅他们的[关于轮换个人访问令牌的文档](https://circleci.com/docs/managing-api-tokens/#rotating-a-personal-api-token)。
