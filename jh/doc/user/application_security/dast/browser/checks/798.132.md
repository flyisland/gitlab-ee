<a id="description"></a>

## 描述

响应正文中包含与 CircleCI 个人访问令牌模式匹配的内容。个人访问令牌授予的权限级别与创建该令牌的用户相同。恶意行为者一旦获取此令牌，就可以冒充该用户，并访问 CircleCI 中的所有功能和服务。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

轮换个人访问令牌：

- 在 CircleCI 应用中，转到您的用户设置。
- 选择“个人 API 令牌”。
- 在要替换的令牌对应的“移除”列中选择“X”，并确认删除。 - 选择“创建新令牌”。
- 在“令牌名称”字段中，为您要轮换的旧令牌输入一个新名称。它可以与旧令牌使用相同的名称。
- 选择“添加 API 令牌”。
- 令牌出现后，将其复制并粘贴到其他位置。之后将无法再次查看该令牌。

有关更多信息，请参阅其[关于轮换个人访问令牌的文档](https://circleci.com/docs/managing-api-tokens/#rotating-a-personal-api-token)。
