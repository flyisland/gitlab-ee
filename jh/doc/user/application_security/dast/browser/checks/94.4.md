<a id="description"></a>

## 描述

目标应用程序被发现存在代码注入漏洞。恶意行为者可以注入任意 JavaScript 代码并在服务器上执行。这可能导致系统完全失陷，例如访问存储的密钥、注入代码以接管账号，或执行操作系统命令。

<a id="remediation"></a>

## 修复

切勿将用户输入直接传入会把字符串数据当作代码进行求值的函数，例如 `eval`、`setTimeout` 或 `setInterval`。将字符串值传给这些方法几乎没有任何好处，因此最好的建议是将当前逻辑替换为更安全的实现，以根据用户输入动态求值逻辑。一种替代方案是将函数或方法存储在 Map 中，通过键来查找。如果该键存在，就可以执行对应的函数。

```javascript
const function_map = new Map();

function_map.set('fn', function() {
    console.log('hello world');
})

const input = 'fn2';

const fn = function_map.get(input)

if (fn) {
    fn();
} else {
    console.log('invalid input');
}
```
