<a id="description"></a>

## 描述

目标应用程序被发现存在代码注入漏洞。恶意攻击者可以注入任意 JavaScript 代码并在服务器上执行。这可能导致系统完全失陷，通过访问存储的密钥、注入代码接管账户或执行操作系统命令。

<a id="remediation"></a>

## 修复

永远不要将用户输入直接传递给将字符串数据作为代码执行的函数，例如 `eval`、`setTimeout` 或 `setInterval`。向这些方法传递字符串值几乎没有好处，因此最佳建议是将当前逻辑替换为更安全的实现，以动态评估带有用户输入的逻辑。一种替代方案是将函数或方法存储在一个 Map 中，可以通过键进行查找。如果键存在，则可以执行该函数。

```javascript
const function_map = new Map();

function_map.set('fn', function() {
    console.log('hello world');
})

const input = 'fn2';

const fn = function_map.get(input)

if (fn) {
    fn();
} else {
    console.log('invalid input');
}
```
