<a id="description"></a>

## 描述

响应正文包含与 Discord 客户端密钥模式匹配的内容。泄露此值可能使攻击者能够访问此令牌授予的所有资源。

<a id="remediation"></a>

## 补救措施

有关处理泄露密钥的安全事件的一般指南，请参阅极狐GitLab 文档中的 [凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换 Discord 客户端密钥：

- 登录并访问 <https://discord.com/developers/applications/>。
- 选择所识别密钥所属的应用程序。
- 在左侧菜单中选择 "OAuth 2" 菜单项。
- 在页面的 "客户端信息" 部分下，选择 "重置密钥"。
- 出现提示时，选择 "是，执行！"。

有关更多信息，请参阅 [Discord 的 OAuth 文档](https://discord.com/developers/docs/topics/oauth2)。
