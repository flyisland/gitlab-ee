<a id="description"></a>

## 描述

响应正文中包含与 SSH 私钥模式匹配的内容。SSH 私钥用于身份验证和对称密钥交换。能够访问该私钥的恶意行为者可以利用它来冒充某个应用程序或服务。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要生成新的 ECDSA 密钥，请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -t ecdsa
```

较新版本的 SSH 可能会输出 `-----BEGIN OPENSSH PRIVATE KEY-----`，而不是 `-----BEGIN EC PRIVATE KEY-----`

有关更多信息，请参阅 [`ssh-keygen` 文档](https://linux.die.net/man/1/ssh-keygen)。
