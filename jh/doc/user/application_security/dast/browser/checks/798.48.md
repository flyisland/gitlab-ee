<a id="description"></a>

## 描述

响应正文中包含与 Frame.io API 令牌模式匹配的内容。Frame.io 支持通过具有作用域的 API 令牌进行外部访问。令牌与单个用户账号关联，并具有与创建该令牌的用户相同的访问权限。Frame.io 中的所有 API 操作都受作用域限制。能够访问此令牌的恶意行为者可以根据分配给该令牌的作用域执行各种功能。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销该 API 令牌：

- 登录并访问 <https://developer.frame.io/app/tokens>
- 找到被识别出的令牌，并记下分配给它的作用域
- 选择被识别出的令牌右侧的垃圾桶图标
- 当出现“删除令牌？”提示时，选择“删除”

有关更多信息，请参阅 [Frame.io 的认证文档](https://developer.frame.io/docs/getting-started/authentication)。
