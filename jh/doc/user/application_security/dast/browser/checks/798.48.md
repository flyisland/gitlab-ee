## 描述

响应正文中包含与 Frame.io API 令牌模式相匹配的内容。Frame.io 通过限定范围的 API 令牌支持外部访问。令牌与个人用户账户关联，并拥有与创建它们的用户相同的访问权限。Frame.io 中的所有 API 操作均受范围限制。获得此令牌的恶意行为者可根据分配给令牌的范围执行各种功能。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复建议

有关处理因密钥泄露导致的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据泄露至公共互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要撤销 API 令牌：

- 登录并访问 <https://developer.frame.io/app/tokens>
- 找到已识别的令牌并记下分配给它的范围
- 选择已识别令牌右侧的删除图标
- 当提示“删除令牌？”时，选择“删除”

更多信息，请参阅 [Frame.io 关于身份验证的文档](https://developer.frame.io/docs/getting-started/authentication)。
