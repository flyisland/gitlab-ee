<a id="description"></a>

## 描述

响应正文中包含与 Artifactory API 密钥模式匹配的内容。Artifactory API 密钥可用于部署产物、管理仓库、配置权限以及从 JFrog Artifactory 仓库检索产物等操作。如果泄露，恶意行为者可能利用它窃取敏感的专有代码、向构建流水线中注入恶意软件包，或删除关键产物，从而破坏组织的软件交付能力。暴露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
