## 机密密钥或令牌 Artifactory API Key 暴露

## 描述

响应正文中包含匹配 Artifactory API 密钥模式的内容。Artifactory API 密钥可用于部署产物、管理仓库、配置权限以及从 JFrog Artifactory 仓库中检索产物。一旦泄露，攻击者可能利用它窃取敏感的专有代码、向构建流水线注入恶意包，或删除关键产物，从而破坏组织的软件交付能力。
暴露此值可能使攻击者获得此令牌授予的所有资源的访问权。

## 修复措施

有关处理因密钥泄露导致的安全事件的通用指导，请参阅极狐GitLab 文档中关于[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
