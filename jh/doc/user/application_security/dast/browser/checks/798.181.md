<a id="description"></a>

## 描述

响应正文中包含与 Yandex Cloud IAM Cookie v1 模式匹配的内容。
暴露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
