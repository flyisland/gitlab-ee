<a id="description"></a>

## 描述

响应体包含的内容与 LinkedIn 客户端 ID 的模式匹配。客户端 ID 与客户端密钥结合使用。能够访问此 ID 的恶意行为者如果同时拥有客户端密钥，则可以模拟客户端应用程序。泄露此值可能允许攻击者获得此令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复方案

有关处理密钥泄露的安全事件的通用指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。客户端 ID 不需要吊销或重新生成。更多信息，请参阅 [LinkedIn 的 API 访问文档](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access)。
