<a id="description"></a>

## 描述

响应正文中包含与 LinkedIn 客户端 ID 模式匹配的内容。客户端 ID 与客户端密钥配合使用。如果恶意行为者能够访问此 ID，并且同时能够访问客户端密钥，就可以冒充客户端应用程序。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。客户端 ID 无需撤销或重新生成。有关更多信息，请参阅 [LinkedIn 的 API 访问文档](https://learn.microsoft.com/en-us/linkedin/learning/getting-started/request-access)。
