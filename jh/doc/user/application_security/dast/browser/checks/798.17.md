## 描述

The response body contains content that matches the pattern of a Beamer API token was detected. 检测到响应体包含匹配 Beamer API 令牌模式的内容。Beamer API 令牌可用于读取、写入和删除帖子和“想法”，以及查看 NPS 分析报告。此服务用于通过电子邮件或其他方法通知用户你的软件变更。能够访问此令牌的恶意行为者可以调用 API 端点，并创建或删除帖子和想法或查看报告。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复

For general guidance on handling security incidents with regards to leaked keys, please see the GitLab documentation on [凭据泄露到公共互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet). 要删除你的 Beamer API 令牌： - 登录你的 Beamer 账户：<https://app.getbeamer.com/auth/login> - 选择左下角的齿轮图标（**设置**），然后在左侧菜单中选择 **API**，或前往 <https://app.getbeamer.com/settings#api> - 找到被检测到的密钥，并选择铅笔图标 **编辑** - 记下所有权限及其设置 - 选择 **删除密钥** - 选择 **创建新的 API 密钥** - 应用与被检测到的密钥相同的设置
