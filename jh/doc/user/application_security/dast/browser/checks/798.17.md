<a id="description"></a>

## 描述

响应正文中包含与 Beamer API 令牌模式匹配的内容。Beamer API 令牌可用于读取、写入和删除帖子及“ideas”，还可查看 NPS 分析报告。该服务用于通过电子邮件或其他方式向用户通知软件的变更。获得该令牌的恶意行为者可以调用 API 端点，创建或删除帖子和 ideas，或查看报告。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要删除您的 Beamer API 令牌：

- 在以下地址登录您的 Beamer 账号：<https://app.getbeamer.com/auth/login>
- 选择左下角的齿轮图标（“Settings”），然后在左侧菜单中选择“API”，或访问 <https://app.getbeamer.com/settings#api>
- 找到被检测到的密钥，并选择铅笔图标“Edit”
- 记录所有权限及其设置
- 选择“Delete Key”
- 选择“Create New API Key”
- 应用与被检测到的密钥相同的设置
