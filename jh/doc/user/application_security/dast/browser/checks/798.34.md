<a id="description"></a>

## 描述

检测到响应正文中包含与 Duffel API 令牌模式匹配的内容。根据创建方式的不同，Duffel API 令牌可以是读写令牌或只读令牌。拥有读写令牌的恶意行为者可以执行订单、预订航班或酒店，或者查看或修改客户列表。只读令牌可以查看客户列表、列出预订和航班信息。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要重新生成令牌：

- 打开并登录 <https://app.duffel.com/>
- 在页面顶部选择 Developers 下拉列表，然后选择“Developers”
- 在左侧菜单中选择“Access tokens”
- 选择检测到的访问令牌
- 记下令牌类型（“Read and Write”或“Read Only”）
- 在“Danger Zone”中选择“Delete token”
- 使用与检测到的令牌相同的设置重新创建一个新令牌

更多信息请参阅其文档：<https://duffel.com/docs/guides/getting-started-with-the-dashboard#access-tokens>
