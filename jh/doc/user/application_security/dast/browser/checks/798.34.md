## 暴露机密密钥或Duffel API令牌

<a id="description"></a>

## 描述

在响应体中检测到与 Duffel API 令牌模式匹配的内容。Duffel API 令牌可以是读写或只读的，具体取决于创建方式。拥有读写令牌的恶意行为者可以执行订单、预订航班或酒店，或查看或修改客户列表。只读令牌可以查看客户列表、列出预订和航班信息。
暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要重新生成令牌：

- 打开并登录 <https://app.duffel.com/>
- 在页面顶部选择“开发者”下拉列表，然后选择“开发者”
- 在左侧菜单中选择“访问令牌”
- 选择被检测到的访问令牌
- 记录令牌类型（“读写”或“只读”）
- 在“危险区域”中选择“删除令牌”
- 使用与被检测令牌相同的设置重新创建新令牌

有关更多信息，请参阅其文档：<https://duffel.com/docs/guides/getting-started-with-the-dashboard#access-tokens>
