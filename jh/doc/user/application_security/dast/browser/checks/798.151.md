<a id="description"></a>

## 描述

响应正文包含与极狐GitLab SCIM 令牌模式匹配的内容。SCIM 令牌用于配置第三方身份提供者（IdP）。拥有此令牌的恶意行为者可以配置 IdP 并添加用户以获取对极狐GitLab 系统的访问权限。泄露此值可能使攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理泄露密钥的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换 SCIM 令牌：
- 以管理员身份登录您的极狐GitLab 帐户
- 在左侧边栏底部，选择管理员
- 选择“设置”，然后选择“通用”
- 展开 SCIM 令牌部分，然后选择“生成 SCIM 令牌”
- 在“您的 SCIM 令牌”下，选择“重置它”以生成新令牌

更多信息，请参阅[极狐GitLab 的 SCIM 配置文档](../../../../../administration/settings/scim_setup.md#configure-gitlab)。
