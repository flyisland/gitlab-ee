## 描述

响应正文包含与 RubyGems API 令牌模式匹配的内容。RubyGems 令牌用于访问 API 或发布软件包。RubyGems 令牌在创建时可设定特定的权限或范围。根据权限和范围的不同，能够访问此令牌的恶意行为者可以添加或删除软件包、添加或删除所有者，或查看仪表盘。
泄露此值可能使攻击者获得此令牌所授权的所有资源的访问权限。

## 修复

关于处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要撤销 API 令牌：

- 登录你的 RubyGems 帐户并访问 <https://rubygems.org/settings/edit>
- 向下滚动并选择 "API 密钥"，或访问 <https://rubygems.org/profile/api_keys>
- 找到已识别的令牌并选择 "删除"
- 在提示时，在对话框中选择 "确认"。

更多信息，请参阅 [RubyGems API 令牌文档](https://guides.rubygems.org/api-key-scopes/)。
