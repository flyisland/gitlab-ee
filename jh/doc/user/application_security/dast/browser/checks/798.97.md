<a id="description"></a>

## 描述

<!-- vale gitlab_base.OxfordComma = NO -->
响应正文中包含与 RubyGems API 令牌模式匹配的内容。RubyGems 令牌用于访问 API 或发布软件包。RubyGems 令牌可在创建时指定特定的权限或作用域。根据权限和作用域的不同，能够访问此令牌的恶意行为者可以添加或删除软件包、添加或删除所有者，或查看仪表板。
暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。
<!-- vale gitlab_base.OxfordComma = YES -->

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销该 API 令牌：

- 登录您的 RubyGems 账号并访问 <https://rubygems.org/settings/edit>
- 向下滚动并选择“API Keys”，或前往 <https://rubygems.org/profile/api_keys>
- 找到被识别出的令牌并选择“Delete”
- 出现提示时，在对话框中选择“OK”。

有关更多信息，请参阅 [RubyGems 关于 API 令牌的文档](https://guides.rubygems.org/api-key-scopes/)。
