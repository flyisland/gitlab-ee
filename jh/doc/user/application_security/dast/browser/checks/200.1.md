<a id="description"></a>

## 描述

在目标应用程序中发现了 RFC 1918/RFC 4193 私有地址。面向公众的网站不应向私有 IP 地址发出请求。试图执行后续攻击（例如服务器端请求伪造 (SSRF)）的攻击者可能会利用此信息来识别其他内部目标。

<a id="remediation"></a>

## 修复

找出错误指定内部 IP 地址的资源，将其替换为面向公众的版本，或从目标应用程序中移除该引用。
