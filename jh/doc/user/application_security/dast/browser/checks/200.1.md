<a id="description"></a>

## 描述

在目标应用中检测到一个私有 RFC 1918/RFC 4193 地址。面向公众的网站不应向私有 IP 地址发出请求。试图执行后续攻击（例如服务器端请求伪造 (SSRF)）的攻击者可能利用此信息识别其他内部目标。

<a id="remediation"></a>

## 修复

识别错误指定了内部 IP 地址的资源，并将其替换为面向公众的版本，或从目标应用中移除该引用。
