## 描述

响应体包含匹配 GoCardless API 令牌模式的内容。
暴露此值可能使攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理已泄露密钥的安全事件的一般指导，请参阅 极狐GitLab 文档中关于 [凭据暴露在公共互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet) 的部分。
