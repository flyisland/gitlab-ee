<a id="description"></a>

## 描述

检测到响应正文中包含与 Asana 客户端密钥模式匹配的内容。客户端密钥用于通过 OAuth 进行身份验证和授权。获得此密钥的恶意行为者可以访问用户账户，并代表他们执行功能。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的通用指导，请参阅极狐GitLab 关于[互联网凭据泄露](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。要撤销检测到的客户端密钥：

- 登录您的开发者账户并访问 <https://app.asana.com/0/my-apps>
- 在“我的应用”页面找到使用该密钥的应用
- 在开发者控制台中选择您的应用
- 转到侧边栏中的“OAuth”选项卡
- 选择客户端密钥旁边的“重置”

有关更多信息，请[查阅他们关于配置 OAuth 的文档](https://developers.asana.com/docs/oauth)
