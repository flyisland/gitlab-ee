<a id="description"></a>

## 描述

响应正文中包含与 Asana 客户端密钥模式匹配的内容。客户端密钥用于通过 OAuth 进行身份验证和授权。获取到该密钥的恶意行为者可能借此访问用户账号，并以用户名义执行操作。泄露该值可能使攻击者能够访问此令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要撤销检测到的客户端密钥：- 登录您的开发者账号并访问 <https://app.asana.com/0/my-apps> - 在“My apps”页面中找到使用该密钥的应用程序 - 在开发者控制台中选择您的应用 - 转到侧边栏中的“OAuth”标签页 - 在客户端密钥旁选择“Reset”。有关更多信息，请[参阅其关于配置 OAuth 的文档](https://developers.asana.com/docs/oauth)
