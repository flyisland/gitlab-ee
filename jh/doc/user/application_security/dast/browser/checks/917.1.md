<a id="description"></a>

## 描述

攻击者可能在目标应用服务器上执行任意的表达式语言（EL）语句。EL 注入是一个严重程度极高的漏洞，可导致整个系统被攻陷。当攻击者控制的数据被用于构造 EL 语句，且未对特殊字符进行中和处理时，就可能发生 EL 注入。在 EL 语句被解释器执行前，这些特殊字符可能会修改预期的 EL 语句。

<a id="remediation"></a>

## 补救措施

在将用户控制的数据用于构造表达式语言语句时，应始终对其中的特殊元素进行中和处理。请查阅所使用的 EL 解释器文档，了解如何正确地中和处理用户控制的数据。
