<a id="description"></a>

## 描述

可以在目标应用服务器上执行任意表达式语言（EL）语句。EL 注入是一种严重级别的漏洞，可能导致系统完全被攻陷。当使用攻击者控制的数据构造 EL 语句而未对特殊字符进行中和处理时，就可能发生 EL 注入。这些特殊字符可能会在解释器执行预期的 EL 语句之前修改该语句。

<a id="remediation"></a>

## 修复

当用户控制的数据被用于构造表达式语言语句时，应始终对其中的特殊元素进行中和处理。请查阅您所使用的 EL 解释器文档，了解如何正确中和用户控制的数据。
