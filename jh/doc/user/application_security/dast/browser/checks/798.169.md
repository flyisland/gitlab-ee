<a id="description"></a>

## 描述

响应正文中包含与 Segment 公共 API 令牌模式匹配的内容。Segment 公共 API 用于管理您的 Segment 工作区及其资源。有两种类型的令牌匹配此模式：工作区所有者令牌和受限角色令牌。一般来说，这些令牌允许 API 调用者执行读取、写入和删除操作。恶意行为者如果获得工作区所有者令牌，就可以访问所有工作区数据。受限角色令牌只能访问其在创建时被授予访问权限的数据。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换公共 API 令牌：

- 登录您的 Segment 账号，并从 <https://app.segment.com/> 访问您的工作区
- 在左侧菜单中，选择“设置”并转到“工作区设置”
- 在“工作区设置”页面中选择“访问管理”标签页
- 在“访问管理”下选择“令牌”标签页
- 找到被识别出的密钥，并选中它
- 在右侧的“令牌权限”部分中，选择“编辑令牌”
- 在右上角选择“移除令牌”
- 出现提示时，在对话框中选择“移除令牌”

有关更多信息，请参阅 [Segment 关于其公共 API 的文档](https://segment.com/docs/api/public-api/)。
