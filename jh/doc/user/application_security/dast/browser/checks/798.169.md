<a id="description"></a>

## 描述

响应正文包含与 Segment 公网 API 令牌相匹配的内容被识别。Segment 公网 API 用于管理你的 Segment 工作区及其资源。有两种类型的令牌与此模式匹配：工作区所有者令牌和受限角色令牌。通常，这些令牌允许 API 的调用方执行读取、写入和删除操作。拥有工作区所有者令牌的恶意行为者可以访问所有工作区数据。受限角色令牌可以访问在创建时被授权访问的数据。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理泄露密钥的安全事件的一般指南，请参阅极狐GitLab 文档中的[凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换公网 API 令牌：

- 登录你的 Segment 账户并从 <https://app.segment.com/> 访问你的工作区
- 从左侧菜单中，选择“设置”并进入“工作区设置”
- 在“工作区设置”页面中选择“访问管理”选项卡
- 在“访问管理”下选择“令牌”选项卡
- 找到被识别的密钥并选择它
- 在右侧，“令牌权限”部分中，选择“编辑令牌”
- 选择右上角的“移除令牌”
- 当出现提示时，在对话框中选择“移除令牌”

有关更多信息，请参阅 [Segment 的公网 API 文档](https://segment.com/docs/api/public-api/)。
