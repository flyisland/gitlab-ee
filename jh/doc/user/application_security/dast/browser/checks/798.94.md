<a id="description"></a>

## 描述

响应主体包含与 SSH 私钥模式匹配的内容。SSH 私钥用于身份验证和对称密钥交换。拥有此密钥的恶意行为者可以冒充应用程序或服务。泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据泄露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

生成新的 ed25519 密钥（推荐），请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -t ed25519
```

生成新的 ECDSA 密钥，请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -t ecdsa
```

生成新的 DSA 密钥，请使用 `ssh-keygen` 工具：

```shell
ssh-keygen -t dsa
```

更多信息，请参阅 [`ssh-keygen` 文档](https://linux.die.net/man/1/ssh-keygen)。
