<a id="description"></a>

## 描述

响应正文中包含与 Flutterwave 测试加密密钥模式匹配的内容。此密钥仅用于[直接扣款端点](https://developer.flutterwave.com/docs/direct-card-charge)。该密钥用于在发送前加密卡详情载荷。更多信息请参见 [Flutterwave 的加密指南](https://developer.flutterwave.com/docs/encryption)。能够访问此密钥的恶意行为者可能解密测试交易，其中可能包含信用卡信息。暴露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参见极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换您的密钥：

- 登录并前往 <https://app.flutterwave.com/dashboard/home>
- 在左侧菜单中选择“设置”
- 在左侧菜单的“开发者”下选择“API 密钥”
- 确保已激活“测试模式”
- 选择“生成密钥”以轮换公钥、密钥和加密密钥

更多信息请参见 [Flutterwave 的认证文档](https://developer.flutterwave.com/docs/authentication)。
