<a id="description"></a>

## 描述

响应正文中包含与识别的 Flutterwave 测试加密密钥模式匹配的内容。此密钥仅用于 [直接扣款端点](https://developer.flutterwave.com/docs/direct-card-charge)。此密钥用于在发送前加密卡详细信息的有效载荷。更多信息请参见 [Flutterwave 加密指南](https://developer.flutterwave.com/docs/encryption)。能够访问此密钥的恶意行为者可能会解密测试交易，其中可能包含信用卡信息。
暴露此值可能允许攻击者访问此令牌授予的所有资源。

<a id="remediation"></a>

## 修复措施

有关处理泄露密钥安全事件的通用指导，请参见极狐GitLab 文档中的[凭据暴露在公网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要轮换您的密钥：

- 登录并前往 <https://app.flutterwave.com/dashboard/home>
- 在左侧菜单中选择 **设置**
- 在左侧菜单的 **开发者** 下选择 **API 密钥**
- 确保 **测试模式** 已激活
- 选择 **生成密钥** 以轮换公钥、密钥和加密密钥

更多信息请参见 [Flutterwave 身份验证文档](https://developer.flutterwave.com/docs/authentication)。
