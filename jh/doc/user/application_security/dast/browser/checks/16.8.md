## 描述

在目标站点上发现缺失或无效的 `Content-Security-Policy`（CSP）。CSP 有助于加强网站防御各种客户端攻击，例如跨站脚本（XSS）。

<a id="remediation"></a>

## 修复建议

如果目标站点缺少 CSP，请调查相关 URL 以启用 CSP。否则，请遵循建议以确定是否需要采取任何操作。
