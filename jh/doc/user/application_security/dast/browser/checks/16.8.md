## 描述

在目标站点上发现缺少或无效的 `Content-Security-Policy`（CSP）。CSP 有助于增强网站对各种客户端攻击（如跨站脚本攻击（XSS））的防护能力。

<a id="remediation"></a>

## 修复

如果目标站点缺少 CSP，请调查相关 URL 以启用 CSP。否则，请遵循建议以确定是否需要采取任何措施。
