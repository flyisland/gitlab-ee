## 描述

该 Cookie 在 `Set-Cookie` 头部中传输，但未设置 `HttpOnly` 属性。
为了防止 JavaScript 能够访问 Cookie 值——通常通过 `document.cookies` 来实现——所有
用于授权的 Cookie 都应设置 `HttpOnly` 属性。

## 修复方案

大多数 Web 应用程序框架都允许配置如何将 Cookie 发送到用户代理。请查阅您所用框架的
文档，以获取关于在向客户端分配 Cookie 时如何启用各种安全指令的更多信息。

如果应用程序是通过直接写入响应头来分配 Cookie，请确保所有响应都包含
`HttpOnly` 属性。通过启用此保护，应用程序能够减轻
某些跨站脚本 (XSS) 攻击的影响。

示例：

```http
Set-Cookie: {cookie_name}=<random secure value>; HttpOnly
```
