<a id="description"></a>

## 描述

响应正文包含与 npm 访问令牌模式匹配的内容。访问令牌可以是经典版或细粒度，两者都允许自定义权限。根据权限，具有此令牌的恶意攻击者可以读取软件包和软件包信息，或创建新软件包并以创建它们的帐户发布。暴露此值可能允许攻击者获得此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中的[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

要从 UI 撤销访问令牌：

- 登录到您的 npm 帐户，网址为 <https://www.npmjs.com/login>
- 在右上角，选择您的个人资料图片，然后选择 **访问令牌**
- 找到被识别的令牌，并在 **删除** 列中选择 **x**
- 出现提示时，在对话框中选择 **确定**

有关更多信息，请参阅 [npm 关于撤销访问令牌的文档](https://docs.npmjs.com/revoking-access-tokens)。
