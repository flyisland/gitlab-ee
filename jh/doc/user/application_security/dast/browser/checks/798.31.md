<a id="description"></a>

## 描述

检测到响应正文中包含与 Dropbox 长期 API 令牌模式匹配的内容。这些令牌已于 2021 年弃用，详情请参见 <https://dropbox.tech/developers/migrating-app-permissions-and-access-tokens#introducing-scoped-apps>。
暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参见极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。
