<a id="description"></a>

## 描述

检测到响应体包含的内容匹配了 Dropbox 长期 API 令牌的模式。这些令牌已于 2021 年弃用，详情见 <https://dropbox.tech/developers/migrating-app-permissions-and-access-tokens#introducing-scoped-apps>。暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复建议

有关处理密钥泄露安全事件的一般指导，请参阅极狐GitLab 文档中的[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
