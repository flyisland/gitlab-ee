<a id="description"></a>

## 描述

响应正文中包含与 New Relic 用户 API ID 模式匹配的内容。泄露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。更多信息，请参阅 [New Relic 关于轮换 API 密钥的文档](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#rotate-keys)。
