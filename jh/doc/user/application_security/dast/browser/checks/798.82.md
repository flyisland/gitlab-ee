<a id="description"></a>

## 描述

响应体包含匹配 New Relic 用户 API ID 模式的内容。
暴露此值可能允许攻击者获取由此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

关于处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的文档。更多信息，请参阅 [New Relic 关于轮换 API 密钥的文档](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#rotate-keys)。
