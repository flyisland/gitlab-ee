<a id="description"></a>

## 描述

响应正文中包含与 PyPi 上传令牌模式匹配的内容。上传令牌用于上传软件包以发布 Python 软件包。获得该令牌访问权限的恶意行为者可以上传潜在的恶意产物。暴露此值可能使攻击者能够访问该令牌授予的所有资源。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。强烈建议改用 OIDC Connect，而不是使用 PyPi 上传令牌。请参阅 [PyPi 关于可信发布者的文档](https://docs.pypi.org/trusted-publishers/)。

要删除 PyPi 上传令牌：

- 登录您的 PyPi 账号并访问 <https://pypi.org/manage/account/>
- 向下滚动到“API 令牌（API tokens）”部分
- 找到已识别的令牌并选择“选项（Options）”下拉列表
- 选择“移除令牌（Remove token）”
- 出现提示时，输入您的密码并选择“移除 API 令牌（Remove API Token）”

有关更多信息，请参阅 [PyPi 关于上传令牌的文档](https://pypi.org/help/#apitoken)。
