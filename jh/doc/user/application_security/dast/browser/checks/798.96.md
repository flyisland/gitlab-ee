<a id="description"></a>

## 描述

响应正文中包含与 PyPi 上传令牌模式相匹配的内容。上传令牌用于上传发布 Python 包的软件包。获得此令牌的恶意行为者可以上传潜在的恶意产物。
暴露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理因密钥泄露而导致的安全事件的一般指南，请参阅极狐GitLab 文档中的[凭证暴露到公共互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。
强烈建议改用 OIDC Connect 而不要使用 PyPi 上传令牌。请参阅 [PyPi 关于受信任发布者的文档](https://docs.pypi.org/trusted-publishers/)。

要删除 PyPi 上传令牌：

- 登录你的 PyPi 账户并访问 <https://pypi.org/manage/account/>
- 向下滚动到“API 令牌”部分
- 找到被识别的令牌，然后选择“选项”下拉列表
- 选择“移除令牌”
- 提示时，输入你的密码并选择“移除 API 令牌”

更多信息，请参阅 [PyPi 关于上传令牌的文档](https://pypi.org/help/#apitoken)。
