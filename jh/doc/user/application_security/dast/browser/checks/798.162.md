## 描述

响应正文中包含与 Oculus 访问令牌模式匹配的内容。当您的应用代表特定用户调用 API 读取、修改或写入其 Oculus 数据时，都需要使用用户令牌。恶意行为者一旦获取此令牌，就可以代表该服务的特定用户调用 Oculus API。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换 Oculus 访问令牌：

- 登录您的 Oculus 开发者账号：<https://developer.oculus.com/>
- 在左侧菜单中选择“Development”，然后选择“API”
- 在“User Token”下选择“Generate Token”

有关更多信息，请参阅 [Meta 关于保护访问令牌的文档](https://developers.meta.com/horizon/resources/publish-sec-details#protecting-credentials-and-access-tokens)
