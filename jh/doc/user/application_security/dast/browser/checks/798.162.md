## 描述

响应正文中包含符合 Oculus 访问令牌模式的内容。每次您的应用调用 API 代表特定用户读取、修改或写入其 Oculus 数据时，都需要用户令牌。能够获取该令牌的恶意攻击者可以代表该服务的特定用户调用 Oculus API。
泄露此值可能让攻击者获得该令牌授权访问的所有资源。

<a id="remediation"></a>

## 修复

有关如何处理泄露密钥的安全事件的通用指导，请参见极狐GitLab 文档中的[凭证暴露在互联网上](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)。

轮换 Oculus 访问令牌的步骤：

- 登录 Oculus 开发者账号，访问 <https://developer.oculus.com/>
- 在左侧菜单中选择“Development”，然后选择“API”
- 在“User Token”下选择“Generate Token”

更多信息，请参见 [Meta 关于保护访问令牌的文档](https://developers.meta.com/horizon/resources/publish-sec-details#protecting-credentials-and-access-tokens)
