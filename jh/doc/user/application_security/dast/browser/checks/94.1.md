## 描述

目标应用被发现存在代码注入漏洞。恶意行为者可以注入任意 PHP 代码并在服务器上执行。这可能导致通过访问存储的密钥、注入代码接管账户或执行操作系统命令来使系统完全沦陷。

## 修复

永远不要将用户输入直接传递给将字符串数据作为代码执行的函数，例如 `eval`。
将字符串值传递给 `eval` 几乎没有任何益处，因此最佳的修复建议是用更安全的实现替换当前逻辑，以动态评估包含用户输入的逻辑。一种替代方法是使用 `array()`，将预期的用户输入存储在数组键（array key）中，并使用该键作为查找来执行函数：

```php
$func_to_run = function()
{
    print('hello world');
};

$function_map = array();
$function_map["fn"] = $func_to_run; // 在此处存储额外的输入到函数的映射

$input = "fn";

// 查找 "fn" 作为键（key）
if (array_key_exists($input, $function_map)) {
    // 运行存储在 "fn" 数组哈希值中的 $func_to_run。
    $func = $function_map[$input];
    $func();
} else {
    print('invalid input'); // 无效输入
}
```
