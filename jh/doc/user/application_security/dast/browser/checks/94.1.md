<a id="description"></a>

## 描述

目标应用程序被发现易受代码注入攻击。恶意行为者可以注入任意 PHP 代码在服务器上执行。这可能导致系统完全失陷，例如访问存储的密钥、注入代码以接管账号，或执行操作系统命令。

<a id="remediation"></a>

## 修复

切勿将用户输入直接传入会将字符串数据作为代码进行求值的函数，例如 `eval`。将字符串值传入 `eval` 几乎没有任何好处，因此最佳建议是将当前逻辑替换为更安全的实现，以根据用户输入动态求值逻辑。一种替代方案是使用 `array()`，将预期的用户输入存储在数组键中，并使用该键作为查找来执行函数：

```php
$func_to_run = function()
{
    print('hello world');
};

$function_map = array();
$function_map["fn"] = $func_to_run; // store additional input to function mappings here

$input = "fn";

// lookup "fn" as the key
if (array_key_exists($input, $function_map)) {
    // run the $func_to_run that was stored in the "fn" array hash value.
    $func = $function_map[$input];
    $func();
} else {
    print('invalid input');
}
```
