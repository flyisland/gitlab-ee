<a id="description"></a>

## 描述

响应正文中包含与 Flutterwave 测试密钥模式匹配的内容。密钥具有最高级别的权限，可以授权您账户上的任何操作。不过，这是测试密钥，因此只能用于模拟交易。能够访问此密钥的恶意行为者可以发送 webhook 和电子邮件事件。泄露此值可能使攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要轮换您的密钥：

- 登录并前往 <https://app.flutterwave.com/dashboard/home>
- 在左侧菜单中选择“设置”
- 在左侧菜单的“开发者”下选择“API 密钥”
- 确保已激活“测试模式”
- 选择“生成密钥”以轮换公钥、密钥和加密密钥

有关更多信息，请参阅 [Flutterwave 身份验证文档](https://developer.flutterwave.com/docs/authentication)。
