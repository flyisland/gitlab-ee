<a id="description"></a>

## 描述

响应正文中包含与 HashiCorp Terraform API 令牌模式匹配的内容。API 令牌可用于访问 HCP Terraform API。获得此令牌的恶意操作者可以执行用户账户有权执行的所有操作。暴露此值可能让攻击者获得该令牌授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复措施

有关处理与泄露密钥相关的安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭证暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的部分。

要撤销 API 令牌：

- 登录 Terraform HCP 控制台，访问 <https://app.terraform.io/app/settings/tokens>
- 找到已识别的令牌
- 选择令牌右侧的垃圾桶图标
- 当出现提示时，在“正在删除令牌...”对话框中，选择“确认”

更多信息，请参阅[Terraform 关于 API 令牌的文档](https://app.terraform.io/app/settings/tokens)。
