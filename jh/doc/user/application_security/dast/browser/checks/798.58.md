<a id="description"></a>

## 描述

响应正文中包含与 HashiCorp Terraform API 令牌模式匹配的内容。API 令牌可用于访问 HCP Terraform API。能够获取此令牌的恶意行为者可执行该用户账号有权执行的所有操作。泄露此值可能使攻击者获得该令牌所授予的全部资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。

要撤销 API 令牌：

- 登录 Terraform HCP 控制台并访问 <https://app.terraform.io/app/settings/tokens>
- 找到被识别出的令牌
- 选择该令牌右侧的垃圾桶图标
- 出现提示时，在“正在删除令牌...”对话框中选择“确认”

有关更多信息，请参阅 [Terraform 关于 API 令牌的文档](https://app.terraform.io/app/settings/tokens)。
