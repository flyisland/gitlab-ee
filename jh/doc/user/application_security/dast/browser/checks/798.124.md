<a id="description"></a>

## 描述

响应正文中包含与 Typeform 个人访问令牌模式匹配的内容。个人访问令牌用于访问 Typeform API。根据所分配的范围和权限，能够获取此令牌的恶意行为者可以读取、更新或删除表单数据。暴露此值可能使攻击者获得该令牌所授予的所有资源的访问权限。

<a id="remediation"></a>

## 修复

有关处理密钥泄露相关安全事件的一般指导，请参阅极狐GitLab 文档中关于[凭据暴露到互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要重新生成 Typeform API 令牌：- 登录您的 Typeform 账户并前往 <https://admin.typeform.com/> - 在右上角，选择您的个人资料图片，然后在“Account”下选择“Your settings” - 在左侧菜单中，选择“Personal tokens” - 在“token name”表格中，找到所识别的令牌，选择省略号，然后选择“Regenerate token”。有关更多信息，请参阅 [Typeform 关于个人访问令牌的文档](https://www.typeform.com/developers/get-started/personal-access-token/)。
