## 描述

检测到响应正文中包含匹配 Typeform 个人访问令牌模式的内容。个人访问令牌用于访问 Typeform API。根据分配的权限范围和权限，获得此令牌的恶意行为者可以读取、更新或删除表单数据。
泄露此值可能允许攻击者获取此令牌授予的所有资源的访问权限。

## 修复措施

关于处理因密钥泄露导致的安全事件的一般性指导，请参阅极狐GitLab 文档中关于[凭据暴露于互联网](../../../../../security/responding_to_security_incidents.md#credential-exposure-to-public-internet)的内容。要重新生成 Typeform API 令牌：
- 登录您的 Typeform 账户并访问 <https://admin.typeform.com/>
- 在右上角，选择您的个人资料图片，然后在“Account”下选择“Your settings”
- 在左侧菜单中，选择“Personal tokens”
- 在“token name”表中，找到已识别的令牌，选择省略号，然后选择“Regenerate token”
更多信息，请参阅[Typeform 关于个人访问令牌的文档](https://www.typeform.com/developers/get-started/personal-access-token/)。
