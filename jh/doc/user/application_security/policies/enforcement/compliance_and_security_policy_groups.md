集中式安全策略管理允许实例管理员指定一个合规与安全策略群组，以便从单一集中位置跨多个群组和项目应用安全策略。

当您在合规与安全策略群组中创建或编辑安全策略时，可以将该群组限定为在以下范围内强制执行该策略：

- **特定群组和子群组**：仅将策略应用于选定的群组及其子群组。
- **特定项目**：将策略应用于单个项目。
- **实例中的所有项目**：将策略应用于整个极狐GitLab 实例。
- **除指定项目外的所有项目**：应用于除您指定的项目之外的所有项目。

当您指定一个合规与安全策略群组作为集中式策略管理中枢时，您可以：

- 创建并配置自动应用于整个实例的安全策略。
- 将策略限定到特定群组、项目或整个实例。
- 查看全面的策略覆盖情况，了解哪些策略处于活动状态以及它们在何处生效。
- 在保持集中控制的同时，允许团队创建自己的附加策略。

<a id="prerequisites"></a>

## 先决条件

- 极狐GitLab 私有化部署。
- 极狐GitLab 18.2 或更高版本。
- 您必须是实例管理员。
- 您必须有一个现有的顶级群组来充当合规与安全策略群组。
- 要使用 REST API（可选），您必须拥有具有管理员访问权限的令牌。

<a id="set-up-centralized-security-policy-management"></a>

## 设置集中式安全策略管理

要设置集中式安全策略管理，您需要指定一个合规与安全策略群组，然后在该群组中创建策略。

有关更多信息，请参阅[实例级合规与安全策略管理](../../../../security/compliance_security_policy_management.md)。

<a id="enable-global-approval-groups"></a>

### 启用全局审批群组

要在整个实例中全局支持审批群组，您必须：

- 在[极狐GitLab 实例应用设置](../../../../api/settings.md)中启用 `security_policy_global_group_approvers_enabled`。

<a id="create-security-policies-in-the-compliance-and-security-policy-group"></a>

### 在合规与安全策略群组中创建安全策略

要创建策略：

1. 转到您指定的合规与安全策略群组。
1. 转到**安全** > **策略**。
1. 按您通常的方式创建一个或多个安全策略。在保存每个策略之前：
   - 在**策略范围**部分，选择一个范围以将策略应用于：
     - **群组**：将策略应用于特定群组和子群组。
     - **项目**：将策略应用于单个项目。
     - **所有项目**：应用于整个实例。
     - **除以下项目外的所有项目**：应用于具有指定例外的所有项目。
1. 保存您的策略配置。

<a id="policy-storage-and-configuration"></a>

## 策略存储与配置

合规与安全策略群组中的策略存储在指定合规与安全策略群组中的 `policy.yml` 文件中，与群组策略的管理方式类似。在合规与安全策略群组中创建的策略使用与其他群组和项目中的安全策略相同的配置格式。

<a id="policy-synchronization"></a>

## 策略同步

- 根据范围内群组和项目的数量，策略更改可能需要一些时间才能在整个实例中应用。
- 同步过程使用后台作业，当您指定合规与安全策略群组、创建策略或更新策略时，这些作业会自动排队。
- 实例管理员可以在**管理员** > **监控** > **后台作业**中监控后台作业处理情况。
- 要验证策略是否已成功应用于目标群组或项目，请转到该群组或项目中的**安全** > **策略**。

<a id="managing-performance"></a>

### 管理性能

为避免性能问题，请规划您的策略管理策略，以尽量减少对配置的修改次数：

- 谨慎规划更改：避免在短时间内连续进行多次合规与安全策略群组更改。
- 在维护窗口期间安排更改：在低使用率时段进行更改，以尽量减少对用户的影响。
- 监控系统性能：为同步期间可能出现的性能下降做好准备。
- 预留额外时间：同步过程的完成时间取决于您的实例规模。

<a id="troubleshooting"></a>

## 故障排除

**策略未出现在目标群组或项目中**

- 验证策略范围是否包含目标群组或项目。
- 验证合规与安全策略群组是否已在管理员设置中正确指定。
- 验证策略是否已在合规与安全策略群组中启用。
- 策略更改可能需要一些时间才能应用。有关更多信息，请参阅[策略同步](#policy-synchronization)。

**性能问题**

- 监控策略传播时间，尤其是在范围配置较大的情况下。
- 考虑将策略限定到特定群组或项目，而不是将策略应用于所有项目。
- 要减少修改合规安全策略群组时的性能影响，请参阅[管理性能](#managing-performance)。
