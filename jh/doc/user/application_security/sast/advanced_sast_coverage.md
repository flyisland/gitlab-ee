[极狐GitLab Advanced SAST](gitlab_advanced_sast.md) 可在[受支持的语言](gitlab_advanced_sast.md#supported-languages)编写的代码中发现多种类型的潜在安全漏洞。

极狐GitLab 会为每个潜在漏洞分配一个匹配的[通用弱点枚举（CWE）](https://cwe.mitre.org)标识符。CWE 标识符是识别安全弱点的行业标准方式，但需要注意以下几点：

- CWE 采用树状结构组织。
  例如，[CWE-22：路径遍历](https://cwe.mitre.org/data/definitions/22.html)是 [CWE-23：相对路径遍历](https://cwe.mitre.org/data/definitions/23.html)的父级。
  专门检测相对路径遍历弱点（CWE-23）的扫描器，按定义也会检测到更通用的路径遍历类别（CWE-22）的一部分。
- 为清晰起见，此表列出的是分配给极狐GitLab Advanced SAST 规则的确切 CWE 标识符。
  它不会报告父级标识符。

要详细了解极狐GitLab Advanced SAST 中使用的规则，请参阅 [SAST 规则](rules.md#gitlab-advanced-sast)。
