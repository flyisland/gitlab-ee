[极狐GitLab Advanced SAST](gitlab_advanced_sast.md) 可以在 [支持的语言](gitlab_advanced_sast.md#supported-languages) 编写的代码中发现多种潜在的安全漏洞。

极狐GitLab 会为每个潜在的漏洞分配一个匹配的 [通用缺陷枚举 (CWE)](https://cwe.mitre.org) 标识符。
CWE 标识符是识别安全缺陷的行业标准方法，但需要了解以下几点：

- CWE 是按树形结构排列的。
  例如，[CWE-22：路径遍历](https://cwe.mitre.org/data/definitions/22.html) 是 [CWE-23：相对路径遍历](https://cwe.mitre.org/data/definitions/23.html) 的父级。
  如果一个扫描器专门检测相对路径遍历缺陷 (CWE-23)，那么根据定义，它也检测了一部分更通用的路径遍历类别 (CWE-22)。
- 为了清晰起见，此表格标识了分配给极狐GitLab Advanced SAST 规则的确切 CWE 标识符。
  它不报告父级标识符。

要了解有关极狐GitLab Advanced SAST 中所用规则的更多信息，请参阅 [SAST 规则](rules.md#gitlab-advanced-sast)。
