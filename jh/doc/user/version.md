查找您正在运行的极狐GitLab 版本。

<a id="for-gitlab-self-managed-and-gitlab-dedicated"></a>

## 对于极狐GitLab 私有化部署

先决条件：

- 您必须是已通过身份验证的用户。

要查找极狐GitLab 版本：

- 在左侧边栏底部，选择**帮助** > **帮助**。

版本显示在页面顶部。

<a id="for-gitlabcom"></a>

## 对于 JihuLab.com

- 前往 <https://jihulab.com/help>。

版本显示在页面顶部。例如，`GitLab Enterprise Edition 18.10.0-pre bc9e216d399` 表示极狐GitLab 18.10 的预发布版本。
