# 群组代码仓分析

群组代码仓分析提供群组中所有项目的测试覆盖率数据。

你可以使用群组代码仓分析来：

- 监控群组中所有项目的代码覆盖率趋势。
- 跟踪生成覆盖率报告的项目和作业总数。
- 下载历史覆盖率数据进行分析。

<a id="view-group-repository-analytics"></a>

## 查看群组代码仓分析

先决条件：

- 群组中的项目必须配置为收集测试覆盖率数据。

要查看群组的代码仓分析：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到你的群组。
2. 在左侧边栏中，选择 **分析** > **代码仓分析**。

<a id="coverage-metrics"></a>

## 覆盖率指标

群组 **代码仓分析** 页面显示：

- **当前群组代码覆盖率**：
  - 有覆盖率报告的项目数量。
  - 所有项目的平均覆盖率百分比。
  - 产生覆盖率报告的流水线作业总数。
- **平均测试覆盖率**：一个图表，显示过去 30 天内群组中所有项目的平均测试覆盖率。
- **最新测试覆盖率结果**：群组中每个项目的最新覆盖率数据列表。从下拉列表中选择项目以过滤结果。

<a id="download-coverage-data"></a>

## 下载覆盖率数据

你可以下载包含群组项目历史覆盖率数据的 CSV 文件。

CSV 报告：

- 最多包含 1000 条记录。
- 包含每个项目默认分支的数据。
- 当有覆盖率报告时，每天显示一行。
- 如果一天内生成多个覆盖率报告，则使用当天的最后一个值。
- 每个覆盖率报告包含以下信息：
  - 覆盖率作业运行日期
  - 生成报告的作业名称
  - 项目名称
  - 覆盖率百分比

要下载覆盖率数据：

1. 在群组 **代码仓分析** 页面上，选择 **下载历史测试覆盖率数据 (.csv)**。
2. 选择要包含的项目：
   - 从 **项目** 下拉列表中，选择特定项目。项目下拉列表最多显示 100 个项目。
   - 可选。选择 **全选** 以包含群组中的所有项目。
3. 从 **日期范围** 下拉列表中，选择要包含的时间段。
4. 选择 **下载测试覆盖率数据 (.csv)**。
