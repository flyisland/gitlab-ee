你可以使用命令面板来缩小搜索范围或更快地查找对象。

<a id="open-the-command-palette"></a>

## 打开命令面板

要打开命令面板：

1. 在顶部栏中，选择 **搜索或跳转到**，或者使用 <kbd>/</kbd> 键来启用。
1. 输入以下特殊字符之一：

   - <kbd>></kbd> - 创建新对象或查找菜单项。
   - <kbd>@</kbd> - 搜索用户。
   - <kbd>:</kbd> - 搜索项目。
   - <kbd>~</kbd> - 在默认代码仓分支中搜索项目文件。
