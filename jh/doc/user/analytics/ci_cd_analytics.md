使用 CI/CD 分析，深入了解您的流水线性能和成功率。

CI/CD 分析页面直接在极狐GitLab UI 中提供关键 CI/CD 流水线指标的可视化。这些可视化图表可帮助开发团队快速了解其软件开发流程的健康状况和效率。

<a id="view-cicd-analytics"></a>

## 查看 CI/CD 分析

要查看 CI/CD 分析：

1. 在顶部栏中，选择**搜索或跳转到**，然后找到您的项目。
1. 在左侧边栏中，选择**分析** > **CI/CD 分析**。

<a id="pipeline-metrics"></a>

## 流水线指标

您可以查看流水线成功和失败的历史记录，以及每条流水线的运行时长。流水线统计信息通过收集项目中所有可用的流水线来汇总，无论其状态如何。每天可用的数据取决于流水线的启动时间。

CI/CD 分析会显示有关您流水线的关键指标：

- **流水线运行总数**：所选时间段内运行的流水线总数。流水线总数计算包括子流水线以及因 YAML 无效而失败的流水线。
  要根据其他属性筛选流水线，请使用[流水线 API](../../api/pipelines.md#list-project-pipelines)。
- **中位时长**：流水线完成所需的中位时间。
- **失败率**：失败的流水线所占百分比。
- **成功率**：成功完成的流水线所占百分比。
- **其他比率**：被跳过或取消的流水线所占百分比。

<a id="filter-your-results"></a>

## 筛选结果

您可以筛选分析数据，以聚焦特定方面：

- **来源**：按流水线触发来源筛选。
- **分支**：按流水线运行所在的分支筛选。
- **日期范围**：选择要分析的时间段（例如，上周）。

通过筛选，您可以分析特定工作流组件的性能，或比较不同分支。

<a id="pipeline-duration-chart"></a>

## 流水线时长图表

时长图表显示您的流水线执行时间随时间的变化情况。该图表显示：

- **中位数（第 50 百分位）**：典型的流水线时长。
- **第 95 百分位**：95% 的流水线在此时间内或更短时间内完成，只有 5% 需要更长时间。

此可视化图表可帮助您识别流水线时长的趋势，从而帮助您判断 CI/CD 流程随时间的效率。

<a id="pipeline-status-chart"></a>

## 流水线状态图表

状态图表显示流水线状态随时间的分布情况：

- **成功**：无错误完成的流水线。
- **失败**：因错误而未能成功完成的流水线。
- **其他**：处于其他状态（已取消、已跳过）的流水线。

此可视化图表可帮助您跟踪流水线的稳定性，并识别失败率较高的时间段。

<a id="cicd-job-performance-metrics"></a>

## CI/CD 作业性能指标

{{< details >}}

- Tier: 专业版，旗舰版
- Offering: JihuLab.com
- Status: 有限可用性

{{< /details >}}

> [!note]
> 默认情况下，极狐GitLab 私有化部署上不可用。
> 要在极狐GitLab 私有化部署实例上查看 CI/CD 作业性能指标，您必须配置 [ClickHouse](../../integration/clickhouse.md)。

CI/CD 作业性能趋势使开发者能够快速识别低效或有问题的 CI/CD 作业。通过将这些功能直接集成到极狐GitLab UI 中，开发者可以掌握相关背景信息，从而定位并修复 CI/CD 性能问题。

作业性能指标让您能够识别瓶颈、监控作业可靠性，并将优化工作集中在对整体流水线时长影响最大的作业上。

作业性能部分会显示所选时间段内您流水线中每个作业的指标：

- **作业名称**：CI/CD 作业的名称。
- **P50 时长**（中位数）：此作业的典型执行时间。一半的作业运行完成得更快，一半需要更长时间。
- **P95 时长**：95% 的作业运行在此时间内完成。使用此指标可识别异常值和最坏情况。
- **失败率**：失败的作业运行所占百分比。比率越高，表明可靠性问题越严重，需要调查。

默认情况下，表格按平均时长排序（运行时间最长的作业排在最前）。表格每页显示 10 个作业，并带有分页控件。您可以选择任意列标题以按该指标排序，或使用搜索栏按名称查找特定作业。
