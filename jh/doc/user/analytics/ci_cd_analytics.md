使用 CI/CD 分析来深入了解您的流水线性能和成功率。

CI/CD 分析页面直接在极狐GitLab UI 中提供关键 CI/CD 流水线指标的可视化展示。这些可视化展示可以帮助开发团队快速了解其软件开发过程的健康状况和效率。

<a id="view-cicd-analytics"></a>

## 查看 CI/CD 分析

{{< history >}}

- 在极狐GitLab 18.0 中更新，通过使用 ClickHouse 作为数据源（当可用时）来改进分析。

{{< /history >}}

要查看 CI/CD 分析：

1. 在顶部栏中，选择**搜索或跳转到**并找到您的项目。
1. 在左侧边栏中，选择**分析** > **CI/CD 分析**。

<a id="pipeline-metrics"></a>

## 流水线指标

您可以查看流水线成功和失败的历史记录，以及每个流水线的运行时长。流水线统计数据通过收集项目中所有可用的流水线来获取，无论其状态如何。每天可用的数据基于流水线开始的时间。

CI/CD 分析显示了关于流水线的关键指标：

- **总流水线运行次数**：所选时间段内运行的流水线总数。总流水线计算包括子流水线和因 YAML 无效而失败的流水线。
  要根据其他属性过滤流水线，请使用 [流水线 API](../../api/pipelines.md#list-project-pipelines)。
- **时长中位数**：流水线完成所需时间的中位数。
- **失败率**：失败流水线的百分比。
- **成功率**：成功完成的流水线的百分比。
- **其他率**：被跳过或取消的流水线的百分比。

<a id="filter-your-results"></a>

## 筛选结果

您可以对分析数据进行筛选，以聚焦特定方面：

- **来源**：按流水线触发源筛选。
- **分支**：按流水线运行所在的分支筛选。
- **日期范围**：选择要分析的时间段（例如，上周）。

通过筛选，您可以分析特定工作流组件的性能，或比较不同分支。

<a id="pipeline-duration-chart"></a>

## 流水线时长图表

时长图表显示了流水线执行时间随时间的变化情况。该图表展示：

- **中位数（第 50 百分位）**：典型的流水线时长。
- **第 95 百分位**：95% 的流水线在此时间内或更短时间内完成，而只有 5% 花费更长时间。

此可视化有助于您识别流水线时长的趋势，从而帮助您判断 CI/CD 流程随时间的效率变化。

<a id="pipeline-status-chart"></a>

## 流水线状态图表

状态图表显示了流水线状态随时间的分布情况：

- **成功**：完成且没有错误的流水线。
- **失败**：因错误而未成功完成的流水线。
- **其他**：其他状态的流水线（已取消、已跳过）。

此可视化有助于您追踪流水线的稳定性，并识别出失败率较高的时段。

<a id="cicd-job-performance-metrics"></a>

## CI/CD 作业性能指标

{{< details >}}

- Tier: 专业版，旗舰版
- Offering: JihuLab.com
- Status: 有限可用性

{{< /details >}}

{{< history >}}

- 在极狐GitLab 18.9 中引入，为有限可用性。

{{< /history >}}

> [!note]
> 默认不适用于私有化部署。
> 要在私有化部署实例上查看 CI/CD 作业性能指标，必须配置 [ClickHouse](../../integration/clickhouse.md)。

CI/CD 作业性能趋势使开发者能够快速识别低效或有问题的 CI/CD 作业。通过将这些功能直接集成到极狐GitLab UI 中，开发者有了定位和修复 CI/CD 性能问题的上下文。

作业性能指标使您能够识别瓶颈、监控作业可靠性，并将优化工作重点放在对整体流水线时长影响最大的作业上。

作业性能部分显示了所选时间段内流水线中每个作业的指标：

- **作业名称**：CI/CD 作业的名称。
- **P50 时长**（中位数）：此作业的典型执行时间。一半的作业运行在此时间内完成，另一半花费更长时间。
- **P95 时长**：95% 的作业运行在此时间内完成。使用此指标可识别异常值和最坏情况。
- **失败率**：作业运行失败的百分比。较高的失败率表明存在可靠性问题，需要调查。

默认情况下，表格按平均时长排序（运行时间最长的作业优先）。表格每页显示 10 个作业，并带有分页控件。您可以选择任意列标题按该指标排序，或使用搜索栏按名称查找特定作业。
