链接的项可在工作项之间创建双向关系，帮助您在整个工作流中直观呈现并管理依赖关系。

借助链接的项，您可以连接各种工作项，包括议题、史诗、任务和目标，以展示它们之间的关系。

这些连接可帮助所有人了解各个工作项之间以及它们与更大战略计划之间的关系。

<a id="ways-to-use-linked-items"></a>

## 链接的项的使用方式

您可以使用链接的项来解决多种规划与协调方面的难题。

以下示例展示了链接的项如何帮助团队更高效地协作。

<a id="track-dependencies"></a>

### 跟踪依赖关系

{{< details >}}

- Tier: 专业版，旗舰版

{{< /details >}}

清晰识别会阻塞其他项或被其他项阻塞的工作。

当您以阻塞关系链接各项时：

- 团队可以立即看到自己依赖哪些其他工作。
- 状态更新会在链接的项之间自动流转。
- 关闭存在未解决阻塞项的项时，会显示警告。
- 团队可以主动处理依赖关系，从而避免延误。

这种可见性有助于跨团队协调工作，并减少瓶颈。

<a id="connect-strategic-goals-with-implementation-details"></a>

### 将战略目标与实施细节关联起来

使用链接的项将高层规划与日常执行关联起来。

当您将战略目标与战术任务链接时：

- 团队可以了解自己的工作如何为更大的目标做出贡献。
- 相关方可以追踪从战略到实施的进展。
- 所有人都能了解各项具体工作如何支持更宏大的愿景。
- 战略变化可以快速追溯到受影响的实施工作。

这种层级之间的关联可在整个组织中建立一致性和目标感。

<a id="organize-cross-functional-initiatives"></a>

### 组织跨职能计划

跨不同团队和项目链接相关工作，以协调复杂的计划。

当您将链接的项用于跨职能工作时：

- 每个团队都可以在自己的领域内工作，同时保持与相关工作的连接。
- 专业团队之间的依赖关系变得可见。
- 状态更新会在相关项之间自动流转。
- 团队无需频繁开会即可协调工作。

这种协调有助于打破孤岛，并确保计划的各个方面保持同步。

<a id="types-of-linked-items"></a>

## 链接的项的类型

极狐GitLab 支持链接多种类型的工作项：

- [议题](../project/issues/related_issues.md)可帮助您跟踪任务、缺陷和功能，并可
  通过链接展示各项独立工作之间的依赖关系。
- [史诗](../group/epics/linked_epics.md)可让您管理跨职能计划、展示
  依赖关系，并将战略规划与跨多个团队或项目的执行关联起来。
  适用于旗舰版。
- [任务](../tasks.md#linked-items-in-tasks)为较小的工作单元提供轻量级跟踪，
  并可链接到其他项，以展示项目中的关系或依赖关系。
- [目标和关键结果](../okrs.md#linked-items-in-okrs)有助于将战略目标与
  执行细节关联起来，确保日常工作始终与更高层级的组织
  优先事项保持一致。
- [事件](../../operations/incident_management/incidents.md)表示需要紧急恢复的服务中断或
  故障，可链接到相关工作项，以便更好地跟踪
  运维问题及其对计划工作的影响。
- [测试用例](../../ci/test_cases/_index.md)将测试规划直接集成到您的极狐GitLab
  工作流中，让团队可以在管理代码的同一平台上记录测试场景并跟踪需求。
  适用于旗舰版。

<a id="relationship-types"></a>

## 关系类型

链接各项时，您可以指定关系类型：

- **关联到**：表示各项之间的一般关系。
- **阻塞**：表示某项会阻止另一项取得进展。
- **被阻塞**：表示某项在另一项解决之前无法继续。

<a id="common-tasks-with-linked-items"></a>

## 链接的项的常见任务

通过以下常见操作，了解如何创建和管理工作项之间的关系。

<a id="add-a-linked-item"></a>

### 添加链接的项

先决条件：

- 您必须对两个项所属的项目或群组具有访客、计划者、报告者、开发者、维护者或所有者角色。

添加链接的项的通用流程在所有工作项类型中类似：

1. 转到您要修改的工作项。
1. 在描述底部，找到工作项的**链接的项**部分。
1. 选择**添加**。
1. 选择关系类型：**关联到**、**阻塞**或**被阻塞**。
1. 输入要链接的项的引用。您可以：
   - 输入 `#` 或 `&`（取决于项类型），后跟项的编号。
   - 输入文本以按标题搜索该项。
   - 粘贴该项的完整 URL。
1. 选择**添加**以确认。

或者，您可以使用[快速操作](../project/quick_actions.md)添加链接的项：

- `/relate`
- `/blocks`
- `/blocked_by`

有关各工作项类型的详细信息，请参阅相关文档：

- [链接的议题](../project/issues/related_issues.md#add-a-linked-issue)
- [链接的史诗](../group/epics/linked_epics.md#add-a-linked-item)
- [链接的任务](../tasks.md#linked-items-in-tasks)
- [链接的 OKR](../okrs.md#linked-items-in-okrs)

<a id="remove-a-linked-item"></a>

### 移除链接的项

先决条件：

- 您必须对两个项所属的项目或群组具有访客、计划者、报告者、开发者、维护者或所有者角色。

要移除链接的项：

1. 转到您要修改的工作项。
1. 在描述底部，找到工作项的**链接的项**部分。
1. 对于每个链接的项，选择**移除**（{{< icon name="close" >}}）。

双向关系会从两个项中移除。

或者，您可以使用 [`/unlink` 快速操作](../project/quick_actions.md#unlink)移除链接的项。

<a id="configure-linked-item-display-preferences"></a>

### 配置链接的项显示偏好

您可以配置**链接的项**部分中显示的信息，以便专注于对您的工作流最重要的内容。

> [!note]
> 当您更改工作项中显示的信息时，您会更改项目和群组中所有工作项的显示信息。

1. 在**链接的项**部分标题的右上角，选择**显示选项**（{{< icon name="preferences" >}}）。

   默认情况下，所有选项和字段均可见。
1. 要更改显示的信息，请打开或关闭以下开关：

   - 对于显示选项：
     - **显示已关闭的项**
   - 对于显示的字段：
     - **状态**
     - **指派人**
     - **标记**
     - **权重**
     - **里程碑**
     - **迭代**
     - **日期**
     - **健康状况**
     - **被阻塞/阻塞中**
