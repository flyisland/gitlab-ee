子项是嵌套在父工作项下的工作项。这创建了一个用于组织和跟踪工作的层级结构。

子项可以是：

- 嵌套在父史诗下的子史诗。
- 分配给史诗的议题，例如功能或缺陷。
- 可以作为议题子项的任务。

```plaintext
Parent epic
|─ Child epic
   |─ Issue
      |- Task
   |─ Issue
      |- Task
   |─ Issue
  ```

您可以使用子项来解决多个规划和协调难题。

以下示例展示了子项如何帮助团队更有效地协同工作。

<a id="view-all-child-items-assigned-to-a-parent-work-item"></a>

## 查看分配给父工作项的所有子项

在“子项”部分，您可以查看分配给史诗的史诗、议题和任务。

您还可以查看由后代项继承的任何史诗、议题和任务。

只有您可以访问的史诗、议题和任务才会显示在列表中。

如果议题位于群组的子项目中，您可以查看分配给史诗的议题。这是因为项目的可见性设置必须与其父群组相同或限制更少。

<a id="track-work-item-progress"></a>

## 跟踪工作项进度

您可以使用不同的标准来跟踪工作项的进度。

<a id="view-count-and-weight-of-issues-in-an-epic"></a>

### 查看史诗中议题的数量和权重

在史诗的**子项**部分标题中，会显示后代工作项的数量及其总权重。任务权重包含在议题总权重中。

要查看未关闭和已关闭工作项的数量，请在部分标题中或每个史诗名称下，将鼠标悬停在总数上。

这些数字反映了与该史诗关联的所有子工作项，包括您可能无权查看的那些。

<a id="view-epic-progress"></a>

### 查看史诗进度

在史诗的**子项**部分标题中，会显示史诗进度百分比。

要查看子项的已完成权重和总权重，请在部分标题中将鼠标悬停在百分比上。

任务作为子议题百分比的一部分包含在进度百分比中。

权重和进度反映了与该史诗关联的所有议题，包括您可能无权查看的议题。

<a id="add-child-items"></a>

## 添加子项

您可以：

- 将现有工作项添加为子项，包括来自不同群组层级的项目中的工作项。
- 创建一个新工作项，并自动将其添加为子项。

<a id="add-an-issue-to-an-epic"></a>

### 将议题添加到史诗

将现有议题添加到史诗，或创建一个新议题并自动添加到史诗中。

直接子议题和子史诗的最大数量为 5000。

<a id="add-an-existing-issue-to-an-epic"></a>

#### 将现有议题添加到史诗

您可以将现有议题添加到史诗，包括来自[不同群组层级](../group/epics/_index.md#child-issues-from-different-group-hierarchies)的项目中的议题。

新添加的议题会显示在**子项**部分议题列表的顶部。

史诗包含一个议题列表，一个议题最多可以设置为一个史诗的子项。当您添加一个已关联到史诗的新议题时，该议题会自动与其当前父项解除关联。

先决条件：

- 您必须对议题所在项目拥有访客、计划者、报告者、开发者、维护者或所有者角色。
- 您必须有权[查看史诗](../group/epics/manage_epics.md#who-can-view-an-epic)。
  不要求在史诗所在群组中拥有角色。
  项目属于史诗所在群组或其任何后代群组即可。

要将现有议题添加到史诗：

1. 在史诗页面上，在**子项**下，选择**添加**。
1. 选择**现有议题**。
1. 使用以下任一方法确定要添加的议题：
   - 粘贴议题的链接。
   - 通过输入议题标题的一部分来搜索所需议题，然后选择所需的匹配项。来自不同群组层级的议题不会出现在搜索结果中。
     要添加此类议题，请输入其完整 URL。

   如果要添加多个议题，请按 <kbd>空格</kbd> 并重复此步骤。
1. 选择**添加**。

<a id="create-an-issue-from-an-epic"></a>

#### 从史诗创建议题

从史诗创建议题使您能够在将工作划分为更小部分的同时，保持对史诗更广泛背景的关注。

您只能在史诗所在群组或其一个后代子群组中的项目中，从史诗创建新议题。
要在[与史诗所在群组共享的项目](../project/members/sharing_projects_groups.md)中创建新议题，
请先[直接在项目中创建议题](../project/issues/create_issues.md#from-a-project)，然后[将现有议题添加到史诗](#add-an-existing-issue-to-an-epic)。

先决条件：

- 您必须对议题所在项目和史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要从史诗创建议题：

1. 在史诗页面上，在**子项**下，选择**添加**。
1. 选择**添加新议题**。
1. 在**标题**下，输入新议题的标题。
1. 从**项目**下拉列表中，选择应在其中创建议题的项目。
1. 选择**创建议题**。

新议题将分配给该史诗。

<a id="reorganize-child-items"></a>

## 重新组织子项

您可以对子项重新排序，并在层级结构中重新组织它们。

<a id="reorder-issues-assigned-to-an-epic"></a>

### 对分配给史诗的议题重新排序

新议题显示在**子项**部分列表的顶部。您可以通过拖动来对议题列表重新排序。

先决条件：

- 您必须对议题所在项目和史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要对分配给史诗的议题重新排序：

1. 转到**子项**部分。
1. 将议题拖动到所需顺序。

<a id="move-issues-between-epics"></a>

### 在史诗之间移动议题

{{< details >}}

- Tier: 旗舰版
- Offering: JihuLab.com，私有化部署

{{< /details >}}

新议题显示在**子项**选项卡列表的顶部。您可以将议题从一个史诗移动到另一个史诗。

先决条件：

- 您必须对议题所在项目和史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要将议题移动到另一个史诗：

1. 转到**子项**部分。
1. 在可见层级结构中将议题拖动到所需的父史诗中。

<a id="moving-child-items-when-the-parent-issue-is-moved"></a>

### 移动父议题时移动子项

当您将议题移动到另一个项目时，其所有子项也会移动到目标项目，并继续作为所移动议题的子项。每个工作项都以与父项相同的方式移动，即它在原项目中被关闭，并复制到目标项目。

<a id="remove-an-issue-from-an-epic"></a>

### 从史诗中移除议题

您可以在史诗详情页面上从史诗中移除议题。从史诗中移除议题后，该议题将不再与此史诗关联。

先决条件：

- 您必须对议题所在项目拥有访客、计划者、报告者、开发者、维护者或所有者角色。
- 您必须有权[查看史诗](../group/epics/manage_epics.md#who-can-view-an-epic)。
  不要求在史诗所在群组中拥有角色。
  项目属于史诗所在群组或其任何后代群组即可。

要从史诗中移除议题：

1. 在要移除的议题旁边，选择**移除**（{{< icon name="close" >}}）。
   将出现**移除议题**警告。
1. 选择**移除**。

<a id="work-with-multi-level-hierarchies"></a>

## 使用多级层级结构

{{< details >}}

- Tier: 旗舰版
- Offering: JihuLab.com，私有化部署

{{< /details >}}

史诗可以包含多个嵌套的子史诗。您可以通过以下方式使用这些多级子史诗：

- 通过向现有史诗添加父史诗来创建史诗层级结构。
- 添加属于与父史诗所在群组不同的群组的子史诗。
- 在路线图上查看史诗的子史诗和相关里程碑。
- 从史诗中添加、移动、重新排序和移除子史诗。

史诗可以包含多个嵌套的子史诗，总共最多 7 层深。

<a id="add-a-parent-epic-to-an-epic"></a>

### 向史诗添加父史诗

要创建史诗层级结构，请向现有史诗添加父史诗。这有助于在多个史诗之间组织和跟踪相关工作。

先决条件：

- 您必须对父史诗所在群组或子史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要添加父史诗：

1. 在顶部栏中，选择**搜索或跳转到**并找到您的群组。
1. 选择**计划** > **工作项**。
1. 选择一个史诗。
1. 在右侧边栏的**父项**部分中，选择**编辑**。
1. 在搜索框中，输入父史诗标题的一部分。
   您只能搜索同一群组层级中的史诗。
1. 从搜索结果中，选择要添加为父项的史诗。

父史诗已添加。

<a id="child-epics-from-other-groups"></a>

### 来自其他群组的子史诗

添加属于与父史诗所在群组不同的群组的子史诗。

先决条件：

- 您必须对子史诗和父史诗所在群组都拥有访客、计划者、报告者、开发者、维护者或所有者角色。
- 多级子史诗必须对子史诗和父史诗所在群组都可用。

要从另一个群组添加子史诗，请在[添加现有史诗](#add-a-child-epic-to-an-epic)时粘贴该史诗的 URL。

<a id="view-child-epics-on-a-roadmap"></a>

### 在路线图上查看子史诗

从史诗中，在[路线图](../group/roadmap/_index.md)上查看其子史诗和相关里程碑。

先决条件：

- 您必须对父史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要从父项查看子史诗：

- 在**子项**部分标题中，选择**显示选项**（{{< icon name="preferences" >}}）>
  **在路线图上查看**。

<a id="add-a-child-epic-to-an-epic"></a>

### 向史诗添加子史诗

先决条件：

- 您必须对父史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

<a id="new-epic"></a>

#### 新史诗

要将新史诗添加为子史诗：

1. 在史诗中，在**子项**部分，选择**添加** > **添加新史诗**。
1. 从下拉列表中选择一个群组。默认选择史诗所在群组。
1. 输入新史诗的标题。
1. 选择**创建史诗**。

<a id="existing-epic"></a>

#### 现有史诗

要将现有史诗添加为子史诗：

1. 在史诗中，在**子项**部分，选择**添加** > **现有史诗**。
1. 使用以下任一方法确定要添加的史诗：
   - 粘贴史诗的链接。
   - 通过输入史诗标题的一部分来搜索所需史诗，然后选择所需的匹配项。此搜索仅适用于同一群组层级中的史诗。

   如果要添加多个史诗，请按 <kbd>空格</kbd> 并重复此步骤。
1. 选择**添加**。

<a id="move-child-epics-between-epics"></a>

### 在史诗之间移动子史诗

新的子史诗显示在**子项**部分列表的顶部。您可以将子史诗从一个史诗移动到另一个史诗。当您添加一个已关联到父史诗的新史诗时，其与当前父项的关联将被移除。议题和子史诗不能混在一起。

先决条件：

- 您必须对父史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要将子史诗移动到另一个史诗：

1. 转到**子项**部分。
1. 将史诗拖动到所需的父史诗中。

<a id="reorder-child-epics-assigned-to-an-epic"></a>

### 对分配给史诗的子史诗重新排序

新的子史诗显示在**子项**部分列表的顶部。您可以对子史诗列表重新排序。

先决条件：

- 您必须对父史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要对分配给史诗的子史诗重新排序：

1. 转到**子项**部分。
1. 将史诗拖动到所需顺序。

<a id="remove-a-child-epic-from-a-parent-epic"></a>

### 从父史诗中移除子史诗

先决条件：

- 您必须对父史诗所在群组拥有访客、计划者、报告者、开发者、维护者或所有者角色。

要从父史诗中移除子史诗：

1. 在父史诗的史诗列表中选择**移除**（{{< icon name="close" >}}）。
   将出现**移除史诗**警告。
1. 选择**移除**。

## 配置子项显示偏好

您可以配置**子项**部分中显示的信息，以便专注于对您的工作流最重要的内容。

您可以配置**子项**部分中显示的信息，以便专注于对您的工作流最重要的内容。

> [!note]
> 当您更改一个史诗或议题中显示的信息时，您会为您的群组和项目中的所有工作项更改该信息。

1. 在**子项**部分标题的右上角，选择
   **显示选项**（{{< icon name="preferences" >}}）。

   默认情况下，所有选项和字段均可见。
1. 要更改显示的信息，请打开或关闭以下开关：

   - 对于显示选项：
     - **显示已关闭条目**
   - 对于显示的字段：
     - **状态**
     - **指派人**
     - **标记**
     - **权重**
     - **里程碑**
     - **迭代**
     - **日期**
     - **健康度**
     - **阻塞/被阻塞**
