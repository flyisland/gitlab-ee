安全分析 Agent 是一个专门的 AI 助手，可帮助您在极狐GitLab 中进行漏洞管理和安全分析工作流。它结合了安全专业知识和对极狐GitLab 安全功能、漏洞报告、安全仪表板和合规工具的深入了解，帮助您高效地分类、评估和修复安全发现。

在以下情况下使用安全分析 Agent：

- 漏洞分类：分析和优先处理不同扫描类型的安全发现。
- 风险评估：评估漏洞的严重性、可利用性和业务影响。
- 误报识别：区分真正的威胁和良性发现。
- 合规管理：了解法规要求和修复时间表。
- 安全报告：生成安全态势和修复进度的摘要。
- 修复计划：创建可操作的计划来解决安全漏洞。
- 安全工作流自动化：简化重复的安全评估任务。

安全分析 Agent 理解极狐GitLab 特定的安全实现，包括漏洞状态、严重性级别和安全扫描器输出。它可以解释 EPSS 分数、CVE 数据和可达性分析，以提供上下文安全指导。

<a id="use-the-security-analyst-agent"></a>

## 使用安全分析 Agent

您可以在极狐GitLab UI 中使用安全分析 Agent。

<a id="in-the-gitlab-ui"></a>

### 在极狐GitLab UI 中

先决条件：

- 使用启用了安全扫描的极狐GitLab 项目。
- [开启](_index.md#turn-foundational-agents-on-or-off)内置 Agent。

要在极狐GitLab UI 中使用安全分析 Agent：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的项目。
1. 在极狐GitLab Duo 侧边栏中，选择 **添加新聊天** ({{< icon name="pencil-square" >}})。
1. 从下拉列表中，选择 **安全分析**。

   一个聊天对话会在屏幕右侧的极狐GitLab Duo 侧边栏中打开。
1. 输入您的安全相关问题或请求。为了从您的请求中获得最佳结果：

   - 提供关于您的安全要求和风险容忍度的上下文。
   - 指定您关注哪些类型的漏洞或扫描结果。
   - 在请求分析时，包含相关的项目或组件详细信息。
   - 如果安全分析 Agent 的建议与您的安全策略不一致，请要求澄清。
   - 在讨论特定发现时，使用具体的漏洞 ID 或 URL。

<a id="example-prompts"></a>

## 示例提示

- 漏洞分析：
  - "显示我项目中的所有严重漏洞。"
  - "列出 EPSS 分数高于 0.7 且可达的漏洞。"
  - "根据可利用性，我应该优先处理哪些 SAST 发现？"
  - "分析 (组件名称) 中漏洞的安全影响。"
  - "比较此版本与上一版本之间的漏洞趋势。"
- 风险评估：
  - "这些容器扫描发现对业务有何风险？"
  - "帮助我评估此依赖项漏洞是否影响我们的用例。"
  - "评估跨越信任边界的漏洞的严重性。"
  - "哪些漏洞对生产环境构成最高风险？"
- 分类和管理：
  - "驳回所有标记为误报且具有不可达代码的依赖项扫描漏洞。"
  - "确认所有具有已知漏洞利用的容器扫描漏洞。"
  - "将所有跨越信任边界的漏洞的严重性更新为高。"
  - "显示过去一周内驳回的漏洞及其理由。"
  - "将漏洞状态恢复为已检测以进行重新评估。"
- 议题管理：
  - "为所有已确认的高严重性 SAST 漏洞创建议题，并将其分配给最近的提交者"
  - "将漏洞 (漏洞 ID) 链接到议题 (议题 ID) 以跟踪修复。"
  - "为关键基础设施漏洞生成修复任务。"
  - "创建一个安全史诗来跟踪所有与身份验证相关的漏洞。"
- 报告和合规：
  - "生成我们当前安全态势的执行摘要。"
  - "起草一份显示修复进度的合规报告。"
  - "为安全审查委员会总结安全发现。"
  - "创建一个时间表来处理所有高严重性发现。"
- 修复指导：
  - "为这些 SQL 注入漏洞建议修复方法。"
  - "针对此容器基础镜像漏洞的推荐修复是什么？"
  - "帮助我优先考虑下一个迭代的安全补丁。"
  - "提供安全编码实践指导，以防止这些问题。"
