AI 目录是 Agent 和流程的中央列表。
将这些 Agent 和流程添加到您的项目中，即可开始编排 Agent AI 任务。

使用 AI 目录可以：

- 发现由极狐GitLab 团队和社区成员创建的 Agent 和流程。
- 创建自定义 Agent 和流程，并与其他用户共享。
- 在您的项目中启用 Agent 和流程，以便在极狐GitLab Duo Agent Platform 中使用。

## 查看 AI 目录

{{< history >}}

- 使用极狐GitLab Duo 侧边栏查看 AI 目录的功能在极狐GitLab 18.11 中引入。

{{< /history >}}

先决条件：

- 您必须满足相关先决条件。
- 要从 AI 目录启用 Agent 和流程：
  - 在群组中，您必须具有维护者或所有者角色。
  - 在项目中，您必须具有维护者或所有者角色。

要查看 AI 目录，您可以：

- 使用顶部栏：
  1. 在顶部栏中，选择 **搜索或跳转到** > **探索**。
  1. 选择 **AI 目录**。

- 使用极狐GitLab Duo 侧边栏：
  1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的项目。
  1. 在极狐GitLab Duo 侧边栏上，选择 **极狐GitLab Duo AI 目录** ({{< icon name="tanuki-ai" >}})。

将显示 Agent 列表。

在私有化部署实例上，以下 Agent 不会显示在 AI 目录中：

- 在 JihuLab.com 上创建的自定义 Agent。
- 尚未添加到实例的由极狐GitLab 管理的第三方 Agent。

要查看可用的流程，请选择 **流程** 选项卡。

## Agent 和流程版本

{{< history >}}

- 在极狐GitLab 18.7 中引入。

{{< /history >}}

AI 目录中的每个自定义 Agent 和流程都维护着一个版本历史。
当您更改项目的配置时，极狐GitLab 会自动创建一个新版本。
内置 Agent 和流程不使用版本控制。

极狐GitLab 使用语义化版本控制来表示更改的范围。
例如，一个 Agent 可以有一个版本号，如 `1.0.0` 或 `1.1.0`。
极狐GitLab 会自动管理语义化版本控制。Agent 或流程的更新总是递增次版本号。

版本控制可确保您的项目和群组继续使用稳定、经过测试的 Agent 或流程配置。
这可以防止意外更改影响您的工作流。

### 创建版本

在以下情况下，极狐GitLab 会创建一个版本：

- 更新自定义 Agent 的系统提示。
- 修改第三方 Agent 或流程的配置。

为确保行为一致，版本是不可变的。

### 版本锁定

{{< history >}}

- 管理 Agent 或流程的项目始终使用该项目的最新版本的功能在极狐GitLab 18.10 中引入。

{{< /history >}}

当您启用一个 AI 目录项目时：

- 在群组中，极狐GitLab 会锁定最新版本。
- 在不管理该项目的项目中，极狐GitLab 会锁定与该项目顶级群组相同的版本。

版本锁定意味着：

- 您的项目或群组使用固定版本的项目。
- AI 目录中 Agent 或流程的更新不会影响您的配置。
- 您可以控制何时采用新版本。

这种方法为您的人工智能驱动的工作流提供了稳定性和可预测性。

当您在管理该项目的项目中启用 AI 目录项目时，极狐GitLab 不会锁定版本。
相反，管理项目始终使用该项目的最新版本。

如果您在极狐GitLab 18.10 之前于 Agent 或流程的管理项目中启用了它，您的配置将保持在锁定版本。

在您首次更新到最新版本后，极狐GitLab 将从此自动使用最新版本。

### 查看当前版本

先决条件：

- 您必须具有开发者、维护者或所有者角色。

要查看 Agent 或流程的当前版本：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的项目或群组。
1. 在左侧边栏中，选择以下之一：
   - **AI** > **Agent**
   - **AI** > **流程**
1. 选择要查看其详细信息的 Agent 或流程。

详细信息页面显示：

- 您的项目或群组正在使用的锁定版本。
- 版本标识符。例如，`1.2.0`。
- 关于该特定版本配置的详细信息。

### 更新到最新版本

先决条件：

- 您必须具有维护者或所有者角色。

要使您的群组或项目使用 Agent 或流程的最新版本：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的项目或群组。
1. 在左侧边栏中，选择以下之一：
   - **AI** > **Agent**
   - **AI** > **流程**
1. 选择您要更新的 Agent 或流程。
1. 仔细检查最新版本。要更新，请选择 **查看最新版本** > **更新到 `<x.y.z>`**。
