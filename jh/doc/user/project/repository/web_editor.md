Web 编辑器是一个基于浏览器的工具，用于在无需本地设置的情况下对极狐GitLab 仓库进行更改。你可以：

- 编辑单个文件并查看实时 Markdown 预览。
- 创建新文件和目录。
- 上传和替换文件。
- 为版本控制创建分支和标签。
- [锁定文件](../file_lock.md#lock-a-file-or-directory) 以防止并发编辑冲突。
- 无需在本地设置 Git 即可为项目做贡献。

极狐GitLab 使用你的[主邮箱地址](../../profile/_index.md#change-the-email-displayed-on-your-commits) 进行 Web 编辑器提交。

若要更改多个文件，请使用 [Web IDE](../web_ide/_index.md)。

> [!note]
> 要管理[受保护分支](branches/protected.md)中的文件，
> 你必须拥有相应的[权限](../../permissions.md)。

<a id="manage-files"></a>

## 管理文件

你可以通过 Web 编辑器，直接在极狐GitLab UI 中创建、编辑、上传和删除文件。

<a id="create-a-file"></a>

### 创建文件

要在 Web 编辑器中创建文本文件：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到你的项目。
1. 转到你要创建新文件的目录。
1. 在目录名称旁边，选择加号图标 ({{< icon name="plus" >}}) > **新建文件**。
1. 在分支名称旁边，输入文件名和扩展名。例如 `my_file.md`。
1. 向你的文件添加内容。
1. 选择 **提交更改**。
1. 在 **提交信息** 字段中，输入提交的原因。
1. 选择以下选项之一：

   - 要在预填的目标分支中创建文件，请选择 **提交更改**。
   - 要在新分支中创建文件并提交更改：

     1. 选择 **提交到新分支**。
     1. 输入分支名称。
     1. 确保 **为此更改创建合并请求** 复选框处于清除状态。
     1. 选择 **提交更改**。

   - 要在新分支中创建文件、提交更改并创建合并请求：

     1. 选择 **提交到新分支**。
     1. 输入分支名称。
     1. 确保 **为此更改创建合并请求** 复选框处于选中状态。
     1. 选择 **提交更改**。

要打开一个带有预填充内容的新文件编辑器，可以在 URL 中使用 `content` 查询参数。
例如：

```plaintext
https://jihulab.com/<your-namespace>/<your-project>/-/new/main?content=your+content+here
```

<a id="from-a-template"></a>

#### 从模板创建

要在 Web 编辑器中通过模板创建文本文件：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到你的项目。
1. 转到你要创建新文件的目录。
1. 在目录名称旁边，选择加号图标 ({{< icon name="plus" >}}) > **新建文件**。
1. 在 **文件名** 中，输入一个极狐GitLab 提供模板的名称：
   - `.gitignore`
   - `.gitlab-ci.yml`
   - `LICENSE`
   - `Dockerfile`
1. 从 **应用模板** 下拉列表中，选择一个模板。
1. 可选。根据需要更新模板。
1. 继续执行[创建文件](#create-a-file)流程中的第 6 步。

<a id="edit-a-file"></a>

### 编辑文件

要在 Web 编辑器中编辑文本文件：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到你的项目。
1. 转到你要编辑的文件。
1. 选择 **编辑** > **编辑单个文件**。
1. 进行你的更改。
1. 选择 **提交更改**。
1. 在 **提交信息** 字段中，输入提交的原因。
1. 选择以下选项之一：

   - 要在预填的目标分支中编辑文件，请选择 **提交更改**。
   - 要在新分支中编辑文件并提交更改：

     1. 选择 **提交到新分支**。
     1. 输入分支名称。
     1. 确保 **为此更改创建合并请求** 复选框处于清除状态。
     1. 选择 **提交更改**。

   - 要在新分支中编辑文件、提交更改并创建合并请求：

     1. 选择 **提交到新分支**。
     1. 输入分支名称。
     1. 确保 **为此更改创建合并请求** 复选框处于选中状态。
     1. 选择 **提交更改**。
     1. 填写字段并选择 **创建合并请求**。

> [!note]
> 如果你在编辑文件时，其他人同时编辑并提交了对同一文件的更改，
> 你将无法提交你的更改。系统会显示以下错误信息：
> `有人在你编辑的同时编辑了该文件。请检出文件并确保你的更改不会无意中移除他们的更改。`

<a id="markdown-preview"></a>

#### Markdown 预览

要在 Web 编辑器中预览 Markdown 文件：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到你的项目。
1. 转到你要预览的文件。
1. 选择 **编辑** > **编辑单个文件**。
1. 选择 **预览** 选项卡。

你可以在内容旁边看到实时 Markdown 预览。

要关闭预览面板，请选择 **编写** 选项卡。

<a id="link-to-specific-lines"></a>

#### 链接到特定行

要在 Web 编辑器中链接到单行或多行，可以在 URL 的文件名部分添加哈希信息。例如：

- `MY_FILE.js#L3` 高亮 `MY_FILE.js` 中的第 3 行。
- `MY_FILE.js#L3-10` 高亮 `MY_FILE.js` 中的第 3 至 10 行。

在编辑文件时，你也可以通过选择行号来链接到某一行。

<a id="edit-files-in-a-forked-merge-request"></a>

#### 编辑派生合并请求中的文件

先决条件：

- 你必须处理来自派生的合并请求。
- [允许来自上游成员的提交](../merge_requests/allow_collaboration.md#allow-commits-from-upstream-members) 必须启用。

如果你在处理来自派生项目的合并请求，
你可以编辑文件并提交更改。要做到这一点：

1. 转到合并请求。
1. 转到你要编辑的文件。
1. 选择 **编辑** > **编辑单个文件**。
1. 选择 **提交更改**。
1. 在 **提交信息** 中，输入提交的原因。
   系统会提供以下信息：`你的更改可以提交到 <branch-name>，因为有一个合并请求处于开启状态。`
1. 选择 **提交更改**。

   - 确认你要取消更改：选择 **确定**。
   - 不取消更改：选择 **取消**。

### 通过操作菜单进行文件操作

1. 选择你需要的操作。

<a id="editor-accessibility-options"></a>

## 编辑器辅助功能选项

Web 编辑器基于 [Monaco Editor](https://github.com/microsoft/monaco-editor)，它提供了多项[辅助功能](https://github.com/microsoft/monaco-editor/wiki/Monaco-Editor-Accessibility-Guide)，包括：

| 功能 | Windows 或 Linux 上的快捷键 | macOS 上的快捷键 | 详情 |
|----------------------------------|-----------------------------------|------------------------------------------------------|------|
| 键盘导航命令列表 | <kbd>F1</kbd> | <kbd>F1</kbd> | 一个[命令列表](https://github.com/microsoft/monaco-editor/wiki/Monaco-Editor-Accessibility-Guide#keyboard-navigation)，使编辑器在无需鼠标的情况下更易于使用。 |
| 选项卡捕获 | <kbd>Control</kbd>+<kbd>m</kbd> | <kbd>Control</kbd>+<kbd>Shift</kbd>+<kbd>m</kbd> | 启用[选项卡捕获](https://github.com/microsoft/monaco-editor/wiki/Monaco-Editor-Accessibility-Guide#tab-trapping)以转到页面上下一个可聚焦元素，而不是插入制表符。 |
