使用**比较修订版本**查看各修订版本之间发生变更的提交和文件列表。

您可以比较：

- 一个分支与另一个分支。
- 一个标签与一个分支或标签。
- 一个提交与另一个提交或分支。

<a id="compare-methods"></a>

## 比较方法

极狐GitLab 提供两种比较修订版本的方法：

- **仅包含来自源修订版本的传入变更**（默认）：显示两个修订版本的最新共同提交之后源修订版本中的差异。此方法会排除源修订版本创建后对目标修订版本所做的不相关变更。使用此方法可仅查看源修订版本引入的变更。

  此方法使用 `git diff <from>...<to>` Git 命令。它比较的是从合并基点（共同祖先提交）到目标修订版本之间的差异，而不是直接比较实际的提交。

- **包含源修订版本创建后对目标修订版本所做的变更**：显示两个修订版本之间的所有差异，包括对源修订版本和目标修订版本所做的变更。使用此方法可查看代码仓库历史中两个时间点之间的完整差异。

  此方法使用 `git diff <from> <to>` Git 命令。它直接比较实际的提交，显示它们之间的所有变更。

<a id="compare-branches-tags-or-commits"></a>

## 比较分支、标签或提交

要比较修订版本：

1. 在顶部栏中，选择**搜索或跳转到**并找到您的项目。
1. 在左侧边栏中，选择**代码** > **比较修订版本**。
1. 选择**源**修订版本：

   - 要搜索分支，请输入分支名称。完全匹配项会优先显示。
   - 要搜索标签，请输入标签名称。
   - 要搜索提交，请输入提交 SHA。
   - 要使用运算符优化搜索：
     - `^` 匹配名称的开头：`^feat` 匹配 `feat/user-authentication`。
     - `$` 匹配名称的结尾：`widget$` 匹配 `feat/search-box-widget`。
     - `*` 使用通配符进行匹配：`branch*cache*` 匹配 `fix/branch-search-cache-expiration`。
     - 您可以组合使用运算符：`^chore/*migration$` 匹配 `chore/user-data-migration`。

1. 选择**目标**代码仓库和修订版本。
1. 在**显示变更**下方，选择**仅包含来自源修订版本的传入变更**（默认）或**包含源修订版本创建后对目标修订版本所做的变更**。
1. 选择**比较**。
1. 可选。要反转**源**和**目标**，请选择**交换修订版本**（{{< icon name="substitute" >}}）。

比较页面会显示各修订版本之间发生变更的提交和文件列表。

<a id="view-on-environment"></a>

## 在环境中查看

比较修订版本时，您可以直接在文件部署的环境中预览文件。

先决条件：

- 为您的项目配置了[路由映射](../../../ci/review_apps/_index.md#route-maps)。
- 您想要预览的文件已包含在路由映射配置中。
- 有一个可访问的环境。

要在文件部署的环境中预览文件：

1. 在顶部栏中，选择**搜索或跳转到**并找到您的项目。
1. 在左侧边栏中，选择**代码** > **比较修订版本**。
1. 选择您想要比较的**源**和**目标**分支或提交。
1. 在文件差异视图中，找到包含在路由映射配置中的文件。
1. 选择该文件的**更多操作**菜单（{{< icon name="ellipsis_v" >}}）。
1. 选择**在 [环境名称] 中查看**。

该文件会在新标签页中打开，显示它在部署环境中的样子。
