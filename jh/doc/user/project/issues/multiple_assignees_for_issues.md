在拥有共同所有权的大型团队中，跟踪谁正在处理某个议题、谁已完成，或谁尚未开始，可能很困难。

您可以为议题添加多个[指派人](managing_issues.md#assignees)，从而更轻松地跟踪，并更清楚地了解谁对该议题负责。

议题的多个指派人使协作更加顺畅，并能清晰展示共同责任。
所有指派人都会显示在您团队的工作流程中，并收到通知（与作为单一指派人时相同），从而简化沟通和所有权。

指派人完成工作后，会将自己从指派人中移除，以明确其任务已完成。
