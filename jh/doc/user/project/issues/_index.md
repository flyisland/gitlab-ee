议题可帮助您与团队协作，在极狐GitLab 中规划、跟踪和交付工作。议题可以：

- 跟踪功能提案、任务、支持请求和缺陷报告。
- 通过指派人、截止日期和健康状态来组织和确定工作的优先级。
- 通过评论和讨论串促进团队讨论和决策。
- 通过模板、标记、史诗和看板支持自定义工作流。
- 与 Zoom、Jira 和电子邮件服务等外部工具集成。

议题始终与特定项目关联。如果您在一个群组中有多个项目，则可以一次查看所有项目的议题。


<a id="issues-as-work-items"></a>

## 作为工作项的议题

议题已迁移到统一的工作项框架，以更好地
满足极狐GitLab Agile Planning 产品方案的需求。

更多信息，请参见 [史诗 9290](https://gitlab.com/groups/gitlab-org/-/work_items/9290) 和[极狐GitLab 中的新 Agile Planning 体验](https://about.gitlab.com/blog/first-look-the-new-agile-planning-experience-in-gitlab/)博客文章（2024 年 6 月）。

如果您在试用此变更时遇到任何问题，可以使用
[反馈议题](https://gitlab.com/gitlab-org/gitlab/-/issues/523713)提供更多详细信息。

<a id="work-item-markdown-reference"></a>

### 工作项 Markdown 引用

您可以在极狐GitLab 风格 Markdown 字段中使用 `[work_item:123]` 引用工作项。
更多信息，请参见[极狐GitLab 特定引用](../../markdown.md#gitlab-specific-references)。
