极狐GitLab 机器学习运维（MLOps）是一套旨在帮助您进行机器学习工作流的工具。

极狐GitLab MLOps 功能包括：

- 模型注册表：管理您的机器学习模型，以及相关元数据，例如参数、性能指标、产物和日志。更多信息，请参见[模型注册表](model_registry/_index.md)。
- 模型实验：在极狐GitLab 中跟踪和管理机器学习实验。实验是一组可比较的模型候选，它们是机器学习模型训练的不同变体。更多信息，请参见[模型实验](experiment_tracking/_index.md)。

<a id="gitlab-mlops-python-client"></a>

## 极狐GitLab MLOps Python 客户端

极狐GitLab 提供了一个 Python 客户端，用于与极狐GitLab MLOps 功能进行交互。

详情请参见 [极狐GitLab MLOps Python 客户端](https://jihulab.com/gitlab-cn/modelops/mlops/gitlab-mlops)。
