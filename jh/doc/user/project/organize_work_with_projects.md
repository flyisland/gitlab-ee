在极狐GitLab 中，项目是涵盖开发工作各个方面的广泛容器。项目包含代码仓库、协作工具、项目管理功能和 CI/CD 能力。使用项目来组织开发项目的所有数据：

- 跟踪议题
- 规划工作
- 协作编写代码
- 使用 CI/CD 工具持续构建、测试和部署应用程序

项目可以[公开、内部或私有](../public_access.md)。极狐GitLab 不限制您可以创建的私有项目数量。
