[ZenTao](https://www.zentao.net/) 是一个基于 Web 的项目管理平台。

支持以下 ZenTao 版本：

- ZenTao 15.4
- ZenTao Pro 10.2
- ZenTao Biz 5.2
- ZenTao Max 2.2

<a id="configure-zentao"></a>

## 配置 ZenTao

此集成需要 ZenTao API 密钥。

在 ZenTao 中完成以下步骤：

1. 转到您的**管理员**页面，选择**开发** > **应用**。
1. 选择**添加应用**。
1. 在**名称**和**代号**下，为新密钥输入名称和代号。
1. 在**账号**下，选择一个现有账号名称。
1. 选择**保存**。
