[禅道](https://www.zentao.net/) 是一个基于 Web 的项目管理平台。

支持以下版本的禅道：

- ZenTao 15.4
- ZenTao Pro 10.2
- ZenTao Biz 5.2
- ZenTao Max 2.2

<a id="configure-zentao"></a>

## 配置禅道

此集成需要禅道 API 密钥。

在禅道中完成以下步骤：

1. 进入您的 **管理员** 页面，选择 **开发** > **应用**。
1. 选择 **添加应用**。
1. 在 **名称** 和 **代码** 下，输入新密钥的名称和代码。
1. 在 **账号** 下，选择一个已有的账号名称。
1. 选择 **保存**。
