审计事件类型用于筛选流式传输的审计事件：

- [适用于实例](../../administration/compliance/audit_event_streaming.md#update-event-filters)。
- [适用于顶级群组](audit_event_streaming.md#update-event-filters)

每个审计事件都与一个事件类型相关联。审计事件类型可以支持：

- 将大多数审计事件保存到数据库。在专业版和旗舰版中可用。您可以使用审计事件仪表板或
  [审计事件 API](../../api/audit_events.md) 检索与这些类型关联的审计事件。
- 将所有审计事件流式传输到外部目标。在旗舰版中可用。如果设置了目标，您可以将与这些类型关联的审计事件流式传输到外部目标。

审计事件类型的作用域将审计事件类型的可用性限制为以下任一类型：

- [项目、群组或用户](audit_events.md)审计事件。
- [实例](../../administration/compliance/audit_event_reports.md)审计事件。
