合规概览仪表板通过交互式图表和指标提供群组合规态势的可视化洞察。它帮助您快速识别需要关注的领域并跟踪您的整体合规状态。

合规概览仪表板显示合规监控的四个关键领域：

- 合规框架覆盖率。
- 失败的需求状态。
- 失败的控件状态。
- 需要关注的合规框架。

<a id="view-the-compliance-overview-dashboard"></a>

## 查看合规概览仪表板

前提条件：

- 您必须是群组的管理员，或者拥有安全管理员或所有者角色。

要查看合规概览仪表板：

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的群组。
1. 在左侧边栏中，选择 **安全** > **合规中心**。
1. 选择 **概览** 查看合规仪表板。

<a id="compliance-framework-coverage"></a>

## 合规框架覆盖率

框架覆盖率部分提供您群组中已分配合规框架的项目数量概览。

框架覆盖率部分显示：

- **项目总数**：群组中的项目总数。
- **已覆盖项目**：至少分配了一个合规框架的项目数量。
- **覆盖率百分比**：跨项目框架覆盖率的可视化表示。

在摘要指标下方，您可以看到各个框架的覆盖率，包括：

- 带有可视化徽章的框架名称。
- 使用每个框架的项目数量。
- 每个框架覆盖的项目占总数的百分比。

<a id="failed-requirements-chart"></a>

## 失败的需求图表

失败的需求图表可视化框架间需求的合规状态。

失败的需求图表显示三个类别：

- **通过**：完全合规的需求（蓝色显示）。
- **待定**：审核中的需求（橙色显示）。
- **失败**：未满足合规标准的需求（品红色显示）。

<a id="failed-controls-chart"></a>

## 失败的控件图表

失败的控件图表提供整个组织中控件合规状态的可视化表示。

失败的控件图表显示三个类别：

- **通过**：满足合规要求的控件（蓝色显示）。
- **待定**：等待评估的控件（橙色显示）。
- **失败**：不满足合规要求的控件（品红色显示）。

<a id="frameworks-table"></a>

## 框架表格

框架表格突出显示需要立即关注的合规框架。此视图帮助您识别存在配置问题或缺失组件的框架。

框架表格显示：

- **框架名称**：带有可视化徽章的合规框架。
- **项目**：使用此框架的项目数量（如果为零，以红色突出显示）。
- **需求**：框架中的需求总数（如果为零，以红色突出显示）。
- **无控件需求**：列出没有关联控件的特定需求。
- **策略**：与框架关联的安全策略，包括：
  - 扫描执行策略。
  - 漏洞管理策略。
  - 扫描结果策略。
  - 流水线执行策略。
- **操作**：编辑框架按钮（对具有管理员权限的用户可见）。
