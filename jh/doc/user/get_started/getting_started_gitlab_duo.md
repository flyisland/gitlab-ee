title: 开始使用极狐GitLab Duo
---

极狐GitLab Duo 是一款 AI 原生助手，可在您的规划、开发和安全工作流中为您提供帮助。极狐GitLab Duo 包含代码建议和代码解释等功能，可帮助您编写、评审和编辑代码。

<a id="step-1-ensure-you-have-access-to-gitlab-duo"></a>

## 第 1 步：确保您有权访问极狐GitLab Duo

极狐GitLab Duo 需要由您的管理员、群组或项目所有者进行设置。

如果您在访问极狐GitLab Duo 功能时遇到问题，您的管理员可以检查安装的健康状况。

更多信息，请参见：

- [开启极狐GitLab Duo](../gitlab_duo/turn_on_off.md)。
- [健康检查详情](../../administration/gitlab_duo/configure/_index.md#run-a-health-check-for-gitlab-duo)。

<a id="step-2-try-gitlab-duo-chat-in-the-ui"></a>

## 第 2 步：在 UI 中试用极狐GitLab Duo Chat

要开始使用，请尝试在极狐GitLab UI 中使用 Chat。

转到一个项目，然后在右上角选择**极狐GitLab Duo Chat** 按钮。如果此按钮可用，说明一切均已正确配置。尝试向 Chat 询问有关特定议题或合并请求的问题，或有关极狐GitLab 的一般问题。

更多信息，请参见：

- [GitLab Duo Non-Agentic Chat](../gitlab_duo_chat/_index.md)。

<a id="step-3-try-other-gitlab-duo-features"></a>

## 第 3 步：试用其他极狐GitLab Duo 功能

极狐GitLab Duo 可在您的整个工作流中使用。从规划冲刺到排查 CI/CD 流水线问题，从编写测试用例到解决安全威胁，极狐GitLab Duo 都能以多种方式为您提供帮助。

您可访问的功能可能有所不同，具体取决于您的订阅。

更多信息，请参见：

- [决策树，帮助您确定哪些极狐GitLab Duo 功能与您的工作流匹配](../gitlab_duo/_index.md)。
- [极狐GitLab Duo 功能的完整列表](../gitlab_duo/feature_summary.md)。
- [如何开启仍在开发中的极狐GitLab Duo 功能](../gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features)。

<a id="step-4-prepare-to-use-gitlab-duo-in-your-ide"></a>

## 第 4 步：准备在您的 IDE 中使用极狐GitLab Duo

现在，请在您的 IDE 中试用极狐GitLab Duo 功能。在 VS Code 和其他编辑器中，您可以使用极狐GitLab Duo Chat、软件开发任务流和代码建议等功能。

要开始使用，请安装扩展并使用极狐GitLab 进行身份验证。

更多信息，请参见：

- [为 VS Code 设置扩展](../../editor_extensions/visual_studio_code/setup.md)。
- [为 JetBrains 设置扩展](../../editor_extensions/jetbrains_ide/setup.md)。
- [为 Visual Studio 设置扩展](../../editor_extensions/visual_studio/setup.md)。
- [为 Neovim 设置扩展](../../editor_extensions/neovim/setup.md)。
- [使用 Web IDE](../project/web_ide/_index.md)。

<a id="step-5-start-using-ide-features"></a>

## 第 5 步：开始使用 IDE 功能

最后，请在您的 IDE 中测试极狐GitLab Duo。

- 代码建议会在您键入时推荐代码。
- Chat 可用于就您的代码或您需要的任何其他内容提问。
- 软件开发任务流会代您执行任务。

您可以选择希望获得建议的开发语言。

更多信息，请参见：

- [支持的扩展和语言](../project/repository/code_suggestions/supported_extensions.md)。
- [开启代码建议](../project/repository/code_suggestions/set_up.md#turn-on-code-suggestions)。
- [对 GitLab for VS Code 进行故障排除](../../editor_extensions/visual_studio_code/troubleshooting.md)。
- [对 JetBrains IDE 的极狐GitLab Duo 插件进行故障排除](../../editor_extensions/jetbrains_ide/jetbrains_troubleshooting.md)。
- [对 GitLab for Visual Studio 进行故障排除](../../editor_extensions/visual_studio/visual_studio_troubleshooting.md)。
- [对 Neovim 的极狐GitLab 插件进行故障排除](../../editor_extensions/neovim/neovim_troubleshooting.md)。
