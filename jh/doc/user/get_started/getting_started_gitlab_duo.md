极狐GitLab Duo 是一个 AI 原生助手，可在您的规划、开发和安全工作流中提供帮助。
极狐GitLab Duo 包含代码建议和代码解释等功能，
帮助您编写、审查和编辑代码。

<a id="step-1-ensure-you-have-access-to-gitlab-duo"></a>

## 步骤 1：确保您可以访问极狐GitLab Duo

极狐GitLab Duo 需要由管理员、群组或项目所有者进行设置。

如果您在访问极狐GitLab Duo 功能时遇到问题，管理员
可以检查安装的健康状况。

更多信息，请参见：

- [开启极狐GitLab Duo](../gitlab_duo/turn_on_off.md)。
- [健康检查详情](../../administration/gitlab_duo/configure/_index.md#run-a-health-check-for-gitlab-duo)。

<a id="step-2-try-gitlab-duo-chat-in-the-ui"></a>

## 步骤 2：在 UI 中试用极狐GitLab Duo Chat

要开始使用，请尝试在极狐GitLab UI 中使用 Chat。

转到项目，在右上角选择 **极狐GitLab Duo Chat** 按钮。
如果此按钮可用，则表示一切配置正确。
尝试向 Chat 询问关于特定议题或合并请求的问题，或者关于极狐GitLab 的一般性问题。

更多信息，请参见：

- [极狐GitLab Duo 非 Agentic 模式 Chat](../gitlab_duo_chat/_index.md)。

<a id="step-3-try-other-gitlab-duo-features"></a>

## 步骤 3：试用其他极狐GitLab Duo 功能

极狐GitLab Duo 可在整个工作流中使用。从规划冲刺到
排查 CI/CD 流水线问题，从编写测试用例到解决安全威胁，
极狐GitLab Duo 都能以多种方式提供帮助。

您可访问的功能可能因订阅而异。

更多信息，请参见：

- [决策树，帮助您确定哪些极狐GitLab Duo 功能与您的工作流匹配](../gitlab_duo/_index.md)。
- [极狐GitLab Duo 功能完整列表](../gitlab_duo/feature_summary.md)。
- [如何开启仍在开发中的极狐GitLab Duo 功能](../gitlab_duo/turn_on_off.md#turn-on-beta-and-experimental-features)。

<a id="step-4-prepare-to-use-gitlab-duo-in-your-ide"></a>

## 步骤 4：准备在 IDE 中使用极狐GitLab Duo

现在在您的 IDE 中试用极狐GitLab Duo 功能。在 VS Code 和其他编辑器中，您可以使用
极狐GitLab Duo Chat、软件开发流程和代码建议等功能。

要开始使用，请安装扩展并使用极狐GitLab 进行身份验证。

更多信息，请参见：

- [设置 VS Code 扩展](../../editor_extensions/visual_studio_code/setup.md)。
- [设置 JetBrains 扩展](../../editor_extensions/jetbrains_ide/setup.md)。
- [设置 Visual Studio 扩展](../../editor_extensions/visual_studio/setup.md)。
- [设置 Neovim 扩展](../../editor_extensions/neovim/setup.md)。
- [使用 Web IDE](../project/web_ide/_index.md)。

<a id="step-5-start-using-ide-features"></a>

## 步骤 5：开始使用 IDE 功能

最后，在您的 IDE 中测试极狐GitLab Duo。

- 代码建议会在您键入时推荐代码。
- Chat 可用于询问有关代码或您需要的任何其他内容的问题。
- 软件开发流程可代表您执行任务。

您可以选择希望获得建议的开发语言。

更多信息，请参见：

- [支持的扩展和语言](../project/repository/code_suggestions/supported_extensions.md)。
- [开启代码建议](../project/repository/code_suggestions/set_up.md#turn-on-code-suggestions)。
- [排查极狐GitLab for VS Code 问题](../../editor_extensions/visual_studio_code/troubleshooting.md)。
