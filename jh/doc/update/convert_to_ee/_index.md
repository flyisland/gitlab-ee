并非所有升级都是从极狐GitLab 的一个版本升级到另一个版本。还有其他升级路径可用。

## <a id="convert-to-enterprise-edition"></a>

## 转换为企业版

你可以将极狐GitLab 基础版（CE）实例转换为极狐GitLab 企业版（EE）实例：

- [将 Linux 软件包实例转换为企业版](package.md)
- [将 Docker 实例转换为企业版](docker.md)
- [将自编译实例转换为企业版](self_compiled.md)
- [将极狐GitLab Helm chart 实例转换为企业版](https://gitlab.cn/docs/charts/installation/deployment/#convert-community-edition-to-enterprise-edition)

如果需要，你可以[从企业版回退至基础版](revert.md)。

## <a id="convert-a-self-compiled-instance-to-a-linux-package"></a>

## 将自编译实例转换为 Linux 软件包

如果你有自编译的极狐GitLab 实例，你可以
[将自编译的极狐GitLab 实例转换为 Linux 软件包](https://gitlab.cn/docs/omnibus/update/convert_to_omnibus/)。
