极狐GitLab [集成](../user/project/integrations/_index.md)了许多第三方服务，因此您可以直接在极狐GitLab 中使用这些服务。

| 主题 | 描述 | 适合初学者 |
|-------|-------------|--------------------|
| [创建 Jira 凭据](../integration/jira/jira_server_configuration.md) | 创建 Jira 凭据，以在极狐GitLab 中配置 Jira 议题集成。预计用时：15-20 分钟。 | |
| [与 Jira 集成](https://about.gitlab.com/blog/gitlab-jira-integration-selfmanaged/) | 配置 Jira 议题集成，将一个或多个极狐GitLab 项目连接到一个 Jira 实例。预计用时：30-45 分钟。 | |
| [与 Gitpod 集成](https://about.gitlab.com/blog/teams-gitpod-integration-gitlab-speed-up-development/)  | 与 Gitpod 集成，为任意极狐GitLab 项目设置开发环境。预计用时：30-45 分钟。 | |
