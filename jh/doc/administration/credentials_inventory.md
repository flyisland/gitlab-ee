使用凭证清单来监控和控制对您组织的访问。

- 在 JihuLab.com 上，凭证清单监控顶级群组中的企业用户和服务账户。
- 在私有化部署实例上，凭证清单监控整个实例中的所有人类用户和服务账户。

前提条件：

- 在 JihuLab.com 上，您必须拥有群组的 所有者 角色。
- 在私有化部署实例上，您必须是管理员。

<a id="view-the-credentials-inventory"></a>

## 查看凭证清单

您可以使用凭证清单查看：

- 个人访问 Token。
- 群组访问 Token。
- 项目访问 Token。
- SSH 密钥。
- GPG 密钥（仅限私有化部署实例）。

要查看凭证清单：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择 **管理员**。
1. 在左侧边栏中，选择 **凭证**。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的群组。
1. 在左侧边栏中，选择 **安全合规**。
1. 选择 **凭证**。

{{< /tab >}}

{{< /tabs >}}

您可以使用清单查看凭证详细信息，包括：

- 所有权。
- 访问范围。
- 使用模式。
- 到期日期。
- 吊销日期。

<a id="revoke-personal-access-tokens"></a>

## 吊销个人访问 Token

要吊销个人访问 Token：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择 **管理员**。
1. 在左侧边栏中，选择 **凭证**。
1. 在个人访问 Token 旁边，选择 **吊销**。
   如果 Token 之前已过期或被吊销，则会显示相关日期。

访问 Token 被吊销，用户会收到电子邮件通知。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的群组。
1. 在左侧边栏中，选择 **安全合规**。
1. 选择 **凭证**。
1. 在个人访问 Token 旁边，选择 **吊销**。
   如果 Token 之前已过期或被吊销，则会显示相关日期。

访问 Token 被吊销，用户会收到电子邮件通知。

{{< /tab >}}

{{< /tabs >}}

<a id="revoke-project-or-group-access-tokens"></a>

## 吊销项目或群组访问 Token

要吊销项目或群组访问 Token：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择 **管理员**。
1. 在左侧边栏中，选择 **凭证**。
1. 选择 **项目和群组访问 Token** 选项卡。
1. 在项目访问 Token 旁边，选择 **吊销**。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的群组。
1. 在左侧边栏中，选择 **安全合规**。
1. 选择 **凭证**。
1. 选择 **项目和群组访问 Token** 选项卡。
1. 在项目访问 Token 旁边，选择 **吊销**。

{{< /tab >}}

{{< /tabs >}}

<a id="delete-ssh-keys"></a>

## 删除 SSH 密钥

要删除 SSH 密钥：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择 **管理员**。
1. 在左侧边栏中，选择 **凭证**。
1. 选择 **SSH 密钥** 选项卡。
1. 在 SSH 密钥旁边，选择 **删除**。

SSH 密钥将被删除，并通知用户。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择 **搜索或跳转到** 并找到您的群组。
1. 在左侧边栏中，选择 **安全合规**。
1. 选择 **凭证**。
1. 选择 **SSH 密钥** 选项卡。
1. 在 SSH 密钥旁边，选择 **删除**。

SSH 密钥将被删除，并通知用户。

{{< /tab >}}

{{< /tabs >}}
