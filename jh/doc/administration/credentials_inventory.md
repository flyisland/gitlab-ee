使用凭据清单来监控和控制对您组织的访问。

- 在 JihuLab.com 上，凭据清单监控顶级群组中的企业用户和服务账号。
- 在极狐GitLab 私有化部署上，凭据清单监控整个实例中的所有人类用户和服务账号。

先决条件：

- 在 JihuLab.com 上，您必须拥有群组的所有者角色。
- 在极狐GitLab 私有化部署上，您必须是管理员。

<a id="view-the-credentials-inventory"></a>

## 查看凭据清单

您可以使用凭据清单查看：

- 个人访问令牌。
- 群组访问令牌。
- 项目访问令牌。
- SSH 密钥。
- GPG 密钥（仅限极狐GitLab 私有化部署）。

要查看凭据清单：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择**管理员**。
1. 在左侧边栏中，选择**访问** > **凭据**。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择**搜索或跳转到**，然后找到您的群组。
1. 在左侧边栏中，选择**安全**。
1. 选择**凭据**。

{{< /tab >}}

{{< /tabs >}}

您可以使用该清单查看凭据详细信息，包括：

- 所有权。
- 访问范围。
- 使用模式。
- 到期日期。
- 撤销日期。

<a id="revoke-personal-access-tokens"></a>

## 撤销个人访问令牌

要撤销个人访问令牌：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择**管理员**。
1. 在左侧边栏中，选择**访问** > **凭据**。
1. 在该个人访问令牌旁边，选择**撤销**。
   如果该令牌之前已过期或已撤销，则会显示相关日期。

该访问令牌将被撤销，并通过电子邮件通知用户。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择**搜索或跳转到**，然后找到您的群组。
1. 在左侧边栏中，选择**安全**。
1. 选择**凭据**。
1. 在该个人访问令牌旁边，选择**撤销**。
   如果该令牌之前已过期或已撤销，则会显示相关日期。

该访问令牌将被撤销，并通过电子邮件通知用户。

{{< /tab >}}

{{< /tabs >}}

<a id="revoke-project-or-group-access-tokens"></a>

## 撤销项目或群组访问令牌

要撤销项目或群组访问令牌：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择**管理员**。
1. 在左侧边栏中，选择**访问** > **凭据**。
1. 选择**项目和群组访问令牌**标签页。
1. 在该项目访问令牌旁边，选择**撤销**。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择**搜索或跳转到**，然后找到您的群组。
1. 在左侧边栏中，选择**安全**。
1. 选择**凭据**。
1. 选择**项目和群组访问令牌**标签页。
1. 在该项目访问令牌旁边，选择**撤销**。

{{< /tab >}}

{{< /tabs >}}

<a id="delete-ssh-keys"></a>

## 删除 SSH 密钥

要删除 SSH 密钥：

{{< tabs >}}

{{< tab title="针对实例" >}}

1. 在右上角，选择**管理员**。
1. 在左侧边栏中，选择**访问** > **凭据**。
1. 选择 **SSH 密钥**标签页。
1. 在该 SSH 密钥旁边，选择**删除**。

该 SSH 密钥将被删除，并通知用户。

{{< /tab >}}

{{< tab title="针对群组" >}}

1. 在顶部栏中，选择**搜索或跳转到**，然后找到您的群组。
1. 在左侧边栏中，选择**安全**。
1. 选择**凭据**。
1. 选择 **SSH 密钥**标签页。
1. 在该 SSH 密钥旁边，选择**删除**。

该 SSH 密钥将被删除，并通知用户。

{{< /tab >}}

{{< /tabs >}}
