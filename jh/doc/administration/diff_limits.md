显示大文件的完整内容可能会降低合并请求的速度。为防止这种情况，您可以配置合并请求中显示的差异限制，包括最大差异大小、更改的文件数、更改的行数、差异版本和差异提交数。这些限制同时适用于返回差异信息的极狐GitLab UI 和 API 端点。

当差异达到最大差异补丁大小、最大差异文件数或最大差异行数值的 10% 时，极狐GitLab 会以折叠视图显示文件，并提供展开差异的链接。超过这三项中任何一项的差异会显示为 **过大**，您无法在 UI 中展开它们。

最大差异版本数和最大差异提交数限制合并请求的更新。达到这些限制的合并请求无法进一步更新：

| 值                       | 定义                                                              | 默认值 | 最大值 |
|-----------------------------|-------------------------------------------------------------------------|:-------------:|:-------------:|
| **最大差异补丁大小** | 整个差异的总大小（以字节为单位）。                           |    200 KB     |    500 KB     |
| **最大差异文件数**      | 差异中更改的文件总数。                                            |     1000      |     3000      |
| **最大差异行数**      | 差异中更改的行总数。                            |    50,000     |    100,000    |
| **最大差异版本数**   | 每个合并请求的差异版本数。                          |     1,000     |     无     |
| **最大差异提交数**    | 每个合并请求所有版本中的差异提交总数。 |   1,000,000   |     无     |

无法在 JihuLab.com 上配置差异限制。

有关差异文件的详细信息，请参阅[查看文件之间的更改](../user/project/merge_requests/changes.md)。
详细了解[合并请求和差异的内置限制](instance_limits.md#merge-requests)。

## 配置差异限制

> [!warning]
> 更高的限制会增加资源消耗，并可能导致实例
> 不稳定。请谨慎调整这些值，并在任何更改后监控实例
> 性能。

先决条件：

- 管理员访问权限。

要设置合并请求中差异显示的最大值：

1. 在右上角，选择 **管理员**。
1. 在左侧边栏中，选择 **设置** > **通用**。
1. 展开 **差异限制**。
1. 为差异限制输入一个值。
1. 选择 **保存更改**。
