<a id="create-a-geo-site"></a>

## 创建 Geo 站点

创建一个 Geo 站点。

```plaintext
POST /geo_sites
```

```shell
curl --request POST \
  --header "PRIVATE-TOKEN: <your_access_token>" \
  --url "https://primary.example.com/api/v4/geo_sites" \
  --data "name=himynameissomething" \
  --data-urlencode "url=https://another-node.example.com/"
```

| 属性                             | 类型    | 必需 | 描述                                                                                                                                            |
|---------------------------------------|---------|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| `primary`                             | boolean | 否       | 指定该站点是否应为主站点。默认为 false。                                                                                     |
| `enabled`                             | boolean | 否       | 指示 Geo 站点是否已启用的标志。默认为 true。                                                                                          |
| `name`                                | string  | 是      | Geo 站点的唯一标识符。如果在 `gitlab.rb`中设置了 `geo_node_name`，则必须与其匹配，否则必须与 `external_url` 匹配                 |
| `url`                                 | string  | 是      | Geo 站点的用户可访问 URL。                                                                                                                  |
| `internal_url`                        | string  | 否       | 在主站点上定义的 URL，从站点应使用该 URL 与其联系。如果未设置，则返回 `url`。                                           |
| `files_max_capacity`                  | integer | 否       | 控制此从站点的 LFS/附件回填的最大并发数。默认为 10。                                                    |
| `repos_max_capacity`                  | integer | 否       | 控制此从站点的代码仓库回填的最大并发数。默认为 25。                                                        |
| `verification_max_capacity`           | integer | 否       | 控制此站点的代码仓库校验的最大并发数。默认为 100。                                                             |
| `container_repositories_max_capacity` | integer | 否       | 控制此站点的容器仓库同步的最大并发数。默认为 10。                                                            |
| `sync_object_storage`                 | boolean | 否       | 指示 Geo 从站点是否应复制对象存储中的 blob 的标志。默认为 false。                                                 |
| `selective_sync_type`                 | string  | 否       | 将同步限制为仅特定群组或分片。有效值：`"namespaces"`、`"shards"` 或 `null`。                                                  |
| `selective_sync_shards`               | array   | 否       | 如果 `selective_sync_type` == `shards`，则为已同步项目的代码仓库存储。                                                                   |
| `selective_sync_namespace_ids`        | array   | 否       | 如果 `selective_sync_type` == `namespaces`，则为应同步的群组 ID。                                                                     |
| `minimum_reverification_interval`     | integer | 否       | 代码仓库校验有效的间隔（以天为单位）。一旦过期，将重新校验。在从站点上设置此项无效。 |
| `blob_download_timeout`               | integer | 否       | blob 复制的超时时间（以秒为单位）。默认为 28800。最大值为 86400。                                                                    |

示例响应：

```json
{
  "id": 3,
  "name": "Test Site 1",
  "url": "https://secondary.example.com/",
  "internal_url": "https://secondary.example.com/",
  "primary": false,
```
