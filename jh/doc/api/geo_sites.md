## 创建 Geo 站点

{{< history >}}

- `blob_download_timeout` 在极狐GitLab 18.10 引入。

{{< /history >}}

创建一个 Geo 站点。

```plaintext
POST /geo_sites
```

```shell
curl --header "PRIVATE-TOKEN: <your_access_token>" \
     --url "https://primary.example.com/api/v4/geo_sites" \
     --request POST \
     -d "name=himynameissomething" \
     -d "url=https://another-node.example.com/"
```

| 属性                                   | 类型     | 必需 | 描述                                                                                                                             |
|----------------------------------------|----------|------|----------------------------------------------------------------------------------------------------------------------------------|
| `primary`                              | boolean  | 否   | 指定此站点是否应为主站点。默认为 false。                                                                                          |
| `enabled`                              | boolean  | 否   | 指示 Geo 站点是否启用的标志。默认为 true。                                                                                        |
| `name`                                 | string   | 是   | Geo 站点的唯一标识符。如果在 `gitlab.rb` 中设置了 `geo_node_name`，则必须与其匹配，否则必须与 `external_url` 匹配。                   |
| `url`                                  | string   | 是   | Geo 站点的对外 URL。                                                                                                              |
| `internal_url`                         | string   | 否   | 在主站点上定义的 URL，辅助站点应使用该 URL 与其联系。如果未设置，则返回 `url`。                                                     |
| `files_max_capacity`                   | integer  | 否   | 控制此辅助站点的 LFS/附件回填的最大并发数。默认为 10。                                                                              |
| `repos_max_capacity`                   | integer  | 否   | 控制此辅助站点的仓库回填的最大并发数。默认为 25。                                                                                  |
| `verification_max_capacity`            | integer  | 否   | 控制此站点的仓库验证的最大并发数。默认为 100。                                                                                     |
| `container_repositories_max_capacity`  | integer  | 否   | 控制此站点的容器镜像仓库同步的最大并发数。默认为 10。                                                                               |
| `sync_object_storage`                  | boolean  | 否   | 指示辅助 Geo 站点是否应复制对象存储中的 blob 的标志。默认为 false。                                                                 |
| `selective_sync_type`                  | string   | 否   | 仅将同步限制到特定的群组或分片。有效值：`"namespaces"`、`"shards"` 或 `null`。                                                      |
| `selective_sync_shards`                | array    | 否   | 如果 `selective_sync_type` == `shards`，同步项目的仓库存储。                                                                        |
| `selective_sync_namespace_ids`         | array    | 否   | 如果 `selective_sync_type` == `namespaces`，应同步的群组 ID。                                                                       |
| `minimum_reverification_interval`      | integer  | 否   | 仓库验证有效的间隔（天数）。过期后，将重新验证。在辅助站点上设置时无效。                                                           |
| `blob_download_timeout`                | integer  | 否   | Blob 复制的超时时间（秒）。默认为 28800。最大值为 86400。                                                                           |

示例响应：

```json
{
  "id": 3,
  "name": "Test Site 1",
```
