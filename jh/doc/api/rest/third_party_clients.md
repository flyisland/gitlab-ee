你可以将第三方 API 客户端库与极狐GitLab 集成。以下库由社区成员维护，并非由极狐GitLab 官方支持。请将错误和功能提案报告给相应的项目。

有关这些集成的问题，请使用[极狐GitLab 社区论坛](https://forum.gitlab.com/)。

管理员可以通过[解析日志](../../administration/logs/log_parsing.md#print-top-api-user-agents)来监控这些 API 客户端的使用情况。
