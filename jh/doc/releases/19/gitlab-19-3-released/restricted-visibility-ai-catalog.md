现在，您可以为顶级群组中的每个群组、子群组和项目，将自定义 Agent 和自定义任务流设置为**受限可见性**。

此前，您只能将自定义任务流或 Agent 设置为**私有**（仅限单个项目）或**公开**（对 JihuLab.com 上的所有人可见）。当您将可见性设置为**受限**时，该任务流或 Agent 仅对您顶级群组中的群组、子群组和项目可见。这可以确保您自定义 Agent 和任务流的内部逻辑不会在您的公司或组织之外共享。
