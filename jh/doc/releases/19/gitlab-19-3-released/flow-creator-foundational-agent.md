您现在可以使用任务流创建器，这是 AI Catalog 中一个专门构建的内置 Agent，通过自然语言对话为极狐GitLab Duo Agent Platform 创建自定义任务流。
借助任务流创建器，您可以描述希望任务流执行的操作，该 Agent 会生成一个完整、可运行的任务流 YAML，您可以立即注册并使用。
该 Agent 还可以帮助您调试现有任务流并解释框架概念。
