此前，当您打开会话详情页面时，必须手动展开各个活动日志条目才能找到 Agent 的当前任务列表。现在，会话详情侧边栏会自动显示 Agent 的最新计划。您可以查看每项任务及其状态，以及“已完成 2/5”之类的进度摘要。您无需翻阅活动日志，即可跟踪 Agent 正在处理的工作及其进度。
