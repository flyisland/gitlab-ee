新的极狐GitLab Duo Agent 和任务流工具让您可以从任何 MCP 客户端调用并跟踪极狐GitLab Duo Agent 和任务流：

- `start_duo_session` 启动会话。
- `get_duo_session` 读取会话的当前状态。
- `list_duo_sessions` 分页浏览您的会话历史。
- `list_duo_agents_and_flows` 列出项目中启用的极狐GitLab Duo Agent 和任务流。
