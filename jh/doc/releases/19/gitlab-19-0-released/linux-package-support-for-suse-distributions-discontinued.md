极狐GitLab 19.0 将停止支持 SUSE 发行版的 Linux 软件包，这会影响 openSUSE Leap 15.6、
SUSE Linux Enterprise Server 12.5 和 SUSE Linux Enterprise Server 15.6。极狐GitLab 18.11 是
为这些发行版提供 Linux 软件包的最后一个版本。要继续使用 SUSE 发行版，请迁移到
[极狐GitLab 的 Docker 部署](../../../install/docker/installation.md)。
