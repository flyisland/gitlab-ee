极狐GitLab Duo Agent Platform 现在支持更多开源模型用于自部署环境，包括国内 SOTA 模型、GLM-5.1-FP8 等。这有助于客户在各种环境中支撑 Agentic 工作流，包括离线环境和网络受限的部署。
