从极狐GitLab 19.0 开始，极狐GitLab Duo Core 转为按用量计费。Web IDE 和桌面 IDE 中的代码建议现在会消耗[极狐GitLab Credits](../../../subscriptions/gitlab_credits.md)。

极狐GitLab Duo Chat 也有所变化。对于极狐GitLab Duo Core 用户，Chat 现在具备 Agentic 能力，并运行在极狐GitLab Duo Agent Platform 上。要在极狐GitLab UI 或桌面 IDE 中使用极狐GitLab Duo Chat，请为您的实例或顶级群组启用极狐GitLab Duo Agent Platform。
