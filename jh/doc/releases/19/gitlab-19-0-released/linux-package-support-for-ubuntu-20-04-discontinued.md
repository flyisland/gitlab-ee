Ubuntu 20.04 已于 2025 年 5 月结束标准支持。从极狐GitLab 19.0 开始，不再为 Ubuntu 20.04 提供 Linux 软件包。极狐GitLab 18.11 是最后一个提供该发行版软件包的版本。在升级到极狐GitLab 19.0 之前，请迁移到 Ubuntu 22.04 或其他[受支持的操作系统](../../../install/package/_index.md#supported-platforms)。
