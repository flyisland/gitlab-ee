本文档部分涵盖了由极狐GitLab 开发和提供的各种解决方案组件。要下载并运行这些解决方案组件，请联系您的客户团队获取邀请码。

任何解决方案组件的使用均受 [极狐GitLab 订阅协议](https://handbook.gitlab.com/handbook/legal/subscription-agreement/)（以下简称“协议”）的约束，并构成协议中定义的自由软件。

<a id="gitlab-duo-workflow"></a>

## 极狐GitLab Duo Workflow

极狐GitLab Duo Workflow 帮助你完成开发任务。极狐GitLab 代码库、议题、合并请求和流水线可以作为上下文，通过提示词执行自动化工作流。

有关 极狐GitLab Duo Workflow 的详细信息，请查看[此文档](../../../user/duo_agent_platform/_index.md)。

<a id="duo-workflow-solution"></a>

## Duo Workflow 解决方案

Duo Workflow 解决方案为不同的软件开发用例提供了提示词和上下文库。每个解决方案用例的提示词和上下文库支持所需的自主工作流，以自动化开发任务，包括根据定义的工作流计划进行代码更改、问题修复和代码审查等任务。
