此处列出的认证与称号可在 [极狐GitLab 在 AWS 的合作伙伴页面](https://partners.amazonaws.com/partners/001E0000018YWFfIAO/GitLab,%20Inc.) 上验证。

所有 AWS 合作伙伴资质均需提交并验证详尽的检查清单，并提供支持性证据，AWS 据此决定是否授予该资质。

<a id="devops-software-isv-competency"></a>

## DevOps 软件 / ISV 能力认证

该能力认证验证了极狐GitLab 提供的 DevOps 解决方案能够与 AWS 协同工作并运行于 AWS 之上。[AWS 项目信息](https://aws.amazon.com/devops/partner-solutions/)

<a id="devsecops-specialty-category"></a>

## DevSecOps 专业类别

DevSecOps 资质是 DevOps 软件能力认证的一个类别，表明极狐GitLab 在帮助组织实现 DevSecOps 成熟度目标方面是一款重要的解决方案。极狐GitLab 在获得该称号前，经过了针对这些额外资质的审核。[AWS 项目信息](https://aws.amazon.com/blogs/apn/aws-devops-competency-expands-to-include-devsecops-category/) [极狐GitLab 公告](https://gitlab.cn/blog/aws-devsecops-competency-partner/)

<a id="public-sector-partner"></a>

## 公共部门合作伙伴

该称号表明极狐GitLab 已被认定具备与 AWS 公共部门客户合作的能力。极狐GitLab 拥有专门的团队来满足公共部门的特定需求。[AWS 项目信息](https://aws.amazon.com/partners/programs/public-sector/)

<a id="aws-graviton"></a>

## AWS Graviton

极狐GitLab 实例与 Runner 已经过测试，可在 AWS Graviton 上运行。针对 Amazon Linux，我们维护了适用于 ARM 架构的 YUM 软件包。[AWS 项目信息](https://aws.amazon.com/ec2/graviton/partners/)

<a id="amazon-linux-ready"></a>

## Amazon Linux 就绪

极狐GitLab 实例与 Runner 已在 Amazon Linux 2 和 2023 上通过验证——这包括为两者提供的 YUM 软件包和软件包仓库，以及在打包前对两者进行的超过 2300 项 CI 测试。[AWS 项目信息](https://aws.amazon.com/amazon-linux/partners/)

<a id="aws-marketplace-seller"></a>

## AWS Marketplace 卖家

极狐GitLab 是 Marketplace 卖家，你可以通过 AWS Marketplace 购买并部署它。[AWS 项目信息](https://aws.amazon.com/marketplace/partners/management-tour)
